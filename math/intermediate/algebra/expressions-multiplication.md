## 単項式と多項式

$3x$ や $5x^2y$ のように、数と文字の掛け算だけでできた式を**単項式**、$2x + 3y - 1$ のように単項式の和の形で書かれた式を**多項式**といいます。$x$ のような文字だけの式や、$-1$ のような数だけの式も単項式とみなします。

---

## 多項式に数をかける・多項式を数で割る

分配法則を使って、括弧の前の数を各項に配ります。

$$2(4x - 5y) = 8x - 10y$$

割り算は、割る数の逆数をかけると考えます。$\div 2$ は $\times \frac{1}{2}$ と同じなので、各項を分数の形にしてから約分すれば計算できます。

$$(4x + 6) \div 2 = \frac{4x}{2} + \frac{6}{2} = 2x + 3$$

---

## 単項式どうしの乗法・除法

単項式どうしの掛け算は、数どうし・同じ文字どうしをそれぞれ掛け合わせます。同じ文字の累乗どうしを掛けるときは、指数の和をとります（$x^a \times x^b = x^{a+b}$）。これは[累乗](../numbers/arithmetic.md)で学んだ指数法則で、底が文字でもそのまま使えます。

$$3x^2 \times 4x = 3 \times 4 \times x^2 \times x = 12x^3$$

割り算は分数の形にしてから約分します。同じ文字の累乗どうしを割るときも、指数法則により指数の差をとります（$x^a \div x^b = x^{a-b}$）。ただし、この規則は割られる式の指数が割る式の指数より大きい（$a > b$）場合に使います。指数が等しいときは、$\frac{x}{x} = 1$ のように約分すると $1$ になります。割られる式の指数のほうが小さい場合（$x^2 \div x^3$ など）は、この記事では扱いません。

なお、数の割り算で $0$ で割ることを考えないのと同じように、文字を含む式で割るときは、割る式の値が $0$ になる場合（下の例では $x = 0$）は除いて考えます。また、$6x^3 \div 2x$ の $2x$ は1つの単項式として、まとめて割る式になります（$6x^3 \div (2x)$ と同じ意味で、「$2$ で割ってから $x$ を掛ける」という意味ではありません）。

$$6x^3 \div 2x = \frac{6x^3}{2x} = \frac{6}{2} \times \frac{x^3}{x} = 3x^2$$

異なる文字や負の係数を含む式、掛け算と割り算が混じった式、係数が分数の単項式で割る式も、同じように計算できます。数どうし・文字どうしに分けて計算し、割り算は割る式の逆数をかけて分数の形にしてから約分します。係数の符号は、負の数の掛け算・割り算と同じように決まります。異なる文字はまとめられないので、掛けた形のまま残ります。

$$(-2x) \times 3xy = (-2) \times 3 \times x \times x \times y = -6x^2y$$

$$(-8x^2y) \div 4x = \frac{-8x^2y}{4x} = \frac{-8}{4} \times \frac{x^2}{x} \times y = -2xy$$

$$4x^2 \times 3y \div 6x = 4x^2 \times 3y \times \frac{1}{6x} = \frac{12x^2y}{6x} = 2xy$$

$$6x^2y \div \frac{3}{2}x = 6x^2y \div \frac{3x}{2} = 6x^2y \times \frac{2}{3x} = \frac{12x^2y}{3x} = 4xy$$

単項式の累乗は、累乗の意味に戻って、同じ単項式を繰り返し掛けます。

$$(-3x)^2 = (-3x) \times (-3x) = (-3) \times (-3) \times x \times x = 9x^2$$

括弧がないと、累乗は直前の文字だけにかかります。そのため $-3x^2$ は $x$ だけを $2$ 乗して $-3$ を掛けた式で、$(-3x)^2 = 9x^2$ とは別の式です。

$$-3x^2 = -3 \times x \times x$$

## 単項式と多項式の乗法・除法

かけ算では、まず「多項式に数をかける・多項式を数で割る」で使った分配法則で括弧を展開します。次に、展開後の各項の計算で「単項式どうしの乗法・除法」で使った指数法則を使います。

$$2x(3x - 4) = 2x \times 3x - 2x \times 4 = 6x^2 - 8x$$

割り算も同様に、各項を単項式で割ってから、指数法則を使って約分します。

$$
\begin{aligned}
(6x^2 - 8x) \div 2x &= \frac{6x^2}{2x} - \frac{8x}{2x} \\
&= \left(\frac{6}{2} \times \frac{x^2}{x}\right) - \left(\frac{8}{2} \times \frac{x}{x}\right) \\
&= 3x - 4
\end{aligned}
$$

## 多項式の加減と数倍の組み合わせ

「多項式に数をかける・多項式を数で割る」で学んだ、多項式に数をかける計算を複数の項に対して組み合わせて使うと、加減を含む複雑な式も計算できます（多項式どうしを直接掛け合わせるわけではありません）。下の例の $- 3(2x + 5y)$ のように $3(2x + 5y)$ を引くことは、$(-3) \times (2x + 5y)$ を足すことと同じです。このように負の数をかけるときは、分配法則により括弧内のすべての項の符号が反転する点に注意します。

$$2(3x - 2y) - 3(2x + 5y) = 6x - 4y + (-3) \times 2x + (-3) \times 5y = 6x - 4y - 6x - 15y = (6x - 6x) + (-4y - 15y) = -19y$$

このような計算は、連立方程式（複数の文字についての方程式を同時に満たす解を求める単元）を解くときに使います。

## 文字式で数の性質を説明する

文字式は、具体的な数によらず成り立つ性質を説明するのにも使えます。

**例題 $1$**：「2つの奇数の和は偶数になる」ことを説明する。

[倍数と約数](../../beginner/numbers/multiples-divisors.md)では、自然数の範囲で、$2$ の倍数を偶数、$2$ で割り切れない数を奇数と呼びました。この記事では範囲を $0$ や負の整数まで広げ、$2 \times$（整数）の形の数を偶数、$2 \times$（整数）$+1$ の形の数を奇数として扱います。例えば $7 = 2 \times 3 + 1$ は奇数、$0 = 2 \times 0$ は偶数です。

2つの奇数を、整数 $m, n$ を使って $2m+1$、$2n+1$ と表します。2つの奇数は別々に選べるので、異なる文字 $m, n$ を使います。同じ文字 $m$ を使って $2m+1$ と $2m+1$ とすると、2つの奇数が等しい場合しか説明できません。

分配法則 $a(b+c) = ab + ac$ は逆向きにも使え、共通因数 $a$ でくくり出すことで $ab + ac = a(b+c)$ と変形できます。

$$(2m+1) + (2n+1) = 2m + 2n + 2 = 2\times m + 2\times n + 2\times 1 = 2(m+n+1)$$

$m+n+1$ は整数なので、この式は $2 \times$（整数）の形、つまり偶数です。よって2つの奇数の和は偶数になります。

このように、次の手順で数の性質を一般的に証明できます。

1. 説明したいことに出てくる数を、条件に合うように文字を使って表す
2. 計算する
3. 結果を、示したい性質を表す形に変形する（偶数なら $2 \times$（整数）、$3$ の倍数なら $3 \times$（整数）の形）
4. 結論を述べる

**例題 $2$**：「連続する $3$ つの整数の和は $3$ の倍数になる」ことを説明する。

連続する $3$ つの整数は、いちばん小さい数を整数 $n$ とすると、$n$、$n+1$、$n+2$ と表せます。例題 $1$ の $2$ つの奇数は別々に選べるので異なる文字を使いましたが、連続する $3$ つの整数は $1$ つ目が決まると残りも決まるので、$1$ つの文字で表します。

$$n + (n+1) + (n+2) = 3n + 3 = 3 \times n + 3 \times 1 = 3(n+1)$$

$n$ は整数なので、$n+1$ も整数です。よって、この式は $3 \times$（整数）の形、つまり $3$ の倍数です。

---

## まとめ

単項式・多項式の乗法・除法は、分配法則と指数法則を組み合わせて計算します。また、具体的な数を文字に置き換えることで、数の性質を一般的に説明する（証明する）ことができます。
