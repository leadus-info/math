## 一次方程式を解く

両辺を整理すると $ax + b = c$（$a$、$b$、$c$ は数で、$a \neq 0$）の形になる方程式を**一次方程式**といいます。ここで「整理する」とは、未知数 $x$ を含む項を片方の辺に集め、同類項をまとめることです（集め方はこのあと説明します）。整理したあとの未知数の項が $ax$ のように $x$ を1回だけ掛けた形なので、「一次」と呼びます。

たとえば $x^2 + 1 = 5$ は整理しても $x^2$ が残るので、一次方程式ではありません。見かけ上 $x^2$ を含んでいても、$x^2 + x = x^2 + 3$ のように整理すると $x^2$ が消えて $x = 3$ になる方程式は一次方程式です。

$$2x + 3 = 7$$

両辺から $3$ を引くと、左辺は $2x + 3 - 3 = 2x$、右辺は $7 - 3$ になるので、$2x = 7 - 3 = 4$ です。$2x = 4$ の両辺を $2$ で割ると $x = 2$ が得られます。確かめ：$2 \times 2 + 3 = 7$ ✓

$2x + 3 = 7$ と $2x = 7 - 3$ を見比べると、左辺の $+3$ が、符号を変えて右辺に $-3$ として移ったように見えます。このように、一方の辺の項を符号を変えて他方の辺に移すことを**移項**といいます。移項で符号が変わるのは、移項が「両辺から同じ項を引く」または「両辺に同じ項を足す」という操作を言い換えたものだからです。

両辺から同じ $x$ の項を引いても等式は成り立つので、未知数 $x$ が両辺に現れる場合も、$x$ の項を移項して片方の辺に集めれば同様に解けます。

$$3x + 2 = x + 8$$

右辺の $x$ を左辺に移項すると符号が変わって $-x$ になるので、$3x - x + 2 = 8$ です。左辺を整理すると $2x + 2 = 8$ になります。次に左辺の $+2$ を右辺に移項すると、$2x = 8 - 2 = 6$ です。両辺を2で割ると $x = 3$。確かめ：左辺は $3 \times 3 + 2 = 11$、右辺は $3 + 8 = 11$ で、両辺とも $11$ ✓

一般に $ax + b = c$（$a \neq 0$）を解いてみます。具体例と同様に、両辺から $b$ を引くと $ax = c - b$ となり、両辺を $a$ で割ると $x = \dfrac{c - b}{a}$ が得られます。

一次方程式の定義に $a \neq 0$ という条件を入れているのは、整理したあとに $x$ の項を残すためです。$a = 0$ だと $ax$ は $0$ になり、$x$ の項が消えてしまいます。たとえば $2x + 1 = 2x + 3$ は、右辺の $2x$ を左辺に移項すると $x$ の項が消えるので、一次方程式ではありません。$a \neq 0$ なので、最後に両辺を $a$ で割ることができます。この条件があるので、一次方程式の解は $x = \dfrac{c - b}{a}$ のただ $1$ つに決まります。

## 比例式

$a:b = c:d$ のように、比が等しいことを表す式を**比例式**といいます。このとき両端の $a,d$ を**外項**、内側の $b,c$ を**内項**といいます。比例式は「外項の積 $=$ 内項の積」という性質を使うと、方程式に直せます。

$$a:b = c:d \implies ad = bc$$

比 $a:b$ の比の値は $a \div b = \dfrac{a}{b}$、比 $c:d$ の比の値は $\dfrac{c}{d}$ です。等しい比どうしは比の値も等しいので、$a:b = c:d$ ならば $\dfrac{a}{b} = \dfrac{c}{d}$ が成り立ちます。この両辺に $bd$ をかけると、左辺は $\dfrac{a}{b} \times bd = ad$（$b$が約分される）、右辺は $\dfrac{c}{d} \times bd = bc$（$d$が約分される）となるので、$ad = bc$ が得られます。

**例題**：$x : 6 = 2 : 3$ を満たす $x$ を求める。外項どうしの積は $x \times 3 = 3x$、内項どうしの積は $6 \times 2 = 12$。これらが等しいので $3x = 12$、よって $x = 4$。確かめ：元の比例式に $x = 4$ を代入すると $4 : 6 = 2 : 3$ です。$4 : 6$ の両方の数を $2$ で割ると $2 : 3$ になるので、等しい比です ✓

---

## まとめ

一次方程式は、項を符号を変えて他方の辺に移したり（移項）、両辺を同じ $0$ でない数で割ったりして、$x$ だけを残すことで解けます。4つの項のうち1つだけが未知数 $x$ である比例式は、「外項の積 $=$ 内項の積」を使って $x$ についての一次方程式に直して解けます（$x : 6 = 2 : 3$ なら $3x = 12$）。
