## 一次方程式を解く

両辺を整理すると $ax + b = c$（$a$、$b$、$c$ は数で、$a \neq 0$）の形になる方程式を**一次方程式**といいます。ここで「整理する」とは、未知数 $x$ を含む項を片方の辺に集め、同類項をまとめることです（集め方はこのあと説明します）。整理したあとの未知数の項が $ax$ のように $x$ を1回だけ掛けた形なので、「一次」と呼びます。

たとえば $3x + 2 = x + 8$ は、$x$ の項を左辺に集めると $2x + 2 = 8$ となるので一次方程式です。一方、$x^2 + 1 = 5$ は整理しても $x^2$（$x$ を2回掛けた項）が残るので、一次方程式ではありません。見かけ上 $x^2$ を含んでいても、$x^2 + x = x^2 + 3$ のように整理すると $x^2$ が消えて $x = 3$ になる方程式は一次方程式です。

$$2x + 3 = 7$$

両辺から3を引くと、左辺は $2x + 3 - 3 = 2x$、右辺は $7 - 3$ になるので、$2x = 7 - 3 = 4$ です。$2x = 4$ の両辺を2で割ると $x = 2$ が得られます。（見かけ上、左辺の $+3$ が右辺に移って符号が反転し $-3$ になったのと同じです。このように、一方の辺の項を符号を変えて他方の辺に移すことを**移項**といいます。）確かめ：$2 \times 2 + 3 = 7$ ✓

未知数 $x$ が両辺に現れる場合も、移項を使って $x$ の項をすべて片方の辺に集めれば同様に解けます。

$$3x + 2 = x + 8$$

右辺の $x$ を左辺に移項すると符号が変わって $-x$ になるので、$3x - x + 2 = 8$ です。左辺を整理すると $2x + 2 = 8$ になります。次に左辺の $+2$ を右辺に移項すると、$2x = 8 - 2 = 6$ です。両辺を2で割ると $x = 3$。確かめ：左辺は $3 \times 3 + 2 = 11$、右辺は $3 + 8 = 11$ で、両辺とも $11$ ✓

一般に $ax + b = c$（$a \neq 0$）を解いてみます。具体例と同様に、両辺から $b$ を引くと $ax = c - b$ となり、両辺を $a$ で割ると $x = \dfrac{c - b}{a}$ が得られます。

最後に両辺を$a$で割るので、$a=0$だと割ることができません。

実際、$a=0$ を代入すると $0 \times x + b = c$、つまり $b = c$ となり、$x$ を含まない定数どうしの等式になってしまいます。このとき、$b=c$ であれば、どんな $x$ を代入しても成り立つため解が定まりません。これを**不定**といいます。一方、$b \neq c$ であれば、成り立つ $x$ が存在しません。これを**解なし**といいます。

## 比例式

$a:b = c:d$ のように、比が等しいことを表す式を**比例式**といいます。このとき両端の $a,d$ を**外項**、内側の $b,c$ を**内項**といいます。比例式は「外項の積 $=$ 内項の積」という性質を使うと、方程式に直せます。

$$a:b = c:d \implies ad = bc$$

これは、比 $a:b$、$c:d$ をそれぞれ分数 $\dfrac{a}{b}$、$\dfrac{c}{d}$ とみて、$\dfrac{a}{b} = \dfrac{c}{d}$ の両辺に $bd$ をかけると得られます。左辺は $\dfrac{a}{b} \times bd = ad$（$b$が約分される）、右辺は $\dfrac{c}{d} \times bd = bc$（$d$が約分される）となるので、$ad = bc$ が得られます。

**例題**：$x : 6 = 2 : 3$ を満たす $x$ を求める。外項どうしの積は $x \times 3 = 3x$、内項どうしの積は $6 \times 2 = 12$。これらが等しいので $3x = 12$、よって $x = 4$。確かめ：外項の積 $4 \times 3 = 12$、内項の積 $6 \times 2 = 12$ で一致 ✓

---

## まとめ

一次方程式は、同じ項を移したり（＝移項したり）、両辺を同じ数で割ったりして $x$ だけを残すことで解けます。比例式 $a:b=c:d$ は $ad=bc$ という一次方程式に直して解けます。
