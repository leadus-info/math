## 展開——括弧を外す

括弧同士の掛け算は、一方の括弧を1つの数のように見て分配法則を使うと計算できます。

$$(x + 2)(x + 3) = x(x+3) + 2(x+3) = x^2 + 3x + 2x + 6 = x^2 + 5x + 6$$

括弧の中の各項どうしをすべて掛け合わせて足す、と考えても同じ結果になります。

---

## 乗法公式

よく使う展開の形は、公式として覚えておくと計算が速くなります。

$$(a + b)^2 = a^2 + 2ab + b^2$$
$$(a - b)^2 = a^2 - 2ab + b^2$$
$$(a + b)(a - b) = a^2 - b^2$$
$$(x + a)(x + b) = x^2 + (a+b)x + ab$$

**例**：$(x+3)^2 = x^2 + 6x + 9$、$(x-2)(x+2) = x^2 - 4$、$(x+2)(x+5) = x^2 + 7x + 10$

$x$ の係数が1でない場合も、同じ考え方で展開できます。

$$(ax + b)(cx + d) = acx^2 + (ad+bc)x + bd$$

**例**：$(2x+1)(3x+4) = 6x^2 + 8x + 3x + 4 = 6x^2 + 11x + 4$

## 因数分解——掛け算の形に戻す

展開の逆を**因数分解**といいます。

$$x^2 + 5x + 6 = (x + 2)(x + 3)$$

展開すると左辺に戻ることを確認してみてください。展開と因数分解は、同じ式の「別の見た目」です。場面に応じて使いやすい形に変えます。

### 共通因数のくくり出し

各項に共通する因数を先に外します。

$$6x^2 + 9x = 3x(2x + 3)$$

### 和と積による分解

$x^2 + 5x + 6$ を因数分解するには、乗法公式 $(x+a)(x+b) = x^2+(a+b)x+ab$ の逆を使い、「足して5、掛けて6になる2数」を探します。$2 + 3 = 5$、$2 \times 3 = 6$ なので、

$$x^2 + 5x + 6 = (x + 2)(x + 3)$$

### 乗法公式の逆利用

他の乗法公式も、逆向きに使えば因数分解になります。

$$x^2 - 9 = x^2 - 3^2 = (x + 3)(x - 3)$$
$$x^2 + 6x + 9 = (x+3)^2$$

---

## 因数分解の活用

乗法公式を使うと、複雑に見える数の計算も簡単になることがあります。

**例**：$101^2$ を計算する。$101 = 100+1$ とみて $(a+b)^2$ の公式を使うと、

$$101^2 = (100+1)^2 = 100^2 + 2\times100\times1 + 1^2 = 10000+200+1 = 10201$$

**例**：$13^2 - 12^2$ を計算する。$(a+b)(a-b)$ の公式を使うと、

$$13^2 - 12^2 = (13+12)(13-12) = 25 \times 1 = 25$$

---

## まとめ

展開は括弧を外して単項式の和にする操作、因数分解はその逆で掛け算の形に戻す操作です。4つの乗法公式を覚えておくと、展開・因数分解のどちらも素早く計算でき、工夫した数の計算にも活用できます。
