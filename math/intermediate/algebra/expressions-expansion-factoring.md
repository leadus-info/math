## 展開——括弧を外す

括弧同士の掛け算は、一方の括弧を1つの数のように見て分配法則を使うと計算できます。

$$(x + 2)(x + 3) = x(x+3) + 2(x+3) = x^2 + 3x + 2x + 6 = x^2 + 5x + 6$$

括弧の中の各項どうしをすべて掛け合わせて足す、と考えても同じ結果になります。

---

## 乗法公式

よく使う展開の形は、公式として覚えておくと計算が速くなります。次の公式は、どれも「展開——括弧を外す」節の $(x+2)(x+3)$ と同じように、分配法則で展開すると得られます。各行の最後の式が公式です。

$$(a + b)^2 = (a + b)(a + b) = a(a+b) + b(a+b) = a^2 + ab + ab + b^2 = a^2 + 2ab + b^2$$
$$(a - b)^2 = (a - b)(a - b) = a(a-b) - b(a-b) = a^2 - ab - ab + b^2 = a^2 - 2ab + b^2$$
$$(a + b)(a - b) = a(a-b) + b(a-b) = a^2 - ab + ab - b^2 = a^2 - b^2$$
$$(x + a)(x + b) = x(x+b) + a(x+b) = x^2 + bx + ax + ab = x^2 + (a+b)x + ab$$

$(a+b)^2$ では $ab$ が、$(a-b)^2$ では $-ab$ が $2$ 回出てくるので、真ん中の項がそれぞれ $2ab$、$-2ab$ になります。$(a+b)(a-b)$ では $-ab$ と $+ab$ が打ち消し合うので、$ab$ の項が残りません。$(x+a)(x+b)$ は、「展開——括弧を外す」節の $(x+2)(x+3)$ の $2$ と $3$ を、$a$ と $b$ に置き換えたものです。

**例**：$(x+3)^2 = x^2 + 6x + 9$、$(x-3)^2 = x^2 - 6x + 9$、$(x-2)(x+2) = x^2 - 4$、$(x+2)(x+5) = x^2 + 7x + 10$

$x$ の係数が1でない場合も、同じ考え方で展開できます。

$$(ax + b)(cx + d) = acx^2 + (ad+bc)x + bd$$

**例**：$(2x+1)(3x+4) = 6x^2 + 8x + 3x + 4 = 6x^2 + 11x + 4$

## 因数分解——掛け算の形に戻す

多項式をいくつかの式の積の形に表すことを**因数分解**といいます。積をつくっている1つ1つの式を、もとの式の**因数**といいます。因数分解は、展開の逆の操作です。

$$x^2 + 5x + 6 = (x + 2)(x + 3)$$

この式では、$x+2$ と $x+3$ が $x^2+5x+6$ の因数です。右辺を展開すると左辺に戻ることを確認してみてください。展開と因数分解は、同じ式の「別の見た目」です。場面に応じて使いやすい形に変えます。

### 共通因数のくくり出し

各項に共通する因数を**共通因数**といいます。共通因数があれば、まず括弧の外にくくり出します。

$6x^2 + 9x$ では、数の部分 $6$ と $9$ の両方を割り切る最も大きい数は $3$ です。文字の部分では、どちらの項にも $x$ が含まれています。この $3$ と $x$ を合わせた $3x$ が、くくり出す共通因数です。

$$6x^2 + 9x = 3x \times 2x + 3x \times 3 = 3x(2x + 3)$$

$3$ だけをくくり出すと $3(2x^2+3x)$ になります。しかし、括弧の中の $2x^2$ と $3x$ には、まだ共通因数 $x$ が残っているので、これは途中の形です。共通因数は、数の部分も文字の部分もすべて、できるだけ大きくくくり出します。括弧の中に共通因数が残らなくなれば完成です。

### 和と積による分解

$x^2 + 5x + 6$ を因数分解するには、乗法公式 $(x+a)(x+b) = x^2+(a+b)x+ab$ を逆向きに使います。$x^2 + 5x + 6$ と公式の右辺を、上下に並べて見比べます。

$$
\begin{aligned}
x^2 &+ 5x + 6 \\
x^2 &+ (a+b)x + ab
\end{aligned}
$$

$x$ の係数 $5$ は、$a+b$ に当たります。定数項 $6$ は、$ab$ に当たります。したがって、「足して $5$、掛けて $6$ になる2数」を $a$ と $b$ として見つければ、因数分解できます。

2数を見つけるには、まず掛けて $6$ になる整数の組を書き出します。$1$ と $6$、$2$ と $3$、$-1$ と $-6$、$-2$ と $-3$ の $4$ 組です。次に、その中から足して $5$ になる組を選びます。$2 + 3 = 5$ なので、$2$ と $3$ の組です。

$$x^2 + 5x + 6 = (x + 2)(x + 3)$$

書き出す組は、和と積の符号を使って絞り込めます。積が正の場合、2数は同符号です。このとき、和が正なら2数とも正、和が負なら2数とも負です。積が負の場合、2数は異符号です。このとき、和が正なら符号を除いた大きさが大きいほうが正、和が負なら符号を除いた大きさが大きいほうが負です。

たとえば $x^2 - 5x + 6$ は「足して$-5$、掛けて$6$になる2数」を探すので、積が正・和が負より2数とも負と分かり、$(-2) + (-3) = -5$、$(-2) \times (-3) = 6$ から

$$x^2 - 5x + 6 = (x - 2)(x - 3)$$

また $x^2 + x - 6$ は、「足して $1$、掛けて $-6$ になる2数」を探します。積が負なので、2数は異符号です。和が正なので、符号を除いた大きさが大きいほうが正です。したがって、候補は $6$ と $-1$、$3$ と $-2$ の $2$ 組に絞られます。このうち足して $1$ になるのは $3$ と $-2$ です。$3 + (-2) = 1$、$3 \times (-2) = -6$ なので、

$$x^2 + x - 6 = (x + 3)(x - 2)$$

### 乗法公式の逆利用

他の乗法公式も、逆向きに使えば因数分解になります。

$$x^2 - 9 = x^2 - 3^2 = (x + 3)(x - 3)$$
$$x^2 + 6x + 9 = x^2 + 2 \times 3 \times x + 3^2 = (x+3)^2$$
$$x^2 - 6x + 9 = x^2 - 2 \times 3 \times x + 3^2 = (x-3)^2$$

## 乗法公式の活用

乗法公式を使うと、複雑に見える数の計算も簡単になることがあります。

**例**：$101^2$ を計算する。$101 = 100+1$ とみて $(a+b)^2$ の公式を使うと、

$$101^2 = (100+1)^2 = 100^2 + 2\times100\times1 + 1^2 = 10000+200+1 = 10201$$

**例**：$13^2 - 12^2$ を計算する。$(a+b)(a-b)$ の公式を使うと、

$$13^2 - 12^2 = (13+12)(13-12) = 25 \times 1 = 25$$

## まとめ

展開は括弧を外して単項式の和にする操作、因数分解はその逆で掛け算の形に戻す操作です。4つの乗法公式を覚えておくと、展開・因数分解のどちらも素早く計算でき、工夫した数の計算にも活用できます。
