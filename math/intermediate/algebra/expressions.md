## 文字を使うと便利なわけ

自然数（初級編）で、足し算や掛け算は順番を入れ替えても答えが同じであることを、具体的な数で確認しました。しかし、これはどんな数でも成り立ちます。いちいち $1+2=2+1$、$3+5=5+3$ と書き並べるのは大変です。

そこで、$x$ や $a$ のような**文字**を使います。文字は「どんな数でも入る箱」だと思ってください。文字を使うと、数量の関係や法則を一般的に表したり、決まった手順で計算したりできるようになります。

---

## 文字式の表し方

文字式では、いくつかの決まりに従って式を簡潔に書きます。

- 数と文字の掛け算は $\times$ を省略する：$2 \times x = 2x$
- 文字どうしの掛け算も $\times$ を省略する：$a \times b = ab$
- 同じ文字の掛け算はべき乗で書く：$x \times x = x^2$
- 数は文字の前に書く：$x \times 3 = 3x$

割り算は分数の形で書きます。

$$x \div 2 = \frac{x}{2}$$

---

## 項・係数・同類項

$3x + 2y - 5$ のように、文字式は $+$ や $-$ で区切られた部分（**項**）の集まりとして見ることができます。この式は $3x$、$2y$、$-5$ の3つの項からなります。文字にかけられている数を**係数**といい、$3x$ の係数は3です。

$3x + 2x$ は、$x$ が3つと $x$ が2つで、合わせて $x$ が5つです。

$$3x + 2x = 5x$$

$x$ と $y$ のように違う文字同士はまとめられません。

$$3x + 2y + x = 4x + 2y$$

このように、同じ文字を同じ次数だけ含む項（**同類項**）をまとめることが、文字式の計算の基本です。

---

## 一次式の加法・減法

$x$ を1つだけ含む項（$3x$ など）と数の項（定数項）だけでできた式を**一次式**といいます。一次式どうしの加法・減法は、同類項どうし・定数項どうしをまとめるだけで計算できます。

$$(2x + 3) + (x - 1) = (2x + x) + (3 - 1) = 3x + 2$$

引き算のときは、括弧の前が $-$ なら中の符号がすべて反転することに注意します。

$$(2x + 3) - (x - 1) = 2x + 3 - x + 1 = x + 4$$

---

## まとめ

文字式は数と同じ規則（$\times$ の省略、べき乗の表記）で書き表します。同じ文字の項（同類項）をまとめることで、一次式の加法・減法ができるようになります。
