## 文字を使うと便利なわけ

足し算や掛け算は、順番を入れ替えても答えが同じです（交換法則）。たとえば $1+2=2+1$、$3+5=5+3$、$2 \times 3 = 3 \times 2$ のように、これはどんな数の組み合わせでも成り立ちます。しかし、そのたびに具体的な数を使って確かめるのは大変です。

そこで、$x$ や $a$ のような**文字**を使います。文字は「どんな数でも入る箱」だと思ってください。文字を使うと、数量の関係や法則を一般的に表したり、決まった手順で計算したりできるようになります。

---

## 文字式の表し方

文字式では、いくつかの決まりに従って式を簡潔に書きます。

- 数と文字の掛け算は $\times$ を省略する：$2 \times x = 2x$
- 文字どうしの掛け算も $\times$ を省略する：$a \times b = ab$
- 同じ文字の掛け算はべき乗で書く：$x \times x = x^2$
- 数は文字の前に書く：$x \times 3 = 3x$

割り算は分数の形で書きます。

$$x \div 2 = \frac{x}{2}$$

## 項・係数・同類項

$3x + 2y - 5$ のように、文字式は $+$ や $-$ で区切られた部分（**項**）の集まりとして見ることができます。この式は $3x$、$2y$、$-5$ の3つの項からなります。文字にかけられている数を**係数**といい、$3x$ の係数は3です。$x$ のように文字だけの項は、係数が1の項（$1 \times x$ の1を省略した形）です。

$3x + 2x$ は、$x$ が3つと $x$ が2つで、合わせて $x$ が5つです。

$$3x + 2x = 5x$$

一方、$x$ と $y$ は別々の値を表す文字なので、りんごとみかんのように種類の異なるものとして扱われ、まとめられません。

$$3x + 2y + x = 4x + 2y$$

$3x + 2y + x$ の $x$ は係数1の項なので、$3x$ と合わせて $4x$ になります。このように、文字の部分（掛けられている文字とその個数）が同じ項（**同類項**）をまとめることが、文字式の計算の基本です。

---

## 一次式の加法・減法

1種類の文字が1つだけ掛けられた項（他の文字は掛けられていない。$3x$、$2y$ など。$x^2$ のように同じ文字が2つ以上掛けられた項や、$ab$ のように異なる文字どうしの積を含む項は含みません）と数の項（定数項）だけでできた式を**一次式**といいます。$3x + 2y - 5$ のように、複数の文字を含む式もこれに含まれます。一次式どうしの加法・減法は、同類項どうし・定数項どうしをまとめるだけで計算できます。

$$(2x + 3) + (x - 1) = (2x + x) + (3 - 1) = 3x + 2$$

引き算のときは、括弧の前が $-$ なら中の符号がすべて反転することに注意します。

これは、括弧の前の $-$ を「$-1$を掛ける」と考えると説明できます。括弧の中のすべての項に同じ数を掛けて計算できるという規則を**分配法則**といい、たとえば $a \times (b + c) = a \times b + a \times c$ が成り立ちます。引き算は $x - 1 = x + (-1)$ のように「$+ (-\ )$」の形に直せるので、この法則がそのまま使えます。この分配法則を使うと、$-1 \times (x-1) = -x + 1$ のように、括弧の中それぞれに$-1$が掛かることがわかります。だから、括弧を外すと中の符号がすべて反転するのです。

$$(2x + 3) - (x - 1) = 2x + 3 - x + 1 = x + 4$$

---

## まとめ

文字式は数と同じ規則（$\times$ の省略、べき乗の表記）で書き表します。文字の部分（掛けられている文字とその個数）が同じ項（同類項）をまとめることで、一次式の加法・減法ができるようになります。
