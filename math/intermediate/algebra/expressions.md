## 文字を使うと便利なわけ

自然数（初級編）で、足し算や掛け算は順番を入れ替えても答えが同じであることを、具体的な数で確認しました。しかし、これはどんな数でも成り立ちます。いちいち $1+2=2+1$、$3+5=5+3$ と書き並べるのは大変です。

そこで、$x$ や $a$ のような**文字**を使います。文字は「どんな数でも入る箱」だと思ってください。文字を使うと、式を計算したり形を変えたりできるようになります。

---

## 同類項をまとめる

$3x + 2x$ は、$x$ が3つと $x$ が2つで、合わせて $x$ が5つです。

$$3x + 2x = 5x$$

$x$ と $y$ のように違う文字同士はまとめられません。

$$3x + 2y + x = 4x + 2y$$

このように、同じ文字を含む項（**同類項**）をまとめることが、文字式の計算の基本です。

文字式では、数と文字の掛け算から $\times$ を省略して書きます。同じ文字の掛け算はべき乗で書きます。

$$2 \times x = 2x, \quad a \times b = ab, \quad x \times x = x^2$$

---

## 展開——括弧を外す

括弧の前の数を、括弧の中の各項に配ることを**展開**といいます。

$$3(x + 2) = 3x + 6$$

括弧同士の掛け算も同じ考え方で計算します。

$$(x + 2)(x + 3) = x^2 + 3x + 2x + 6 = x^2 + 5x + 6$$

よく使う展開の結果は公式として覚えておくと便利です。

$$(a + b)^2 = a^2 + 2ab + b^2$$
$$(a - b)^2 = a^2 - 2ab + b^2$$
$$(a + b)(a - b) = a^2 - b^2$$

**例**：$(x+3)^2 = x^2 + 6x + 9$、$(x-2)(x+2) = x^2 - 4$

---

## 因数分解——掛け算の形に戻す

展開の逆を**因数分解**といいます。

$$x^2 + 5x + 6 = (x + 2)(x + 3)$$

展開すると左辺に戻ることを確認してみてください。展開と因数分解は、同じ式の「別の見た目」です。場面に応じて使いやすい形に変えます。

### 共通因数のくくり出し

各項に共通する因数を先に外します。

$$6x^2 + 9x = 3x(2x + 3)$$

### 和と積による分解

$x^2 + 5x + 6$ を因数分解するには、「足して5、掛けて6になる2数」を探します。$2 + 3 = 5$、$2 \times 3 = 6$ なので、

$$x^2 + 5x + 6 = (x + 2)(x + 3)$$

### 展開公式の逆利用

$$x^2 - 9 = x^2 - 3^2 = (x + 3)(x - 3)$$

---

## まとめ

文字式の計算では、同類項をまとめる、分配法則で括弧を外す（展開）、掛け算の形に戻す（因数分解）が基本操作です。これらは方程式を解くときや、関数の性質を調べるときに繰り返し使います。
