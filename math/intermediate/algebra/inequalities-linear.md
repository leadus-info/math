## 一次不等式を解く

一次不等式とは、未知数（$x$など）が1次である不等式のことです。一次方程式と同じ手順で解けますが、負の数で割るとき、向きが逆転する点に注意します。

**例題**：$-2x + 1 > 5$ を解く。

両辺から $1$ を引くと $-2x > 4$ です。両辺から同じ数を引いても、不等号の向きは変わりません。次に両辺を負の数 $-2$ で割ると、不等号の向きが逆転して $x < -2$ です。

一方、係数が正の場合は向きが逆転しません。

**例題**：$2x + 1 > 5$ を解く。

両辺から $1$ を引くと $2x > 4$ です。両辺を正の数 $2$ で割ると、向きはそのまま $x > 2$ です。

$x$ が両辺にある場合も、$x$ の項を一方の辺に集めてから同じように解きます。

**例題**：$3x + 2 \geq 5x - 4$ を解く。

$$
\begin{aligned}
3x + 2 &\geq 5x - 4 \\
-2x + 2 &\geq -4 && (\text{両辺から } 5x \text{ を引く}) \\
-2x &\geq -6 && (\text{両辺から } 2 \text{ を引く}) \\
x &\leq 3 && (\text{両辺を負の数 } -2 \text{ で割る})
\end{aligned}
$$

最後の段では負の数で割ったので、不等号の向きが逆転して $\geq$ が $\leq$ になります。

不等式の解は、数直線上でその範囲を図示すると分かりやすくなります。1つ目の例題の解 $x < -2$ と2つ目の例題の解 $x > 2$ は、それぞれ別の問題の答えなので、別々の数直線で図示します。

**例1の解**（$x < -2$）：$-2$ より左側全体を表します。

```
         -2
←════════o----------------------→
```

**例2の解**（$x > 2$）：$2$ より右側全体を表します。

```
                       2
←----------------------o════════→
```

---

## まとめ

一次不等式は一次方程式と同じ手順で解きますが、負の数を掛けたり負の数で割ったりする操作をする際は、不等号の向きが逆転することに注意が必要です。
