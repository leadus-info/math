## 対頂角

2本の直線が1点で交わると、4つの角ができます。向かい合う2つの角を**対頂角**といいます。

1直線上に並ぶ2つの角の和は $180°$ になります。この性質を使うと、対頂角はいつでも等しくなることがわかります。片方の角を $a$ とすると、それと隣り合う右側の角は $180° - a$ です。さらに、この隣り合う角 $180° - a$ ととなり合う角（$a$ の対頂角にあたります）は $180° - (180° - a) = a$ となり、もとの $a$ と等しくなります。同様に、この $a$ の対頂角（下側の角）ととなり合う左側の角を考えると、1直線上に並ぶ角の性質から、左側の角は $180° - a$ です。これは先に求めた右側の角 $180° - a$ と一致しており、向かい合う右側と左側の角も互いに等しい（対頂角の関係にある）ことが確かめられます。

![2本の直線が1点Oで交わってできる4つの角の図。上側の角をaとする。aと隣り合う右側の角は180°-a。aの真下、交点を挟んでaと向かい合う位置(対頂角の位置)にある角をaの対頂角とする。残る左側の角は、180°-aと交点を挟んで向かい合う位置にあり、180°-aとする。](angles/images/vertical-angles.svg)

> 図で $a = 65°$ のとき、$a$ ととなり合う角、$a$ の対頂角はそれぞれ何度でしょうか。
>
> 隣り合う角は $180° - 65° = 115°$、$a$ の対頂角は $a$ と等しいので $65°$ です。

## 同位角と錯角

2本の平行な直線に、別の1本の直線（**横断線**）が交わるとき、8つの角ができます。

![平行な2直線に1本の横断線が交わり、上下2つの交点にできる合計8つの角の図。上の交点にできる4つの角を時計回りに角1(左上)、角2(右上)、角3(右下)、角4(左下)とし、下の交点にできる4つの角も同様に角5(左上)、角6(右上)、角7(右下)、角8(左下)とする。角1・角3・角5・角7(番号が奇数)は鋭角で1本線の印、角2・角4・角6・角8(番号が偶数)は鈍角で2本線の印が付いている。](angles/images/corresponding-alternate-angles.svg)

図のように、平行な2直線の同じ位置にある角どうし（角1と角5、角2と角6、角3と角7、角4と角8）を**同位角**、平行線の内側で互い違いの位置にある角どうし（角3と角5、角4と角6）を**錯角**といいます。

**同位角の性質**：2直線が平行ならば、同位角は等しくなります。この性質は、「同じ向きにまっすぐ伸び、決して交わらない」という平行線の意味そのものから直観的・実験的に確認できるものであり、本記事ではこれ以上さかのぼって証明せず、他の性質を導くための前提として認めます。逆に、同位角が等しければ2直線は平行である、ということも成り立ちます。

**錯角の性質**：錯角は対頂角の関係にある同位角なので、同位角の性質と対頂角の性質を組み合わせると、平行な2直線の錯角も等しいことが導けます。たとえば図の角4と角6は、角2の対頂角が角4であり（対頂角の性質）、角2と角6が同位角で等しいことから、角4 = 角2 = 角6となり、錯角である角4と角6も等しいことがわかります。錯角についても逆が成り立ちます——錯角が等しければ2直線は平行です。

> 図で角2 $= 118°$ のとき、角1・角3・角5・角6はそれぞれ何度でしょうか。
>
> - 角1：角2ととなり合い1直線上にあるので $180° - 118° = 62°$（1直線上の角の性質）
> - 角3：角1の対頂角なので $62°$（対頂角の性質）
> - 角6：角2の同位角なので $118°$（同位角の性質）
> - 角5：角1の同位角なので $62°$（同位角の性質）
>
> 実際、角3と角5はどちらも $62°$ で、錯角として一致していることが確認できます。

## 三角形の内角の和が180度であることの証明

三角形の内角の和が180度であることは、実際に3つの角を切り取って並べると1直線になることから、経験的に確かめられます。しかしこれを、対頂角・同位角・錯角の性質を根拠にして、論理的に証明してみましょう。

三角形 $ABC$ の頂点 $A$ を通り、辺 $BC$ に平行な直線を引きます。

![頂点Aを通り辺BCに平行な直線を引き、頂点Aにできる3つの角のうちBに近い側の角(単一の印)が角Bの錯角、Cに近い側の角(二重の印)が角Cの錯角にあたることから三角形の内角の和が180度になることを示す証明の図](angles/images/triangle-angle-sum-proof.svg)

このとき、頂点 $A$ にできる角のうち、両端の2つは、それぞれ角 $B$・角 $C$ の**錯角**にあたります。辺 $AB$ を延長した直線は、頂点 $A$ を通り辺 $BC$ に平行な直線と、辺 $BC$ の両方に交わるため、横断線の条件を満たします。同様に、辺 $AC$ を延長した直線も、この平行な直線と辺 $BC$ の両方に交わるため、横断線の条件を満たします。辺 $AB$ が横断線として働くため、$A$ の $B$ 寄りの角（単一の印）と角 $B$ が錯角の関係になり、同様に辺 $AC$ が横断線として働くため、$A$ の $C$ 寄りの角（二重の印）と角 $C$ が錯角の関係になります。錯角の性質から、これらは角 $B$、角 $C$ とそれぞれ等しくなります。

頂点 $A$ を通る直線上の3つの角（角 $B$ と等しい角、もとの角 $A$、角 $C$ と等しい角）を合わせると $180°$ の直線になるので、

$$\angle A + \angle B + \angle C = 180°$$

このように、経験的に正しそうだとわかっていることを、すでに認めた性質（ここでは錯角の性質）だけから筋道立てて示すことを**証明**といいます。

> 三角形の2つの内角が $\angle B = 50°$、$\angle C = 70°$ のとき、$\angle A$ は何度でしょうか。
>
> $\angle A = 180° - (50° + 70°) = 60°$ です。実際に頂点 $A$ を通り辺 $BC$ に平行な直線を引くと、その直線上にできる3つの角はそれぞれ $50°$・$60°$・$70°$ となり、合計が $180°$ になることが確認できます。

## 三角形の外角の性質

三角形の1つの辺を延長してできる角を、その頂点における**外角**といいます。外角ととなり合う内角は1直線上に並ぶので、1直線上に並ぶ角の性質から、合わせると $180°$ になります。したがって、

$$\angle A \text{の外角} = 180° - \angle A$$

一方、三角形の内角の和が $180°$ であることから、

$$\angle A + \angle B + \angle C = 180° \implies \angle B + \angle C = 180° - \angle A$$

この2つの式の右辺はどちらも $180° - \angle A$ で一致するので、

$$\angle A \text{の外角} = \angle B + \angle C$$

つまり、**三角形の外角は、それととなり合わない2つの内角の和に等しくなります**。この性質は、円周角の定理の証明でも使います。

> 内角の和の例で使った三角形（$\angle B = 50°$、$\angle C = 70°$、$\angle A = 60°$）で、頂点 $A$ の外角を求めてみましょう。
>
> 外角の性質から $\angle A \text{の外角} = 50° + 70° = 120°$。これは1直線上に並ぶ角の性質から求めた $180° - 60° = 120°$ と一致します。

---

## まとめ

対頂角は常に等しく、平行線にできる同位角も常に等しくなります。錯角の性質はこの2つから導けます。三角形の頂点を通る平行線を1本引き、錯角の性質を使うことで、「三角形の内角の和は180度」であることを証明できます。この内角の和の性質から、三角形の外角はとなり合わない2つの内角の和に等しいこともわかります。
