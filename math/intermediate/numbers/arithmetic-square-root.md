## 平方根——累乗の逆

「2乗すると9になる数は何か？」——$3^2 = 9$ なので3ですが、$(-3)^2 = 9$ でもあるので、$-3$ も当てはまります。このように、2乗して $a$ になる数を $a$ の**平方根**といい、0以上の数の平方根は正と負の2つ存在します（0の平方根は、正の方も負の方も0で一致するため1つだけです）。

> [!NOTE]
> 整数や分数だけでなく、それらだけでは表せない数も含めて**実数**と呼びます（詳しくは後述します）。負の数は2乗すると必ず0以上になるため、2乗して負の数になる実数は存在しません。つまり、負の数には実数の範囲での平方根はありません。

このうち、正の方（0以上の方）の平方根を $\sqrt{a}$ と書きます。負の方の平方根は $-\sqrt{a}$ です。つまり、9の平方根は $3$ と $-3$ の2つですが、$\sqrt{9}$ という記号は正の方の $3$ だけを指します。

$$\sqrt{9} = 3, \quad \sqrt{4} = 2, \quad \sqrt{25} = 5$$

$\sqrt{2}$ はどうでしょう。$1^2 = 1$、$2^2 = 4$ なので1と2の間のどこかにあります。電卓で計算すると $\sqrt{2} \approx 1.41421\ldots$ で、同じ並びが繰り返されないまま小数が延々と続きます。分数は必ず割り切れるか、同じ並びが繰り返される循環小数になりますが、$\sqrt{2}$ はそのどちらにも当てはまりません。つまり整数でも分数でもない数（無理数）です。

## 根号を含む式の計算

平方根には次の性質があります。

$$\sqrt{ab} = \sqrt{a} \times \sqrt{b}, \qquad \sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$$

これを使うと、根号の中を簡単にできます。

**例**：$\sqrt{12} = \sqrt{4 \times 3} = \sqrt{4} \times \sqrt{3} = 2\sqrt{3}$

根号を含む式の足し算・引き算は、根号の中の数が同じ項同士をまとめることで計算できます（文字式で同じ文字の項（同類項）をまとめて計算するのと同様です）。

$$3\sqrt{2} + 5\sqrt{2} = 8\sqrt{2}, \qquad 7\sqrt{5} - 2\sqrt{5} = 5\sqrt{5}$$

根号の中が異なっていても、簡単にすると同じ数になる場合があります。その場合は、先に根号の中を簡単にしてからまとめます。

**例**：$\sqrt{8} + \sqrt{2} = \sqrt{4 \times 2} + \sqrt{2} = 2\sqrt{2} + \sqrt{2} = 3\sqrt{2}$

分母に根号が残っていると計算しづらいので、分母と分子に同じ数を掛けて根号を分子に移します（**有理化**）。平方根の定義から、2乗すると元の数に戻る（$\sqrt{a} \times \sqrt{a} = a$）ことを使うと、次のように分母の根号を消せます。

$$\frac{1}{\sqrt{2}} = \frac{1 \times \sqrt{2}}{\sqrt{2} \times \sqrt{2}} = \frac{\sqrt{2}}{2}$$

**例題**：$\frac{\sqrt{18}}{\sqrt{2}}$ を計算する。

$$\frac{\sqrt{18}}{\sqrt{2}} = \sqrt{\frac{18}{2}} = \sqrt{9} = 3$$

---

## まとめ

平方根は2乗の逆操作で、0以上の数には正・負の2つの平方根があります。$\sqrt{a}$ はそのうち正の方（0以上の方）を指す記号です。$\sqrt{ab}=\sqrt{a}\sqrt{b}$ などの性質を使うと根号の中を簡単にでき、根号の中が同じ項同士は同類項としてまとめて足し算・引き算ができます。分母の根号は有理化して整理します。
