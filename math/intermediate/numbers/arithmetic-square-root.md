## 平方根——累乗の逆

「2乗すると9になる数は何か？」——$3^2 = 9$ なので3ですが、$(-3)^2 = 9$ でもあるので、$-3$ も当てはまります。このように、2乗して $a$ になる数を $a$ の**平方根**といいます。2乗して $0$ になる数は $0$ だけなので、$0$ の平方根は $0$ の $1$ つだけです。正の数の平方根は、正と負の $2$ つあります。

> [!NOTE]
> 整数や分数だけでは表せない数も含めて、数直線上の点で表される数を**実数**と呼びます。実数は、正の数・$0$・負の数のどれかです。正の数も負の数も、2乗すると正の数になります。$0$ を2乗すると $0$ です。どの場合も2乗した結果は $0$ 以上なので、2乗して負の数になる実数は存在しません。つまり、負の数には実数の範囲での平方根はありません。

このうち、正の方（0以上の方）の平方根を $\sqrt{a}$ と書きます。記号 $\sqrt{\ }$ を**根号**といいます。負の方の平方根は $-\sqrt{a}$ です。つまり、9の平方根は $3$ と $-3$ の2つですが、$\sqrt{9}$ という記号は正の方の $3$ だけを指します。

$$\sqrt{9} = 3, \quad \sqrt{4} = 2, \quad \sqrt{25} = 5$$

$\sqrt{2}$ はどうでしょう。$1^2 = 1$、$2^2 = 4$ なので1と2の間のどこかにあります。電卓で計算すると $1.41421\ldots$ と表示されます。実は、$\sqrt{2}$ の小数は同じ並びが繰り返されないまま限りなく続くことが分かっています。その理由は[無理数](irrational-numbers.md)で証明します。分数は必ず割り切れるか、同じ並びが繰り返される循環小数になりますが、$\sqrt{2}$ はそのどちらにも当てはまりません。つまり整数でも分数でもない数（無理数）であり、これは平方根を定義した直後に触れた、整数や分数だけでは表せない数に当たります。

## 根号を含む式の計算

平方根には、積と商について次の性質があります。ただし、$a \geq 0$、$b \geq 0$ とし、商の性質では $b > 0$ とします。

$$\sqrt{ab} = \sqrt{a} \times \sqrt{b}, \qquad \sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$$

積の性質が成り立つ理由は、次のとおりです。$\sqrt{a}$ と $\sqrt{b}$ はどちらも $0$ 以上なので、$\sqrt{a} \times \sqrt{b}$ も $0$ 以上です。また、$\sqrt{a}$ と $\sqrt{b}$ はそれぞれ2乗すると $a$、$b$ になる数なので、$\sqrt{a} \times \sqrt{b}$ を2乗すると次のように $ab$ になります。

$$(\sqrt{a} \times \sqrt{b})^2 = (\sqrt{a})^2 \times (\sqrt{b})^2 = a \times b$$

つまり、$\sqrt{a} \times \sqrt{b}$ は $ab$ の平方根のうち $0$ 以上の方なので、$\sqrt{ab}$ と等しくなります。商の性質も同じように確かめられます。

積の性質を使うと、根号の中を簡単にできます。根号の中の数が $4, 9, 16, 25, 36, \ldots$ のような整数の2乗で割り切れるか調べ、割り切れるもののうち最も大きいものを選んで、その平方根を根号の外に出します。根号の中の数が、$1$ より大きいどの整数の2乗でも割り切れなくなれば完成です。

**例**：$\sqrt{12} = \sqrt{4 \times 3} = \sqrt{4} \times \sqrt{3} = 2\sqrt{3}$

**例**：$\sqrt{72} = \sqrt{36 \times 2} = \sqrt{36} \times \sqrt{2} = 6\sqrt{2}$

積の性質 $\sqrt{a} \times \sqrt{b} = \sqrt{ab}$ を使うと、根号どうしの掛け算もできます。掛けた後は、根号の中を簡単にします。

**例**：$2\sqrt{3} \times \sqrt{6} = 2\sqrt{3 \times 6} = 2\sqrt{18} = 2\sqrt{9 \times 2} = 2 \times 3\sqrt{2} = 6\sqrt{2}$

根号を含む式の足し算・引き算は、根号の中の数が同じ項同士をまとめることで計算できます（文字式で文字の部分が同じ項（同類項）をまとめて計算するのと同様です）。

$$3\sqrt{2} + 5\sqrt{2} = 8\sqrt{2}, \qquad 7\sqrt{5} - 2\sqrt{5} = 5\sqrt{5}$$

ただし、根号の中が異なる項は、根号の中の数を足して $1$ つの根号にまとめることはできません。例えば $\sqrt{2}+\sqrt{3}$ は $\sqrt{5}$ になりません。根号を外せる数で比べると、次のように結果が違うことが分かります。

$$\sqrt{9}+\sqrt{16} = 3+4 = 7, \qquad \sqrt{9+16} = \sqrt{25} = 5$$

根号の中が異なっていても、簡単にすると同じ数になる場合があります。その場合は、先に根号の中を簡単にしてからまとめます。

**例**：$\sqrt{8} + \sqrt{2} = \sqrt{4 \times 2} + \sqrt{2} = 2\sqrt{2} + \sqrt{2} = 3\sqrt{2}$

根号を含む式の計算では、展開・因数分解で使った乗法公式もそのまま利用できます。$a$・$b$に根号を含む項を当てはめても、次の公式は同様に成り立ちます。

$$(a+b)^2 = a^2 + 2ab + b^2 \quad \text{（平方の公式）}$$
$$(a-b)^2 = a^2 - 2ab + b^2 \quad \text{（平方の公式）}$$
$$(a+b)(a-b) = a^2 - b^2 \quad \text{（和と差の積の公式）}$$

**例**：$(\sqrt{3}+1)^2 = (\sqrt{3})^2 + 2\sqrt{3} + 1^2 = 3 + 2\sqrt{3} + 1 = 4 + 2\sqrt{3}$

**例**：$(\sqrt{5}+\sqrt{2})(\sqrt{5}-\sqrt{2}) = (\sqrt{5})^2 - (\sqrt{2})^2 = 5 - 2 = 3$

こうした計算に加えて、分母に根号が残っていると計算しづらいので、分母と分子に同じ数を掛けて根号を分子に移します（**有理化**）。平方根の定義から、2乗すると元の数に戻る（$\sqrt{a} \times \sqrt{a} = a$）ことを使うと、次のように分母の根号を消せます。

$$\frac{1}{\sqrt{2}} = \frac{1 \times \sqrt{2}}{\sqrt{2} \times \sqrt{2}} = \frac{\sqrt{2}}{2}$$

分母が2項（$\sqrt{5}+\sqrt{2}$のような形）の場合は、上で見た和と差の積の公式を使って有理化できます。分母の2つの項の間の符号を、$+$ なら $-$ に、$-$ なら $+$ に変えた式を、分母と分子に掛けます。すると、$(a+b)(a-b) = a^2-b^2$ により分母の根号が消えます。

**例**：$\frac{1}{\sqrt{5}+\sqrt{2}} = \frac{\sqrt{5}-\sqrt{2}}{(\sqrt{5}+\sqrt{2})(\sqrt{5}-\sqrt{2})} = \frac{\sqrt{5}-\sqrt{2}}{3}$

**例題**：$\frac{\sqrt{18}}{\sqrt{2}}$ を計算する。

$$\frac{\sqrt{18}}{\sqrt{2}} = \sqrt{\frac{18}{2}} = \sqrt{9} = 3$$

## まとめ

平方根は2乗の逆操作です。$0$ の平方根は $0$ だけです。正の数には正・負の $2$ つの平方根があります。$\sqrt{a}$ はそのうち正の方（0以上の方）を指す記号です。$\sqrt{ab}=\sqrt{a}\sqrt{b}$ などの性質を使うと根号の中を簡単にでき、乗法公式は根号を含む式にもそのまま適用できます。根号の中が同じ項同士は同類項としてまとめて足し算・引き算ができます。分母の根号は有理化して整理します。
