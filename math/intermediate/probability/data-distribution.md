## ヒストグラム

データの活用で、数値を階級に区切って度数をまとめる度数分布表を見ました。この度数分布表を、階級の幅を柱の幅、度数を柱の高さとした棒グラフのような図で表したものを**ヒストグラム**といいます。

ヒストグラムにすると、次のような特徴が一目で読み取れます。

- データ全体がどのあたりに集まっているか
- 山が1つか複数か
- 左右対称かどうか
- 極端に離れた値（**外れ値**）があるかどうか

階級の幅を変えると、同じデータでも見え方が変わります。例えば幅を狭くしすぎると柱が細かくなりすぎて全体の形がつかみにくくなり、広くしすぎると細かい特徴が失われます。複数の幅でヒストグラムを作って比べてみることが大切です。

**例**：30人のテストの点数（0〜100点）が次の通りだったとします。

```
8, 12, 18, 22, 25, 29, 31, 34, 36, 39,
40, 42, 43, 45, 46, 48, 49, 51, 55, 58,
60, 62, 64, 65, 67, 69, 72, 78, 85, 95
```

このデータを、階級の幅10点で度数分布表にまとめると次のようになります。

| 階級 | 度数 |
|---|---|
| 0以上10未満 | 1 |
| 10以上20未満 | 2 |
| 20以上30未満 | 3 |
| 30以上40未満 | 4 |
| 40以上50未満 | 7 |
| 50以上60未満 | 3 |
| 60以上70未満 | 6 |
| 70以上80未満 | 2 |
| 80以上90未満 | 1 |
| 90以上100未満 | 1 |
| 合計 | 30 |

度数は1, 2, 3, 4, 7, 3, 6, 2, 1, 1と並びます。40点台（7人）と60点台（6人）にそれぞれ山ができ、間の50点台は3人と少なくへこんでいます。全体として「山が2つ」の形に見えます。

![階級の幅10点のヒストグラム](data-distribution/images/histogram-bin-width-10.svg)

同じデータを、階級の幅20点でまとめ直すと次のようになります。

| 階級 | 度数 |
|---|---|
| 0以上20未満 | 3 |
| 20以上40未満 | 7 |
| 40以上60未満 | 10 |
| 60以上80未満 | 8 |
| 80以上100未満 | 2 |
| 合計 | 30 |

度数は3, 7, 10, 8, 2と並び、今度は増えてから減る「山が1つ」の形になります。

![階級の幅20点のヒストグラム](data-distribution/images/histogram-bin-width-20.svg)

同じ30人のデータなのに、階級の幅を10点から20点に変えただけで「山が2つ」から「山が1つ」へと読み取れる特徴が変わってしまいました。ヒストグラムから分布の特徴を読み取るときは、1つの幅だけを見て結論を出さないようにしましょう。複数の幅で作り直して見え方が変わらないかを確かめましょう。そのうえで、結論が妥当かどうかを批判的に考察する姿勢が欠かせません。

## 相対度数

集団の大きさが異なるデータどうしを比べたいとき、度数（個数）そのものを比べても正しく比較できません。度数全体に対する割合を**相対度数**といいます。

$$\text{相対度数} = \frac{\text{その階級の度数}}{\text{度数の合計}}$$

**例**：通学時間が「20分以上30分未満」の階級について、クラスAとクラスBを比較します。

- クラスA（40人）：この階級に8人。相対度数は $8 \div 40 = 0.2$
- クラスB（20人）：この階級に5人。相対度数は $5 \div 20 = 0.25$

度数だけならAの8人がBの5人より多いですが、相対度数で比べるとBの方がこの階級の割合が高いとわかります。

なお、各階級の度数をすべて合計すると、度数の合計（全体の人数）に一致します。したがって、例えばクラスA全体で見ると、すべての階級の相対度数を合計すると必ず1になります（クラスBも同様）。

## 累積度数・累積相対度数

**累積度数**とは、最も小さい階級から、ある階級までの度数を合計したものです。**累積相対度数**とは、最も小さい階級から、ある階級までの相対度数を合計したものです。「ある値以下のデータが全体のどれくらいか」を知りたいときに使います。

**例**：あるクラス（合計40人）の通学時間の内訳は、次の通りです。

- 「0分以上10分未満」：5人
- 「10分以上20分未満」：12人
- 「20分以上30分未満」：8人

このとき、「20分未満」に含まれるのは「0分以上10分未満」と「10分以上20分未満」の2階級で、「20分以上30分未満」の階級は含まれません。したがって累積度数は $5+12=17$ 人、累積相対度数は $17\div40=0.425$ です。

## 範囲

データの中の最大値と最小値の差を**範囲**といい、データの散らばりの大きさをおおまかにとらえる指標です。

$$\text{範囲} = \text{最大値} - \text{最小値}$$

**例**：5人のテストの点数が$60,75,90,55,80$のとき、最大値は$90$、最小値は$55$なので、範囲は $90-55=35$。

範囲は多数のデータを平均するのではなく、最大値・最小値という2つの極端な値だけで決まります。外れ値は極端に離れた値であるため、そのまま最大値や最小値になりやすく、範囲にその影響が直接反映されてしまいます。より詳しい散らばりの指標として、四分位範囲があります。

---

## まとめ

ヒストグラムは度数分布表を図にしたもので、データ全体の形が視覚的にとらえられます。ただし階級の幅の取り方次第で見え方が変わりうるため、複数の幅で確認したうえで批判的に考察することが大切です。相対度数を使うと、大きさの異なる集団も公平に比較できます。累積度数・累積相対度数を使うと、ある値以下のデータの割合や個数を把握できます。範囲は最大値と最小値の差で、データの散らばりのおおまかな目安になります。
