## 合わせていくつ

こんな場面を考えてみましょう。

> たかしくんはりんごを3個持っています。お母さんから2個もらいました。全部で何個になったでしょう？

2つの数を合わせて、全部で何個になったかを考える。これが**足し算**です。この場面では「持っていた3個」と「もらった2個」を合わせています。

$$3 + 2 = 5$$

---

## 順番を入れ替えても同じ（交換法則）

この話を別の角度から見てみましょう。

> たかしくんとお母さんが、りんごをかごにまとめて入れます。お母さんが2個、たかしくんが3個をかごに入れました。かごの中のりんごは全部で何個でしょう？

$$2 + 3 = 5$$

答えは同じ5個です。「3個に2個を足す」のも「2個に3個を足す」のも、結果は変わりません。足し算は順番を入れ替えても答えが同じになります。この性質を**交換法則(こうかんほうそく)**といいます。

これはどんな数についても成り立つ性質です。特定の数ではなく、任意の数を表す記号として $a$や$b$のような文字を使うと、次のように書けます。

> [!IMPORTANT]
> $$a + b = b + a$$

---

## どこからまとめて足しても同じ（結合法則）

3人がりんごを持ち寄る場面を考えてみましょう。

> たかしくんは3個、お母さんは2個、お父さんは4個のりんごを持ち寄りました。全部で何個になるでしょう？

数える順番として、2通りの方法を考えてみます。

**方法1**：まずたかしくんとお母さんの分を先に合わせてから、お父さんの分を足す。

$$(3 + 2) + 4 = 5 + 4 = 9$$

**方法2**：まずお母さんとお父さんの分を先に合わせてから、たかしくんの分を足す。

$$3 + (2 + 4) = 3 + 6 = 9$$

どちらの順番でまとめても、3人が持ち寄ったりんごを全部合わせているだけなので、答えは同じ9個になります。括弧 $(\quad)$ は「先にまとめて計算するところ」を表す記号です。このように、式のどこに括弧をつけて先にまとめるかを変えても答えが変わらない性質を**結合法則(けつごうほうそく)**といいます。

> [!IMPORTANT]
> $$(a + b) + c = a + (b + c)$$

---

## 2つの法則を組み合わせて計算を楽にする

交換法則は隣り合った2つの数の順番を入れ替える性質、結合法則はどこから先にまとめるかを変える性質でした。実はこの2つを組み合わせると、3つ以上の数の足し算では、どの2つを先に選んで計算しても答えは変わりません。結局、全部を合わせているだけなので、選ぶ順番によって全体の個数が変わるわけではないからです。

例えば $38 + 25 + 12$ を計算するとき、必ずしも左から順に計算する必要はありません。計算しやすい2つを自由に選んでよいのです。ここでは $38$ と $12$ を先に選んでみましょう。この2つを合わせるとちょうど $50$ というきりのいい数になり、そのあとの計算が暗算しやすくなるからです。

$$38 + 12 = 50$$

残りの $25$ を足すと、

$$50 + 25 = 75$$

となります。このように、計算しやすい組み合わせを見つけて先に計算するのが、足し算を工夫するコツです。

> [!NOTE]
> なぜ$38$と$12$のように離れた数を先に選んでよいのか、交換法則・結合法則を使って確認してみましょう。$38 + 25 + 12$は、左から順に計算することを表すので $(38 + 25) + 12$ と同じ意味です。
>
> $$(38 + 25) + 12 = 38 + (25 + 12) = 38 + (12 + 25) = (38 + 12) + 25$$
>
> 1つ目の等号は結合法則で $25 + 12$ を先にまとめる形に括弧を付け替えたもの、2つ目の等号は括弧の中で交換法則により $25$ と $12$ を入れ替えたものです。3つ目の等号も同じ結合法則です。結合法則の式 $(a+b)+c = a+(b+c)$ は、左辺と右辺が同じ値になることを表しているので、$a+(b+c)$の形になっている式を$(a+b)+c$の形に書き換えることもできます。ここでは $38 + (12+25)$ を $(38+12)+25$ の形に書き換え、$38$ と $12$ を先にまとめる形にしています。

---

## まとめ

足し算は2つ以上の数を合わせて、全部で何個になるかを求める操作です。交換法則により順番を入れ替えても、結合法則によりどこから先に計算しても、答えは変わりません。この2つの法則を使えば、計算しやすい組み合わせを先に選んで、計算を楽にすることができます。
