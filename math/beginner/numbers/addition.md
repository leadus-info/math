## 合わせていくつ？
こんな場面を考えてみましょう。

> 空の袋があります。\
> たかしくんが、りんごを3個袋に入れました。\
> 次にお母さんが、りんごを2個袋に入れました。\
> 袋の中のりんごは、全部で何個になったでしょう？

2つの数を合わせて、全部で何個になったかを考える。これが**足し算**です。\
袋の中には $5$ 個のりんごが入っているので、答えは $5$ となります。

$$3 + 2 = 5$$



## 数直線の上を右に進む
足し算には、もう一つの見方があります。\
今度はこんな場面を考えてみましょう。

> たかしくんは、りんごを3個持っています。\
> そこにお母さんが、りんごを2個くれました。\
> たかしくんのりんごは、全部で何個になったでしょう？

はじめに3個あって、そこに2個増えました。りんごは全部で $5$ 個になるので、式は次のようになります。

$$3 + 2 = 5$$

「合わせていくつ？」で考えた式と同じ $3 + 2 = 5$ です。\
2つの数を合わせる場面と、はじめにあった数が増える場面は、同じ式を別の見方で見ているのです。

数が増えるようすは、[自然数](natural-numbers.md)で出てきた数直線を使うと目で見て確かめられます。\
そこでは数直線を大小を確かめる道具として使いましたが、ここでは数の上を移動する道具として使ってみましょう。

はじめのりんごは3個なので、数直線の3の位置から出発します。\
そこに2個増えるので、3の位置から右に2つ進みます。\
すると、5に着きます。これが $3 + 2 = 5$ です。



> [!IMPORTANT]
> 足し算は、数直線の上を右に進むことに対応する。



## 順番を入れ替えても同じ（交換法則）
この話を別の角度から見てみましょう。

> 空の袋があります。\
> お母さんが、りんごを2個袋に入れました。\
> 次にたかしくんが、りんごを3個袋に入れました。\
> 袋の中のりんごは、全部で何個になったでしょう？

$$2 + 3 = 5$$

答えは同じ $5$ 個です。\
「3個に2個を足す」のも「2個に3個を足す」のも、結果は変わりません。\
足し算は順番を入れ替えても答えが同じになります。

この性質を**交換法則**といいます。

これはどんな数についても成り立ちます。\
そこで、どんな数にも当てはまることを表すために、数の代わりに $a$ や $b$ のような文字を使うと、次のようになります。

> [!IMPORTANT]
> 交換法則により、足し算は順番を入れ替えることができる。
> $$a + b = b + a$$

たとえば先ほどの例では、3を$a$、2を$b$とすると、$3+2=2+3$がそのまま$a+b=b+a$の形になります。




## 3つの数の足し算
3人がりんごを持ち寄る場面を考えてみましょう。

> カゴの中に、たかしくんは3個、お母さんは2個、お父さんは4個のりんごを入れました。全部で何個になるでしょう？

まず、たかしくんとお母さんがカゴに入れたりんごの数を考えてみましょう。\
たかしくんとお母さんは、合計で
$$3 + 2 = 5$$
個のりんごをカゴに入れています。

ここにお父さんが入れた $4$ 個のりんごを合わせる時、カゴの中のりんごは合計で
$$5 + 4 = 9$$
個になっているはずです。

このように、3つの数字を全て足す時、式ではこのように書くことができます。

$$(3 + 2) + 4$$

この括弧 $(\quad)$ は「先に計算する」ことを表す記号です。\
これから先、$(\quad)$ が出てきたらそこを先に計算するようにしましょう。

実際に計算してみると、こうなります。

$$(3 + 2) + 4 = 5 + 4 = 9$$

また、この $(\quad)$ は省略することができます。

$$(3 + 2) + 4 = 3 + 2 + 4$$

$(\quad)$ を省略して書いても、「最初の二つを足し、そこに三つ目を足す」という意味は変わりません。


## どこから足しても同じ（結合法則）
引き続き、同じ状況を考えてみましょう。

> カゴの中に、たかしくんは3個、お母さんは2個、お父さんは4個のりんごを入れました。全部で何個になるでしょう？

さっきは、たかしくんとお母さんのりんごを先に足して、最後にお父さんのりんごを足しました。\
今度は、たかしくんのりんごに、「お母さんとお父さんのりんごの合計」を足してみましょう。

お母さんとお父さんのりんごの合計は、
$$2 + 4 = 6$$
個です。

これを、たかしくんのりんごに加えるので、カゴの中のりんごの合計は
$$3 + 6 = 9$$
個となります。

これを、一つの式で表すとこうなります。
$$3 + (2 + 4) = 9$$
$2+4$ を先に計算して、その答えを $3$ に足すという意味です。

$(3 + 2) + 4$ も $3 + (2 + 4)$ も、どちらも答えが $9$ になりました。

このように、3つの数の足し算は「どこから先に計算をしても答えが同じになる」という性質があります。\
（どの順番で計算しても、カゴの中のりんごの数が変わるわけではないからです）

この性質を**結合法則**といいます。

$a$、$b$は「どんな数にも当てはまることを表す文字」として使いました。$c$も同じように、好きな数を表す文字として使うと、次のように書けます。

> [!IMPORTANT]
> 結合法則より、3つの数の足し算はどこから先に計算してもいい。
> $$(a + b) + c = a + (b + c)$$

### 計算を楽にする
交換法則と結合法則を組み合わせると、3つの数の足し算は順番を自由に入れ替えることができるようになります。\
そしてこの性質を使うと、複雑な計算を簡単にできるようになります。

例えば $38 + 25 + 12$ は、次のようにすると計算が簡単になります。
$$
\begin{aligned}
38 + 25 + 12 &= 38 + (25 + 12) \text{\ \ \ \ \ \ \ \ \ \ 結合法則}\\
&= 38 + (12 + 25) \text{\ \ \ \ \ \ \ \ \ \ 交換法則}\\
&= (38 + 12) + 25 \text{\ \ \ \ \ \ \ \ \ \ 結合法則}\\
&= 50 + 25\\ &= 75
\end{aligned}
$$



## まとめ
足し算は2つ以上の数を合わせて、全部で何個になるかを求める操作です。\
交換法則により順番を入れ替えても、結合法則によりどこから先に計算しても、答えは変わりません。\
この2つの法則を使えば、計算しやすい組み合わせを先に選んで、計算を楽にすることができます。
