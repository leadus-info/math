## 位をそろえて計算する

小数の足し算は、位をきちんとそろえて（小数点の位置を合わせて）計算します。小数点をそろえずに右端の数字をそろえてしまうと、次のように誤って計算してしまいます。

```
  1.25
+  0.3
------
  1.28  （誤り）
```

これは、$0.3$ の $3$ を、小数で見た[$\frac{1}{100}$の位](decimals.md)に合わせてしまったために起こる間違いです。本当は $\frac{1}{10}$の位どうしを足すべきところを、$\frac{1}{100}$の位と足し間違えています。必ず小数点の位置で縦をそろえることが大切です。

$$1.25 + 0.3$$

$0.3$ を $0.30$ と考え、位をそろえて筆算すると、

```
  1.25
+ 0.30
------
  1.55
```

小数点より右側の桁数が違う場合は、足りない桁を$0$で埋めて位をそろえると計算しやすくなります。

位ごとに足し算し、答えが10以上になったら1つ上の位に1繰り上げます。これは、自然数で見た「同じ位に10集まると1つ上の位の1個分になる」という位取りの考え方を、小数の位でもそのまま使っているだけです。

**例**：$4.6 + 2.75$。$4.6$ を $4.60$ と考えて位をそろえると、

```
  4.60
+ 2.75
------
```

一番右の$\frac{1}{100}$の位から順に計算します。

- $\frac{1}{100}$の位：$0 + 5 = 5$
- $\frac{1}{10}$の位：$6 + 7 = 13$。$10$以上になったので、$1$の位に$1$繰り上げ、この位には$3$を書きます。
- $1$の位：$4 + 2 + 1$（繰り上がり分）$= 7$

まとめると、次のようになります。

```
  4.60
+ 2.75
------
  7.35
```

---

## まとめ

小数の足し算は、小数点の位置をそろえてから、同じ位どうしを足します。桁数が違うときは$0$で埋めて位をそろえると間違いを防げます。
