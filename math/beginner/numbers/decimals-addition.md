## 位をそろえて計算する

小数の足し算は、位をきちんとそろえて（小数点の位置を合わせて）計算します。小数点をそろえずに右端をそろえてしまうと、$\frac{1}{10}$の位と$\frac{1}{100}$の位を足し間違えてしまうので、必ず小数点の位置で縦をそろえることが大切です。

$$1.25 + 0.3$$

$0.3$ を $0.30$ と考え、位をそろえて筆算すると、

```
  1.25
+ 0.30
------
  1.55
```

小数点より右側の桁数が違う場合は、足りない桁を$0$で埋めて位をそろえると計算しやすくなります。

位ごとに足し算し、答えが10以上になったら1つ上の位に1繰り上げます。

**例**：$4.6 + 2.75$。$4.6$ を $4.60$ と考えて位をそろえると、

```
  4.60
+ 2.75
------
  7.35
```

---

## まとめ

小数の足し算は、小数点の位置をそろえてから、同じ位どうしを足します。桁数が違うときは$0$で埋めて位をそろえると間違いを防げます。
