## 位をそろえて計算する

[足し算](addition.md)では、位ごとに分けて、同じ位どうしを足しました。この計算を、数を縦に並べて行う書き方を**筆算**といいます。

筆算では、同じ位の数字が縦に並ぶように、$2$ つの数を上下に書きます。その下に横線を引きます。一番右の位から順に、縦に並んだ数字どうしを足します。答えは、横線の下の同じ列に書きます。

たとえば $75 + 23$ を筆算で書くと、次のようになります。まず、縦に並んだ $5$ と $3$ を足すと $8$ です。次に、$7$ と $2$ を足すと $9$ です。

```
  75
+ 23
----
  98
```

小数の足し算も、筆算で計算できます。そのときは、位をきちんとそろえて（小数点の位置を合わせて）計算します。小数点をそろえずに右端の数字をそろえてしまうと、次のように誤って計算してしまいます。

```
  1.25
+  0.3
------
  1.28  （誤り）
```

$0.3$ の $3$ は、本来 $\frac{1}{10}$の位を表す数字です。しかし右端の数字をそろえて書くと、この $3$ は $1.25$ の一番右の桁（$5$、[$\frac{1}{100}$の位](decimals.md)）の真下に来てしまいます。その結果、$\frac{1}{10}$の位どうしではなく、$\frac{1}{10}$の位と$\frac{1}{100}$の位を足し間違えてしまうのです。必ず小数点の位置で縦をそろえることが大切です。

では、$1.25 + 0.3$ を正しく計算してみましょう。$0.3$ は $0.30$ と表しても同じ値なので、こう考えて位をそろえて筆算すると、

```
  1.25
+ 0.30
------
  1.55
```

小数点より右側の桁数が違う場合は、足りない桁を$0$で埋めて位をそろえると計算しやすくなります。

位ごとに足し算し、答えが10以上になったら1つ上の位に1繰り上げます。これは自然数の位取りと同じ考え方です。自然数でも、同じ位に10集まると1つ上の位の1個分になります。小数でもこの仕組みをそのまま使っているだけです。

**例**：$4.6 + 2.75$。$4.6$ を $4.60$ と考えて位をそろえると、

```
  4.60
+ 2.75
------
```

一番右の$\frac{1}{100}$の位から順に計算します。

- $\frac{1}{100}$の位：$0 + 5 = 5$
- $\frac{1}{10}$の位：$6 + 7 = 13$。$10$以上になったので、$1$の位に$1$繰り上げ、この位には$3$を書きます。
- $1$の位：$4 + 2 + 1$（繰り上がり分）$= 7$

まとめると、次のようになります。

```
  4.60
+ 2.75
------
  7.35
```

---

## まとめ

小数の足し算は、小数点の位置をそろえてから、同じ位どうしを足します。桁数が違うときは$0$で埋めて位をそろえると間違いを防げます。
