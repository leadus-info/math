## 位をそろえて計算する

こんな場面を考えてみましょう。

> ペットボトルに $1.25\text{L}$、コップに $0.3\text{L}$ のジュースが入っています。合わせると何Lになるでしょう？

$$1.25 + 0.3$$

小数の足し算も、整数の足し算と同じように同じ位どうしを足しますが、位をきちんとそろえて（小数点の位置を合わせて）計算することが大切です。小数点をそろえずに右端をそろえてしまうと、$\frac{1}{10}$の位と$\frac{1}{100}$の位を足し間違えてしまいます。

$0.3$ は $0.30$ と考えると、$1.25$ と桁数がそろって計算しやすくなります。

> [!NOTE]
> $0.3$ を $0.30$ と考えてよいのはなぜでしょうか。[小数](decimals.md)で見たように、小数は「$1$, $\frac{1}{10}$, $\frac{1}{100}$, …を何個ずつ使うか」を並べたものです。$0.3$ は $\frac{1}{100}$ の位の数字が書かれていないだけで、$\frac{1}{100}$ を $0$ 個使うと考えれば $0.3 = 0.30$ です。整数では末尾に$0$を付け足すと（$3 \to 30$のように）既にある数字の位が1つ上がって値が10倍になりますが、小数点より右に$0$を付け足す場合はその逆で、まだ書かれていなかったさらに細かい位を「$0$個」と明記するだけなので、既にある数字の位は動かず、値も変わりません。

位をそろえて筆算すると、

```
  1.25
+ 0.30
------
  1.55
```

小数点より右側の桁数が違う場合は、このように足りない桁を$0$で埋めて位をそろえると計算しやすくなります。

## 繰り上がりの仕組み

位ごとの和が$10$以上になる場合を考えてみましょう。$4.6 + 2.75$ を計算します。$4.6$ を $4.60$ と考えて位をそろえると、

```
  4.60
+ 2.75
------
```

一番細かい位（$\frac{1}{100}$の位）から計算します。$0 + 5 = 5$ なので、そのまま $5$ と書きます。

次に $\frac{1}{10}$ の位を計算すると、$6 + 7 = 13$ になります。1つの位には $0〜9$ の1桁の数字しか書けないので、$13$ のままではこの位に収まりません。10円玉が10枚集まると100円玉1枚に両替できるのと同じように、この位の「10」は1つ上の位（一の位）の「1」に両替できます。そこで、この位には $13$ の一の位の数字である $3$ だけを書き、余った $10$ を1つ上の位に**繰り上げ**ます。

最後に一の位を計算します。繰り上がってきた $1$ も足して、$4 + 2 + 1 = 7$ です。

```
  4.60
+ 2.75
------
  7.35
```

このように、ある位の和が$10$以上になったら、その位には一の位の数字だけを残し、余った$10$を1つ上の位に$1$として繰り上げて足す、という手順を位の低い方（右側）から順に繰り返していきます。

---

## まとめ

小数の足し算は、小数点の位置をそろえてから、同じ位どうしを足します。桁数が違うときは$0$で埋めて位をそろえると間違いを防げます。位ごとの和が$10$以上になったら、一の位の数字だけを残して余りを1つ上の位に繰り上げます。
