## 位をそろえて計算する

足し算と同じように、小数の引き算も位をそろえてから計算します。

$$3.4 - 1.28$$

$3.4$ を $3.40$ と考えて位をそろえます。同じ位どうしを、一番右の位から順に引いていきます。

$\frac{1}{100}$の位は $0 - 8$ となり、そのままでは引けません。このようなときは、1つ上の位から1借りてきて、その位を10として計算します。借りた分、1つ上の位は1減らします。

- $\frac{1}{100}$の位：1つ上（$\frac{1}{10}$の位）から1借りて、$10 - 8 = 2$
- $\frac{1}{10}$の位：1借りられたので$4$ではなく$3$として、$3 - 2 = 1$
- 1の位：$3 - 1 = 2$

```
  3.40
- 1.28
------
  2.12
```

このように、小数点より右側の桁数が少ない方の数を$0$で埋めて位をそろえれば、引く数と引かれる数のどちらの桁数が多い場合でも同じように計算できます。

**例**：引く数の桁数の方が多い場合。$5 - 2.3$。$5$ を $5.0$ と考えて、$\frac{1}{10}$の位は $0 - 3$ が引けないので1の位から1借りて $10 - 3 = 7$、1の位は1借りられたので$5$ではなく$4$として$4 - 2 = 2$です。

```
  5.0
- 2.3
-----
  2.7
```

**例**：引かれる数の桁数の方が多い場合。$6.75 - 2.4$。$2.4$ を $2.40$ と考えて位をそろえると、どの位も引かれる数の方が大きいので借りることなく、同じ位どうしをそのまま引くだけで計算できます。

```
  6.75
- 2.40
------
  4.35
```

**例**：借りたい位がさらに$0$の場合。$4.03 - 1.28$。

$\frac{1}{100}$の位は $3 - 8$ で引けないので、1つ上の$\frac{1}{10}$の位から借りたいところですが、$\frac{1}{10}$の位はもともと$0$なので、そこから借りることはできません。そこで先に1の位から$\frac{1}{10}$の位へ1借りて$\frac{1}{10}$の位を$10$にし、その$10$からあらためて$\frac{1}{100}$の位に1渡します。

- 1の位から$\frac{1}{10}$の位へ1渡すので、$\frac{1}{10}$の位は$0$ではなく$10$
- $\frac{1}{100}$の位：$\frac{1}{10}$の位から1借りて、$13 - 8 = 5$
- $\frac{1}{10}$の位：$\frac{1}{100}$の位に1渡したので$10$ではなく$9$として、$9 - 2 = 7$
- 1の位：$\frac{1}{10}$の位に1渡したので$4$ではなく$3$として、$3 - 1 = 2$

```
  4.03
- 1.28
------
  2.75
```

> [!NOTE]
> ここまでの例はすべて引かれる数の方が大きいので答えが求まりますが、[引き算](subtraction.md)で見たように、引く数の方が大きいと自然数の範囲では答えが求まりません。これは小数の場合も同じです。

---

## まとめ

小数の引き算も、小数点の位置をそろえてから同じ位どうしを引きます。桁数が足りない方を$0$で埋めて位をそろえることが大切です。
