## 位をそろえて計算する

足し算と同じように、小数の引き算も位をそろえてから計算します。

$$3.4 - 1.28$$

$3.4$ を $3.40$ と考えて位をそろえると、

```
  3.40
- 1.28
------
```

ある位から引けないときは、1つ上の位から1借りてきて10として計算します。1つ上の位の1は、下の位から見ると10個分に相当するため、そこから10借りてくることができます。これは、自然数の引き算で行う繰り下がりと同じ考え方を、小数の位でもそのまま使っているだけです。

一番右の$\frac{1}{100}$の位から順に計算します。

- $\frac{1}{100}$の位：$0-8$は引けないので、$\frac{1}{10}$の位から1借りて$10-8=2$
- $\frac{1}{10}$の位：1借りられたので$4-1=3$になり、$3-2=1$
- $1$の位：$3-1=2$

まとめると、次のようになります。

```
  3.40
- 1.28
------
  2.12
```

引く数の桁数の方が多い場合も、引かれる数を$0$で埋めて位をそろえれば同じように計算できます。逆に、引かれる数の桁数の方が多い場合は、引く数を$0$で埋めて位をそろえます。どちらの場合も、桁数が足りない方を$0$で埋めて位をそろえるという考え方は同じです。

**例**：$5.34 - 2.1$。$2.1$ を $2.10$ と考えて位をそろえると、

```
  5.34
- 2.10
------
```

- $\frac{1}{100}$の位：$4-0=4$
- $\frac{1}{10}$の位：$3-1=2$
- $1$の位：$5-2=3$

まとめると、次のようになります。

```
  5.34
- 2.10
------
  3.24
```

**例**：$5 - 2.3$。$5$ を $5.0$ と考えて位をそろえると、

```
  5.0
- 2.3
-----
```

- $\frac{1}{10}$の位：$0-3$は引けないので、$1$の位から1借りて$10-3=7$
- $1$の位：1借りられたので$5-1=4$になり、$4-2=2$

まとめると、次のようになります。

```
  5.0
- 2.3
-----
  2.7
```

---

## まとめ

小数の引き算も、小数点の位置をそろえてから同じ位どうしを引きます。桁数が足りない方を$0$で埋めて位をそろえることが大切です。
