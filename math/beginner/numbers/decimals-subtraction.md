## 位をそろえて計算する

足し算と同じように、小数の引き算も位をそろえてから計算します。

$$3.4 - 1.28$$

$3.4$ を $3.40$ と考えて位をそろえると、

```
  3.40
- 1.28
------
```

ある位で引けないときは、$1$ つ上の位から $1$ 借ります。$1$ つ上の位の $1$ は、すぐ下の位の $1$ の $10$ 個分にあたります。たとえば、$0.1$ は $0.01$ の $10$ 個分です。そのため、借りた $1$ は、すぐ下の位では $10$ として引き算に使います。

一番右の$\frac{1}{100}$の位から順に計算します。

- $\frac{1}{100}$の位：$0-8$は引けないので、$\frac{1}{10}$の位から1借りて$10-8=2$
- $\frac{1}{10}$の位(借りた分を引く)：$4-1=3$
- $\frac{1}{10}$の位(引き算)：$3-2=1$
- $1$の位：$3-1=2$

まとめると、次のようになります。

```
  3.40
- 1.28
------
  2.12
```

位をそろえるときは、小数点以下の桁数が足りない方を$0$で埋めます。

- 引く数の小数点以下の桁数の方が多い場合：引かれる数を$0$で埋める
- 引かれる数の小数点以下の桁数の方が多い場合：引く数を$0$で埋める

**例**：$5.34 - 2.1$。$2.1$ を $2.10$ と考えて位をそろえると、

```
  5.34
- 2.10
------
```

- $\frac{1}{100}$の位：$4-0=4$
- $\frac{1}{10}$の位：$3-1=2$
- $1$の位：$5-2=3$

まとめると、次のようになります。

```
  5.34
- 2.10
------
  3.24
```

**例**：$5 - 2.3$。$5$ を $5.0$ と考えて位をそろえると、

```
  5.0
- 2.3
-----
```

- $\frac{1}{10}$の位：$0-3$は引けないので、$1$の位から1借りて$10-3=7$
- $1$の位(借りた分を引く)：$5-1=4$
- $1$の位(引き算)：$4-2=2$

まとめると、次のようになります。

```
  5.0
- 2.3
-----
  2.7
```

借りようとした位が $0$ のときは、その位がさらに $1$ つ上の位から、先に $1$ 借ります。

**例**：$3 - 1.25$。$3$ を $3.00$ と考えて位をそろえると、

```
  3.00
- 1.25
------
```

一番右の $\frac{1}{100}$ の位から計算します。$\frac{1}{100}$ の位は $0-5$ で、引けません。$\frac{1}{10}$ の位も $0$ なので、$\frac{1}{10}$ の位からは借りられません。そこで、次の順に借ります。

1. $\frac{1}{10}$ の位が、$1$ の位から $1$ 借ります。$1$ の位は $3-1=2$ になります。$\frac{1}{10}$ の位は $10$ になります。
2. $\frac{1}{100}$ の位が、$\frac{1}{10}$ の位から $1$ 借ります。$\frac{1}{10}$ の位は $10-1=9$ になります。$\frac{1}{100}$ の位は $10$ になります。

借りたあとの数で、位ごとに引きます。

- $\frac{1}{100}$ の位：$10-5=5$
- $\frac{1}{10}$ の位：$9-2=7$
- $1$ の位：$2-1=1$

まとめると、次のようになります。

```
  3.00
- 1.25
------
  1.75
```

---

## まとめ

小数の引き算も、小数点の位置をそろえてから同じ位どうしを引きます。小数点以下の桁数が足りない方を$0$で埋めて位をそろえることが大切です。
