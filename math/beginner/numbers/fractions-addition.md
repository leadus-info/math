## 分母が同じ分数の足し算

$\frac{1}{4}$ と $\frac{1}{4}$ を足してみましょう。「4等分の1つ」と「4等分の1つ」を合わせると「4等分の2つ」です。

$$\frac{1}{4} + \frac{1}{4} = \frac{2}{4} = \frac{1}{2}$$

分母が同じなら、分子同士を足すだけです。

$$\frac{2}{5} + \frac{1}{5} = \frac{3}{5}$$

答えが1を超えることもあります。$\frac{3}{4}$ と $\frac{3}{4}$ を足すと、分子同士を足して $\frac{6}{4}$ となり、これは分子が分母以上になる仮分数です。

$$\frac{3}{4} + \frac{3}{4} = \frac{6}{4} = \frac{3}{2}$$

## 分母が違う分数の足し算（通分）

$\frac{1}{4}$ と $\frac{1}{6}$ を足すには、分母がそのままでは足し算ができません。「4等分の1つ」と「6等分の1つ」は大きさが違うからです。

そこで、[分数](fractions.md)で見た「分母と分子の両方に同じ数を掛けても大きさは変わらない」という性質を使って、2つの分数の分母を同じ数にそろえます。これを**通分（つうぶん）**といいます。

分母をそろえる数は、[倍数と約数](multiples-divisors.md)で見た4と6の**公倍数**であれば、どれを選んでも計算自体は成り立ちます。ただ、公倍数は無限にあり、大きい数を選ぶほど分子の数も大きくなって計算や後の約分が面倒になるため、公倍数の中でも一番小さい**最小公倍数**を選ぶのが得策です。4の倍数（4, 8, 12, …）と6の倍数（6, 12, …）を並べて共通する数を探すと、最小公倍数は $12$ なので、分母を $12$ にそろえます。

$$\frac{1}{4} = \frac{1 \times 3}{4 \times 3} = \frac{3}{12}, \qquad \frac{1}{6} = \frac{1 \times 2}{6 \times 2} = \frac{2}{12}$$

$$\frac{1}{4} + \frac{1}{6} = \frac{3}{12} + \frac{2}{12} = \frac{5}{12}$$

通分して足し算した後の分数が、まだ約分できることもあります。$\frac{1}{6}$ と $\frac{1}{3}$ を足す場合を見てみましょう。$6$ と $3$ の最小公倍数は $6$ なので、分母を $6$ にそろえます。

$$\frac{1}{6} + \frac{1}{3} = \frac{1}{6} + \frac{1 \times 2}{3 \times 2} = \frac{1}{6} + \frac{2}{6} = \frac{3}{6}$$

$\frac{3}{6}$ は分母と分子をどちらも $3$ で割り切れるので、[約分](fractions.md)してより簡単な形にしておきましょう。

$$\frac{3}{6} = \frac{3 \div 3}{6 \div 3} = \frac{1}{2}$$

分母が違う分数の大小も、通分すればそのまま比べられます。$\frac{1}{4}$ と $\frac{1}{6}$ なら、$\frac{3}{12}$ と $\frac{2}{12}$ なので $\frac{1}{4}$ の方が大きいとわかります。

---

## まとめ

分母が同じ分数は、分子同士を足すだけで計算できます。答えが1を超えて仮分数になることもあります。分母が違う場合は、通分して分母をそろえてから分子を足します。計算した答えがまだ約分できるときは、約分して簡単な形にしておきましょう。通分は分数の大小比較にも使えます。
