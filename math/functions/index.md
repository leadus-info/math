# 関数

> **標準**：初めて学ぶ人向け　**発展**：高校〜大学入門　**専門**：大学以上

ある値を入力すると別の値が対応して決まる——それが関数です。
関数の種類と、極限・微分・積分などの関数への操作をここで扱います。

## 関数の種類

### 一次関数
グラフが直線になる関数。傾きと切片で完全に決まります。

[入門](linear/introduction.md) / [標準](linear/standard.md) / [専門](linear/professional.md)


### 二次関数
グラフが放物線になる関数。頂点・判別式・二次方程式との対応を扱います。

[入門](quadratic/introduction.md) / [標準](quadratic/standard.md) / [専門](quadratic/professional.md)


### 指数関数
倍々で増える変化を表す関数。ネイピア数 $e$ の意味を扱います。

[入門](exponential/introduction.md) / [標準](exponential/standard.md) / [専門](exponential/professional.md)


### 対数関数
「何乗すれば？」という問いに答える関数。指数関数の逆です。

[入門](logarithmic/introduction.md) / [標準](logarithmic/standard.md) / [専門](logarithmic/professional.md)


### 三角関数
単位円から生まれる周期関数。波・振動・回転のモデルです。

[入門](trigonometric/introduction.md) / [標準](trigonometric/standard.md) / [専門](trigonometric/professional.md)


### 多項式
べき乗の和で表される関数。あらゆる滑らかな関数の近似に使えます。

[入門](polynomials/introduction.md) / [標準](polynomials/standard.md) / [専門](polynomials/professional.md)


### 数列

[入門](sequences/introduction.md) / [標準](sequences/standard.md) / [専門](sequences/professional.md)
