# 関数の操作（微積分）

> **標準**：初めて学ぶ人向け　**発展**：高校〜大学入門　**専門**：大学以上

関数に対して行う操作——極限・微分・積分——を扱います。
これらはすべて「限りなく近づける」という極限の考え方の上に成り立っています。

## 極限
「限りなく近づくとどこへ向かうか」——微積分の出発点となる概念です。

[標準](./limits/standard.md) / [発展](./limits/advanced.md) / [専門](./limits/professional.md)


## 微分
関数の瞬間の変化率。グラフの接線の傾きとして解釈できます。

[標準](./derivatives/standard.md) / [発展](./derivatives/advanced.md) / [専門](./derivatives/professional.md)


## 積分
グラフの下の面積を求める操作。微分の逆操作でもあります。

[標準](./integrals/standard.md) / [発展](./integrals/advanced.md) / [専門](./integrals/professional.md)


## 複素関数
複素数を変数にとる関数への微積分の拡張。正則性・留数定理を扱います。
