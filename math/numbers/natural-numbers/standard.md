## 文字を使って表す

自然数（入門）では、「$3 + 2$ と $2 + 3$ は同じ」「$3 \times 4$ と $4 \times 3$ は同じ」ということを具体的な数で確認しました。しかし、これは $3$ や $4$ に限った話ではなく、どんな自然数でも成り立ちます。

「どんな自然数でも成り立つ」ということを、いちいち $1 + 2 = 2 + 1$、$1 + 3 = 3 + 1$、$2 + 3 = 3 + 2$、……と書き並べていくわけにはいきません。そこで、$a$ や $b$ のような**文字**を使います。$a$ は「どんな自然数でも入る箱」だと思ってください。

$$a + b = b + a$$

こう書けば、「$a$ にどんな自然数を入れても、$b$ にどんな自然数を入れても、左辺と右辺は同じ値になる」ということを一行で表せます。たとえば $a = 3$、$b = 5$ を入れれば $3 + 5 = 5 + 3 = 8$ ですし、$a = 100$、$b = 7$ を入れれば $100 + 7 = 7 + 100 = 107$ です。

以降、このような文字を使って自然数の法則を整理していきます。

## 演算の法則

自然数全体の集合を $\mathbb{N} = \{1, 2, 3, \ldots\}$ と書きます（このサイトでは $0$ を含めません。$0$ を含む場合は $\mathbb{N}_0$ と書きます）。

### 加法

足し算の法則をまとめます。

**交換法則**：$a + b = b + a$（順番を入れ替えても答えは同じ）

**結合法則**：$(a + b) + c = a + (b + c)$（どこから先に足しても答えは同じ）

結合法則により、$1 + 2 + 3 + 4$ のように括弧を省略して書けます。

### 乗法

掛け算の法則をまとめます。

**交換法則**：$a \times b = b \times a$（順番を入れ替えても答えは同じ）

自然数（入門）ではクッキーの数え方を変える例で見ましたが、もっと一般的に考えることができます。$a \times b$ 個の点を横 $a$ 個×縦 $b$ 個の長方形に並べると、90度回転しても点の総数は変わりません。よってどんな自然数でも $a \times b = b \times a$ が成り立ちます。

**結合法則**：$(a \times b) \times c = a \times (b \times c)$（どこから先に掛けても答えは同じ）

**分配法則**：$a \times (b + c) = a \times b + a \times c$（足し算と掛け算をつなぐ法則）

**例**：$7 \times 13 = 7 \times (10 + 3) = 70 + 21 = 91$

**計算の優先順位**：乗法は加法より先に計算します。$(2 + 3) \times 4 = 20$ ですが、$2 + 3 \times 4 = 2 + 12 = 14$ です。

### べき乗

同じ数を繰り返し掛けることを**べき乗**と呼び、次のように書きます。

$$2^3 = 2 \times 2 \times 2 = 8$$

$2^3$ は「$2$ の $3$ 乗」と読みます。右上の小さな数（**指数**）は掛ける回数を表します。

**例**：$3^2 = 3 \times 3 = 9$、$5^3 = 5 \times 5 \times 5 = 125$

## 商と余り

自然数（入門）では、割り算がぴったりいかないとき余りが出ることを見ました。ここではもう少し正確に述べます。

$12 \div 4 = 3$ のように割り切れる場合、答えは自然数になります。$7 \div 3$ のように割り切れない場合でも、「何個ずつ配れて、何個余るか」という形で答えを出せます。この「何個ずつ」を**商**、残りを**余り**と呼びます。

$$7 = 3 \times 2 + 1$$

$2$ が商、$1$ が余りです。余りは割る数より必ず小さくなります（この場合、余りは $3$ より小さい）。

**例**：
- $17 = 5 \times 3 + 2$ → 商 $3$、余り $2$
- $20 = 5 \times 4 + 0$ → 商 $4$、余り $0$（割り切れる）

どんな自然数の組に対しても、商と余りの組はちょうど一通りに決まります。この性質の厳密な証明は自然数（専門）で扱います。

## 倍数と約数

掛け算と割り算から生まれる2つの概念を導入します。

### 倍数

$3 \times 1 = 3$、$3 \times 2 = 6$、$3 \times 3 = 9$、$3 \times 4 = 12$、……

この $3, 6, 9, 12, \ldots$ を $3$ の**倍数**といいます。ある数に自然数を掛けてできる数が、その数の倍数です。同じように、$5$ の倍数は $5, 10, 15, 20, \ldots$ です。

### 約数

余りが出ずに割り切れるとき、割る数のことを**約数**といいます。

$12 \div 4 = 3$ は割り切れるので、$4$ は $12$ の約数です。$12 \div 5$ は割り切れない（余りが出る）ので、$5$ は $12$ の約数ではありません。

$12$ の約数を全部探してみましょう。$1$ から順に $12$ を割ってみます。

$12 \div 1 = 12$、$12 \div 2 = 6$、$12 \div 3 = 4$、$12 \div 4 = 3$、$12 \div 6 = 2$、$12 \div 12 = 1$

$5, 7, 8, 9, 10, 11$ では割り切れません。よって $12$ の約数は $1, 2, 3, 4, 6, 12$ です。

倍数と約数は裏表の関係です。「$12$ は $4$ の倍数」と「$4$ は $12$ の約数」は同じことを言っています。

### 公約数と最大公約数

2つの数に共通する約数を**公約数**、公約数のうち最大のものを**最大公約数**といいます。

**例**：$12$ の約数は $1, 2, 3, 4, 6, 12$。$18$ の約数は $1, 2, 3, 6, 9, 18$。共通するのは $1, 2, 3, 6$ で、最大公約数は $6$ です。

同様に、2つの数に共通する倍数を**公倍数**、公倍数のうち最小のものを**最小公倍数**といいます。

## 素数

約数の個数に注目してみましょう。

$12$ の約数は $1, 2, 3, 4, 6, 12$ の6個でした。では $7$ の約数はどうでしょう。$7 \div 1 = 7$、$7 \div 7 = 1$。それ以外では割り切れません。$7$ の約数は $1$ と $7$ の2個だけです。

このように、約数が $1$ と自分自身しかない数を**素数**といいます。

**定義**：$1$ より大きい自然数で、$1$ と自分自身以外に約数を持たないものを**素数**といいます。素数でない $2$ 以上の自然数を**合成数**といいます。

$$\text{素数}：2, 3, 5, 7, 11, 13, 17, 19, 23, \ldots$$

$1$ は約数が $1$ だけ（1個）なので、素数ではありません。

ある数が素数かどうかを判定するには、$2$ から順に割っていきます。

**例**：$29$ は素数か？ $29 \div 2$、$29 \div 3$、$29 \div 5$ と試しても割り切れないので、$29$ は素数です。実は $\sqrt{29} \approx 5.4$ より小さい素数まで試せば十分です。

## 素因数分解

自然数を素数だけの掛け算に分解することを**素因数分解**といいます。

$12$ は $2 \times 6$ と書けます。$6$ はさらに $2 \times 3$ と書けます。まとめると、

$$12 = 2 \times 2 \times 3$$

べき乗を使うと簡潔に書けます。

$$12 = 2^2 \times 3$$

いくつかやってみましょう。

$$60 = 2^2 \times 3 \times 5, \quad 360 = 2^3 \times 3^2 \times 5$$

$12 = 2 \times 6 = 3 \times 4$ のように途中の分解の仕方は色々ありますが、最終的に素数まで分解すると、どの道を通っても同じ結果になります。これはすべての自然数で成り立つ性質であり、**算術の基本定理**と呼ばれます（証明は自然数（専門）で扱います）。

### 素因数分解で最大公約数を求める

素因数分解を使うと、最大公約数を機械的に求めることができます。各素因数について指数の小さい方を選びます。

**例**：$24 = 2^3 \times 3$、$36 = 2^2 \times 3^2$。各素因数の小さい方の指数を取ると $2^2 \times 3 = 12$。よって最大公約数は $12$ です。
