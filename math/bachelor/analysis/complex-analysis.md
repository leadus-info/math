## 関数の「入力」を複素数にする

$f(x) = x^2$ では実数 $x$ を入れて実数が出ますが、複素数 $z = a+bi$ を入れると $f(z) = z^2 = a^2-b^2+2abi$ という複素数が出ます。このように「複素数を入れて複素数が出る」関数を**複素関数**といいます。

$z = x + iy$ とおくと $f(z) = u(x,y) + iv(x,y)$ と書け、実部 $u$ と虚部 $v$ はそれぞれ2変数の実関数になります。

実数の関数のグラフは2次元平面に描けますが、複素関数は「複素平面（2次元）から複素平面（2次元）への対応」なので、グラフを描こうとすると4次元が必要になります。そのため、複素関数は「ある領域の形が別の形にどう変換されるか」として視覚化されることが多いです。

## 正則性

**定義**：$f(z)$ が $z_0$ で**複素微分可能**であるとは、

$$f'(z_0) = \lim_{h \to 0} \frac{f(z_0+h) - f(z_0)}{h} \quad (h \in \mathbb{C})$$

が存在することです。$z_0$ を中心とするある円板（$z_0$ の近傍）の各点で $f$ が複素微分可能なとき、$f$ は $z_0$ で**正則**（holomorphic）であるといいます。領域 $D$（下で定義します）の各点で正則なとき、$f$ は $D$ で正則であるといいます。

$h$ は複素数なので、$0$ への近づき方は実軸や虚軸に沿うものだけでなく、斜めの方向や曲線に沿うものなど無数にあります。複素微分可能であるためには、$h$ が $0$ にどのような近づき方をしても、差分商が同じ値に収束する必要があります。これは実数の微分可能性より強い条件です。

この強い条件のため、正則関数は実数の関数にはない性質を持ちます。（詳しくは本記事の範囲を超えますが）正則関数は各点のまわりでべき級数として展開できます。また、連結な領域で正則な2つの関数が、その領域内のある点の近くで一致すれば、領域全体で一致することが知られています。ある点の近くの値だけで、領域全体の値が決まってしまうのです。

## コーシー・リーマン方程式

**定理**：$f = u + iv$ が $z_0=x_0+iy_0$ で複素微分可能ならば、$u, v$ の偏導関数が $(x_0, y_0)$ で存在し、次の偏微分方程式（**コーシー・リーマン方程式**）が成り立つ。

$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \qquad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

**証明**：極限 $f'(z_0) = \lim_{h\to 0}\dfrac{f(z_0+h)-f(z_0)}{h}$ が存在するので、特に $h$ を実軸に沿って $0$ に近づけても、虚軸に沿って $0$ に近づけても、同じ値 $f'(z_0)$ に収束します。この2つの近づき方で計算し、結果を比較します。根拠として、「複素数の極限が存在することと、その実部・虚部の極限がそれぞれ存在することは同値で、そのとき極限の実部・虚部はそれぞれ実部・虚部の極限に等しい」という事実を使います。

以下、$\Delta_x u = u(x_0+t,y_0)-u(x_0,y_0)$、$\Delta_y u = u(x_0,y_0+t)-u(x_0,y_0)$ と書き、$v$ についても同様に書きます。

*$h$ が実数（$h = t$、$t \to 0$）の場合*：差分商を実部と虚部に分けると

$$\frac{f(z_0+t)-f(z_0)}{t} = \frac{\Delta_x u}{t} + i\,\frac{\Delta_x v}{t}$$

です。左辺は $f'(z_0)$ に収束するので、実部 $\dfrac{\Delta_x u}{t}$ と虚部 $\dfrac{\Delta_x v}{t}$ もそれぞれ収束します。その極限は偏導関数 $\dfrac{\partial u}{\partial x}$、$\dfrac{\partial v}{\partial x}$ そのものなので、これらが存在して

$$f'(z_0) = \frac{\partial u}{\partial x} + i\frac{\partial v}{\partial x}$$

です。

*$h$ が純虚数（$h = it$、$t \to 0$）の場合*：$\dfrac{1}{i}=-i$（$i\cdot(-i)=1$ より）を使って差分商を実部と虚部に分けると

$$\frac{f(z_0+it)-f(z_0)}{it} = \frac{\Delta_y u + i\,\Delta_y v}{it} = \frac{\Delta_y v}{t} - i\,\frac{\Delta_y u}{t}$$

です。同じ理由で $\dfrac{\partial v}{\partial y}$、$\dfrac{\partial u}{\partial y}$ が存在して

$$f'(z_0) = \frac{\partial v}{\partial y} - i\frac{\partial u}{\partial y}$$

です。

この2つは同じ値 $f'(z_0)$ に等しいので、実部どうし・虚部どうしを比較すると、

$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \qquad \frac{\partial v}{\partial x} = -\frac{\partial u}{\partial y}$$

が得られます。$\blacksquare$

> [!NOTE]
> 逆は単純には成り立ちません。コーシー・リーマン方程式を満たすだけでは、$z_0$ で複素微分可能とは限りません。正確には、$f$ が $z_0$ で複素微分可能であることは、$(u, v)$ が $(x_0,y_0)$ で（2変数関数として1次式で近似できるという意味で）全微分可能で、かつコーシー・リーマン方程式を満たすことと同値です。$u, v$ が $C^1$ 級（偏導関数が存在して連続）なら全微分可能なので、特に**開集合上で $u,v$ が $C^1$ 級でコーシー・リーマン方程式を満たせば、$f$ はその開集合で正則**です。逆向きに、正則関数の $u, v$ が自動的に $C^1$ 級になることも正しいのですが、これはコーシーの積分公式などのより進んだ理論から従います（参考文献を参照）。

**例**：$e^z = e^x(\cos y + i\sin y)$ は、実数の指数関数を複素数に拡張する自然な定義です。$u=e^x\cos y$、$v=e^x\sin y$ とおくと、

$$\frac{\partial u}{\partial x}=e^x\cos y=\frac{\partial v}{\partial y}, \qquad \frac{\partial u}{\partial y}=-e^x\sin y=-\frac{\partial v}{\partial x}$$

です。これらの偏導関数は平面全体で連続なので $u,v$ は $C^1$ 級で、コーシー・リーマン方程式も満たします。よって上の NOTE より、$e^z$ は $\mathbb{C}$ 全体で正則です。導関数は、証明で得た式 $f'=\dfrac{\partial u}{\partial x}+i\dfrac{\partial v}{\partial x}$ より $(e^z)'=e^x\cos y+ie^x\sin y=e^z$ です。

## コーシーの積分定理と留数定理

連結な開集合のことを**領域**といいます。領域 $D$ 内のどの閉曲線も、$D$ の中で連続的に変形して1点に縮められるとき、$D$ を**単連結**な領域といいます（直観的には「穴のない」領域です）。有限個の滑らかな弧をつないでできた曲線のことを**区分的に滑らかな**曲線といいます。自己交差せず出発点に戻る閉曲線のことを**単純閉曲線**といいます。

曲線 $C$ は、パラメータ $t\in[a,b]$ を用いて $z(t) = x(t) + iy(t)$ と表せます。単純閉曲線の場合は始点と終点が一致するので $z(a)=z(b)$ です。この表示を使うと、線積分 $\oint_C f(z)\,dz$ は $z=z(t)$、$dz=z'(t)\,dt$ を代入することで、次のように1変数の定積分に帰着させて計算できます。

$$\oint_C f(z)\,dz = \int_a^b f(z(t))\,z'(t)\,dt$$

同様に、実数値関数 $P,Q$ に対する線積分 $\oint_C (P\,dx+Q\,dy)$ も、$x=x(t)$、$y=y(t)$ を代入することで1変数の定積分に帰着させて計算できます。

**コーシーの積分定理**：$f$ が単連結な領域 $D$ で正則で、$C$ が $D$ 内の区分的に滑らかな単純閉曲線ならば、

$$\oint_C f(z)\,dz = 0$$

**証明の概略**：$f=u+iv$、$dz=dx+i\,dy$ とすると、

$$f\,dz = (u+iv)(dx+i\,dy) = u\,dx + iu\,dy + iv\,dx - v\,dy = (u\,dx - v\,dy) + i(v\,dx + u\,dy)$$

より、線積分は

$$\oint_C f\,dz = \oint_C (u\,dx - v\,dy) + i\oint_C (v\,dx + u\,dy)$$

と実部・虚部に分解できます。ここで次の**グリーンの定理**を、証明なしに用います（多変数の微分積分の教科書を参照してください）。

> $C$ が反時計回りに向きづけられた区分的に滑らかな単純閉曲線で、$R$ をその内部とします。$P, Q$ が $R$ と $C$ を含む開集合で $C^1$ 級ならば、
> $$\oint_C (P\,dx+Q\,dy) = \iint_R \left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dA$$
> が成り立ちます（右辺は $R$ 上の2重積分で、$dA$ は面積要素です）。

$C$ を反時計回りに向きづけます（向きを逆にしても積分の符号が変わるだけなので、$0$ になるかどうかには影響しません）。$D$ は単連結なので、$C$ の内部 $R$ は $D$ に含まれ、$f$ は $R$ と $C$ を含む開集合で正則です。$u,v$ が $C^1$ 級であれば、グリーンの定理により、各線積分は $R$ 上の2重積分に書き換えられます（1つ目の積分は $P=u,\,Q=-v$、2つ目の積分は $P=v,\,Q=u$ とした場合にあたります）。

$$\oint_C (u\,dx - v\,dy) = \iint_R \left(-\frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}\right)dA, \qquad \oint_C (v\,dx + u\,dy) = \iint_R \left(\frac{\partial u}{\partial x} - \frac{\partial v}{\partial y}\right)dA$$

$f$ が正則なのでコーシー・リーマン方程式（上で証明済み）$\dfrac{\partial u}{\partial x}=\dfrac{\partial v}{\partial y}$、$\dfrac{\partial u}{\partial y}=-\dfrac{\partial v}{\partial x}$ が成り立ち、これを代入すると両方の被積分関数がゼロになります。よって $\oint_C f\,dz = 0$。$\blacksquare$

（この証明はグリーンの定理を使うため $u,v$ の偏導関数の連続性を仮定していますが、実際にはこの仮定なしでも成り立つことが知られています。この一般の場合の証明はグルサの定理と呼ばれ、三角形分割による別のアプローチが必要になるため、完全な証明は参考文献に譲ります。）

**特異点**とは、$f$ が正則でなくなる点のことで、典型的には $f$ が無限大に発散する**極**です。特異点を囲む場合は、次の**留数定理**が成り立ちます。

**留数定理**：$f$ が単連結な領域 $D$ で、有限個の点 $z_1,\dots,z_m$ を除いて正則であるとします。$C$ が $D$ 内の区分的に滑らかな単純閉曲線で、どの $z_k$ も通らず、反時計回りに向きづけられているならば、

$$\oint_C f(z)\,dz = 2\pi i \sum_k \mathrm{Res}(f, z_k)$$

ここで和は、$C$ の内側にある特異点 $z_k$ についてとります。ローラン級数展開とは、$z_k$ のまわりで $f$ を、負のべきの項も許すべき級数として

$$f(z) = \sum_{n=-\infty}^{\infty} a_n (z-z_k)^n$$

の形に展開することです。**留数** $\mathrm{Res}(f, z_k)$ とは、この展開における $a_{-1}$（すなわち $(z-z_k)^{-1}$ の項の係数）のことです。

特に、$\lim_{z\to z_k}(z-z_k)f(z)$ が0でない有限値として存在する特異点を**単純極**（1位の極）といいます。

この極限条件を満たす特異点のローラン展開には $n\le-2$ の項が存在しないことが知られています（証明は省略します）。この単純極の場合、ローラン級数は $f(z) = \dfrac{a_{-1}}{z-z_k} + a_0 + a_1(z-z_k) + \cdots$ の形になります。両辺に $(z-z_k)$ を掛けて $z\to z_k$ の極限をとると、右辺の $a_0, a_1, \dots$ に対応する項はすべて0に収束して消え、$a_{-1}$ だけが残ります。したがって、$z_k$ が単純極である場合、その留数は次の公式で計算できます（高階の極についてはこの公式は使えず、別の計算が必要になります）。

$$\mathrm{Res}(f, z_k) = \lim_{z \to z_k} (z-z_k) f(z)$$

留数定理は、コーシーの積分定理を特異点を除いた領域に適用することで証明されます。ただし、特異点を除いた領域には穴があいており、単連結ではないので、コーシーの積分定理をそのままでは適用できません。そこで、$C$ の内側の各特異点 $z_k$ を小さな円 $C_k$ で囲み、$C$ と各 $C_k$ を細い通路（橋）でつないで切れ目を入れます。切れ目を入れた領域は単連結で正則なので、その境界にコーシーの積分定理を適用できます。橋の往復部分の積分は打ち消し合うので、$C$ に沿った積分は各 $C_k$ に沿った（反時計回りの）積分の和に等しくなり、各 $C_k$ に沿った積分はローラン級数の $a_{-1}$ の項だけが残って $2\pi i\,\mathrm{Res}(f,z_k)$ になります（ローラン級数の詳細な扱いが必要なため、完全な証明は参考文献に譲ります）。この定理を使うと、実数の範囲では手強い積分が複素関数の理論で計算できます。工学でも、例えば回路や制御の解析で使うラプラス変換の逆変換は複素平面上の線積分で表され、その計算に留数定理が使われます。

**具体例**：留数定理を使うと、実数の広義積分 $\displaystyle\int_{-\infty}^{\infty}\frac{dx}{1+x^2}$ を計算できます。$f(z)=\dfrac{1}{1+z^2}=\dfrac{1}{(z-i)(z+i)}$ とし、実軸上の線分 $[-R,R]$ と、それをつなぐ上半平面の半円弧 $\Gamma_R$（原点中心・半径 $R$）を合わせた閉曲線 $C_R$ を考えます（$R$ は十分大きい正の実数）。

$C_R$ の内部に含まれる特異点は $z=i$ のみで、これは単純極なので、留数は

$$\mathrm{Res}(f, i) = \lim_{z\to i}(z-i)f(z) = \lim_{z\to i}\frac{1}{z+i} = \frac{1}{2i}$$

となり、留数定理より

$$\oint_{C_R} f(z)\,dz = 2\pi i \cdot \frac{1}{2i} = \pi$$

が得られます。半円弧 $\Gamma_R$ 上の積分は $R\to\infty$ で $0$ に収束することが知られているため（詳細な評価は省略します）、$C_R$ 上の積分はこの極限で実軸部分の積分に一致します。したがって、

$$\int_{-\infty}^{\infty}\frac{dx}{1+x^2} = \lim_{R\to\infty}\int_{-R}^{R}\frac{dx}{1+x^2} = \pi$$

**参考文献**：Ahlfors, L. V. (1979). *Complex Analysis* (3rd ed.). McGraw-Hill.（グルサの定理・ローラン級数・留数定理の完全な証明を含む）

## まとめ

複素関数は複素数を入力・出力とする関数で、正則性（$h$ が $0$ にどのように近づいても差分商が同じ値に収束する、という条件が各点のまわりで成り立つこと）という強い条件のもとで、コーシー・リーマン方程式が成り立つことを証明できます。この方程式とグリーンの定理を組み合わせるとコーシーの積分定理が証明でき、これを特異点のまわりに拡張したものが留数定理です。これらは実数の解析学にはない豊かな理論を形作ります。
