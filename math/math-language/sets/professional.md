## ZFC公理系（概要）

| 公理 | 内容 |
|------|------|
| 外延性 | 同じ要素を持つ集合は等しい |
| 空集合 | $\emptyset$ の存在 |
| 対 | $\{a, b\}$ の存在 |
| 冪集合 | $\mathcal{P}(A)$ の存在 |
| 置換 | 写像による集合の像 |
| 選択公理 | 空でない集合族の選択関数の存在 |

---

## 順序数

整列集合の同型類。$0, 1, 2, \ldots, \omega, \omega+1, \ldots, \omega^2, \ldots$

**超限帰納法**: 順序数に対する帰納法。

---

## 基数と連続体仮説

$$|\mathbb{N}| = \aleph_0 < |\mathbb{R}| = 2^{\aleph_0}$$

**連続体仮説**: $2^{\aleph_0} = \aleph_1$（ZFC で独立——証明も反証もできない）
