## 「どんな数でも」を式で表す

「どんな数に0を足しても変わらない」——\
これを毎回「1に0を足しても1」「2に0を足しても2」と確かめるのは大変です。

文字 $a$ を使えば「$a + 0 = a$」と一行で書けます。\
$a$ は「どんな数でも入れられる箱」です。

---

## 文字式で計算する

$a + b$ と $b + a$ はいつも同じ値になります。\
このことを「$a + b = b + a$」と書くと、\
どんな数の組み合わせでも成り立つ事実を一気に表せます。

「7 + 3 = 3 + 7」「100 + 5 = 5 + 100」と個別に確かめなくて済みます。

---

## 展開と因数分解

$(x + 2)(x + 3)$ を計算すると $x^2 + 5x + 6$ になります——これが展開です。\
逆に $x^2 + 5x + 6$ を $(x + 2)(x + 3)$ と書き直すことを因数分解といいます。

どちらも同じ式の「別の見た目」です。\
場面に応じて使いやすい形に変えます。
