## 曲線で囲まれた面積

長方形の面積は縦×横で求められますが、なめらかな曲線と $x$ 軸の間の面積は定規では測れません。曲線の下の領域を細い長方形で埋めていき、長方形を無限に細くした極限——それが**積分**です。

$$\text{積分} = \text{面積} = \text{無限に細かくした長方形の和の極限}$$

速さが変化しながら走るとき、細かい時間ごとに「速さ×短い時間」を足し合わせていくと走った距離に近づきます。積分は「変化し続ける量を積み重ねた総量」を求める操作でもあります。

---

## 定積分の定義

区間 $[a, b]$ を $n$ 等分し、幅 $\Delta x = \frac{b-a}{n}$ の小区間に分けます。各小区間から代表点 $x_k$（$k$ 番目の小区間内から選んだ点）をとり、高さ $f(x_k)$、幅 $\Delta x$ の長方形で近似します。$f$ が連続な場合、代表点として左端・右端・区間内の任意の点のいずれを選んでも、$n \to \infty$ の極限では同じ値に収束します。

$$\int_a^b f(x)\,dx = \lim_{n \to \infty} \sum_{k=1}^n f(x_k)\,\Delta x$$

これが $f$ の $a$ から $b$ までの**定積分**であり、グラフと $x$ 軸で囲まれた面積を表します（$f \geq 0$ の場合）。

---

## 不定積分と原始関数

$F'(x) = f(x)$ を満たす $F(x)$ を $f(x)$ の**原始関数**といい、

$$\int f(x)\,dx = F(x) + C$$

と書きます（$C$ は任意定数）。

| $f(x)$ | $\int f(x)\,dx$ |
|--------|----------------|
| $x^n$ ($n \neq -1$) | $\dfrac{x^{n+1}}{n+1} + C$（$n=-1$だと分母が$0$になるため除外し、下の$\frac1x$の場合を別に扱います） |
| $\dfrac{1}{x}$ | $\ln\lvert x\rvert + C$ |
| $e^x$ | $e^x + C$ |
| $\sin x$ | $-\cos x + C$ |
| $\cos x$ | $\sin x + C$ |

微分の和・定数倍の規則 $(f+g)'=f'+g'$、$(\alpha f)'=\alpha f'$ に対応して、不定積分にも同様の線形性 $\int\{af(x)+bg(x)\}\,dx=a\int f(x)\,dx+b\int g(x)\,dx$ が成り立ちます。

## 微積分学の基本定理

「速さを積み重ねると距離」「距離を微分すると速さに戻る」——微分と積分は逆の操作です。曲線の傾き（微分）と面積（積分）が逆関係にあるという事実は、数学史上最大の発見のひとつで、**微積分学の基本定理**といいます。

この関係を簡単に確かめます。$a$ から $x$ までの面積を $A(x)=\int_a^x f(t)\,dt$ とおきます（上限の $x$ と区別するため、被積分関数側の変数には $t$ を使います）。$x$ を微小量 $h$ だけ増やしたときの面積の増分は、幅 $h$・高さ $f(x)$ の細い長方形とみなせるので $A(x+h)-A(x)\approx f(x)h$ となります。両辺を $h$ で割ると

$$\frac{A(x+h)-A(x)}{h}\approx f(x)$$

$h\to0$ の極限をとると、左辺は導関数の定義そのものなので $A'(x)=f(x)$ が得られ、$A(x)$ も $f$ の原始関数の一つだとわかります。原始関数どうしは定数だけ異なるので $A(x)=F(x)+C$ と書けます。ここで $A(a)=\int_a^a f(t)\,dt=0$ です（積分区間の幅が0だから）。$A(x)=F(x)+C$ に $x=a$ を代入すると $0=F(a)+C$ となるので、

$$C=-F(a)$$

したがって

$$A(b)=F(b)-F(a)$$

が導かれます。

$$\int_a^b f(x)\,dx = F(b) - F(a) \quad \text{（$F'(x) = f(x)$ とする）}$$

面積の計算が、原始関数に端点を代入する操作に変わります。

**例**：$\displaystyle\int_0^2 x^2\,dx = \left[\frac{x^3}{3}\right]_0^2 = \frac{8}{3}$

## 計算技法

**置換積分**：$u = g(x)$ と置き、積分を変数変換します。$u=x^2$ とおくと $\dfrac{du}{dx}=2x$ なので $du=2x\,dx$。これを使うと、もとの積分の $2x\,dx$ の部分をそのまま $du$ に置き換えられます。

$$\int 2x\cos(x^2)\,dx = \int \cos(x^2)\cdot(2x\,dx) \xrightarrow{u=x^2,\ du=2x\,dx} \int \cos u\,du = \sin u + C = \sin(x^2) + C$$

矢印の上に書いた $u=x^2,\ du=2x\,dx$ は、その箇所で行った置き換えを表す注記です。

**部分積分**：積の微分法則 $(fg)'=f'g+fg'$ の両辺を積分すると、次の式が得られます。

$$fg=\int f'g\,dx+\int fg'\,dx$$

両辺から $\int f'g\,dx$ を引いて $\int fg'\,dx$ について整理すると、次の公式が得られます。

$$\int f g'\,dx = fg - \int f'g\,dx$$

**例**：$f(x)=x$、$g'(x)=e^x$ とおくと $f'(x)=1$、$g(x)=e^x$ なので、

$$\displaystyle\int x e^x\,dx = xe^x - \int e^x\,dx = (x-1)e^x + C$$

## 回転体の体積

区間 $[a,b]$ で $y=f(x)$ と $x$ 軸に囲まれた図形を、$x$ 軸のまわりに1回転させてできる立体（**回転体**）の体積は、次の式で求められます。

$$V = \pi\int_a^b \{f(x)\}^2\,dx$$

これは、$x$ を固定するたびにできる半径 $f(x)$ の円（断面積 $\pi\{f(x)\}^2$）を、$a$ から $b$ まで積み重ねたものと考えられます。

**例題**：$y=\sqrt{x}$（$0\leq x\leq 4$）と $x$ 軸で囲まれた図形を $x$ 軸のまわりに回転させた体積を求める。

$$V = \pi\int_0^4 (\sqrt{x})^2\,dx = \pi\int_0^4 x\,dx = \pi\left[\frac{x^2}{2}\right]_0^4 = 8\pi$$

## 曲線の長さ

$x$、$y$ をともに別の変数 $t$ の関数として $x=f(t)$、$y=g(t)$（$a\leq t\leq b$）と表す（[媒介変数表示](derivatives-applications.md)）と、曲線の長さは次の式で求められます。

$$L = \int_a^b \sqrt{\{f'(t)\}^2+\{g'(t)\}^2}\,dt$$

これは、曲線を微小な直線の断片に分け、三平方の定理でそれぞれの長さを求めて足し合わせた極限と考えられます。

**例題**：半径 $r$ の円 $x=r\cos t,\ y=r\sin t$（$0\leq t\leq 2\pi$）の全周を求める。

$$f'(t)=-r\sin t,\quad g'(t)=r\cos t$$

$$L = \int_0^{2\pi}\sqrt{r^2\sin^2 t+r^2\cos^2 t}\,dt = \int_0^{2\pi} r\,dt = 2\pi r$$

円周の公式 $2\pi r$ と一致します。

---

## まとめ

積分は「細い長方形を無限に足し合わせた極限」として面積や累積量を求める操作です。微積分学の基本定理により、原始関数を使って定積分を計算でき、置換積分・部分積分で計算の幅が広がります。さらに、これらを応用して回転体の体積や曲線の長さも積分で求められます。
