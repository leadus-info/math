## 対数微分法

$f(x) = x^x$ のように、変数どうしがべき乗になっている関数は、そのままでは基本的な導関数の公式が使えません。両辺の対数をとってから微分する**対数微分法**を使います。なお、対数をとるには $y>0$ であることが前提になります(一般に $y$ の符号が定まらない場合は $\ln|y|$ を使います)。

**例題**：$y=x^x$（$x>0$）の導関数を求める。

両辺の自然対数をとると、

$$\ln y = x\ln x$$

$y$ を $x$ の関数とみると、左辺 $\ln y$ は合成関数 $\ln(y(x))$ とみなせます。

左辺を微分すると、連鎖律より $(\ln y)' = \dfrac{1}{y}\cdot y' = \dfrac{y'}{y}$ となります。

右辺を微分すると、積の微分公式より $(x\ln x)' = \ln x + 1$ となります。

よって両辺を $x$ で微分すると、

$$\frac{y'}{y} = \ln x + 1$$

これより、

$$y' = y(\ln x+1) = x^x(\ln x+1)$$

累乗の指数に変数が含まれる関数や、積・商が複雑に絡む関数の微分でも、対数をとることで計算が簡単になることがあります。

**例**：$y=\dfrac{x^2(x-1)}{\sqrt{x+1}}$（$x>1$）の導関数を求める。両辺の自然対数をとると、商・積・べきの対数の性質により次のように展開できます。

$$\ln y = \ln\frac{x^2(x-1)}{\sqrt{x+1}} = \ln(x^2(x-1)) - \ln\sqrt{x+1} = 2\ln x + \ln(x-1) - \frac12 \ln(x+1)$$

両辺を $x$ で微分すると、左辺は対数微分法の要領で $\dfrac{y'}{y}$、右辺は各項を個別に微分し（$2\ln x$ は定数倍の微分、$\ln(x-1)$・$\ln(x+1)$ は連鎖律）、

$$\frac{y'}{y} = \frac{2}{x} + \frac{1}{x-1} - \frac{1}{2(x+1)}$$

よって、

$$y' = y\left(\frac{2}{x} + \frac{1}{x-1} - \frac{1}{2(x+1)}\right)$$

## 逆関数の導関数

$y=f(x)$ の（$f$ が1対1対応であるとき定まる）[逆関数](functions.md) $x=f^{-1}(y)$ について、次の関係が成り立ちます。

$$\frac{dy}{dx} = \frac{1}{\dfrac{dx}{dy}}$$

これは次のようにして得られます。恒等式 $x=f^{-1}(f(x))$ の両辺を $x$ で微分すると、左辺は $x$ を $x$ で微分するので $1$、右辺は $y=f(x)$ とみて連鎖律を適用すると $\dfrac{dx}{dy}\cdot\dfrac{dy}{dx}$ となるので、

$$1 = \frac{dx}{dy}\cdot\frac{dy}{dx}$$

が得られます。両辺を $\dfrac{dx}{dy}$（$\neq0$）で割ると、上の関係式が得られます。

**例**：$x=y^3+y$ で定まる関係を考える。$\dfrac{dx}{dy}=3y^2+1$ は常に正なので、$x$ は $y$ の単調増加関数です。単調な関数は逆関数を持つ、という[前提記事](functions.md)の議論より、この関係は $y$ を $x$ の関数として定めます。ただし、これを $y=(\text{$x$の式})$ の形に具体的に解くのは（三次方程式を解く必要があり）容易ではないため、$y$ を $x$ の具体的な式として直接微分することはできません。そこで上の関係式を使うと、$y$ を陽に求めずに $\dfrac{dy}{dx}$ を計算できます。例えば $x=2$ のとき（$1^3+1=2$ より $y=1$）、$\dfrac{dx}{dy}\bigg|_{y=1}=3(1)^2+1=4$ なので $\dfrac{dy}{dx}\bigg|_{x=2} = \dfrac{1}{4}$ となります。

## 媒介変数で表された関数の導関数

$x$、$y$ がともに $t$ の関数として $x=f(t)$、$y=g(t)$ と表される（**媒介変数表示**）とき、

$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{g'(t)}{f'(t)}$$

これは、連鎖律 $\dfrac{dy}{dt} = \dfrac{dy}{dx}\cdot\dfrac{dx}{dt}$ の両辺を $\dfrac{dx}{dt}$（$\neq0$）で割ることで得られます。

**例題**：$x=\cos t$、$y=\sin t$ のとき $\dfrac{dy}{dx}$ を求める。$\dfrac{dx}{dt}=-\sin t$、$\dfrac{dy}{dt}=\cos t$ なので $\dfrac{dy}{dx} = \dfrac{\cos t}{-\sin t} = -\dfrac{1}{\tan t}$。

## 第2次導関数と変曲点

導関数 $f'(x)$ をさらに微分したものを**第2次導関数**といい、$f''(x)$ と書きます。

- $f''(x) > 0$：グラフは下に凸（$\cup$ 型に曲がる）
- $f''(x) < 0$：グラフは上に凸（$\cap$ 型に曲がる）
- $f''(x)$ の符号が変わる点：**変曲点**（凹凸が入れ替わる点）

**例題**：$f(x)=x^3-3x$ の変曲点を求める。$f'(x)=3x^2-3$、$f''(x)=6x$。$f''(x)=0$ となるのは $x=0$ で、この前後で符号が変わるので $(0, f(0))=(0,0)$ が変曲点。

## 平均値の定理

**平均値の定理**：関数 $f$ が閉区間 $[a,b]$ で連続、開区間 $(a,b)$ で微分可能なとき、

$$f'(c) = \frac{f(b)-f(a)}{b-a}$$

を満たす $c$ が $(a,b)$ の中に少なくとも1つ存在する。

これは「平均の変化率と等しい傾きの接線が、区間のどこかに必ずある」ということを意味します。この定理を使うと、$f'(x)>0$ が区間全体で成り立てば $f$ がその区間で増加することを、厳密に示せます。実際、区間内の任意の2点 $x_1<x_2$ に平均値の定理を適用すると、$f(x_2)-f(x_1) = f'(c)(x_2-x_1)$ となる $c$ が存在します。この $c$ は $c\in(x_1,x_2)\subset(a,b)$ を満たし、前提より区間 $(a,b)$ 全体で $f'(x)>0$ が成り立つから $f'(c)>0$ です。$f'(c)>0$ かつ $x_2-x_1>0$ なので $f(x_2)-f(x_1)>0$、すなわち $f(x_2)>f(x_1)$ が言えます。

## まとめ

このページでは、次の技法を扱いました。

- **対数微分法**：指数に変数を含む関数や、積・商が複雑に絡む関数の微分に使います。
- **逆関数の導関数**：逆関数 $x=f^{-1}(y)$ を経由して、$y=f(x)$ の導関数を求めるときに使います。
- **媒介変数表示の導関数**：$x$、$y$ がともに別の変数 $t$ の関数として表されているときに使います。
- **第2次導関数**：グラフの凹凸・変曲点を特徴づけます。
- **平均値の定理**：「平均の変化率と等しい傾きの点が区間内に必ず存在する」ことを保証します。
