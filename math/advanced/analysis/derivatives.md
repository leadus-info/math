## 「今この瞬間の速さ」とは

車が2時間で100km走ったとき、「平均の速さ」は時速50kmです。でも、実際には信号で止まったり、高速道路で加速したりしているはずです。スピードメーターが示す「今この瞬間の速さ」とは、いったい何を意味するのでしょうか。

1時間での平均 → 30分での平均 → 1秒での平均……。時間の幅を限りなく短くしていくと、「平均の速さ」は「瞬間の速さ」に近づいていきます。この「無限に短い時間幅での変化率」を求める操作が**微分**です。

グラフ上の2点を直線で結ぶと「平均の変化率」が傾きとして現れます。2点を限りなく近づけたとき、この直線は最終的にグラフに「接する」直線（**接線**）になります。

$$\text{微分} = \text{接線の傾き}$$

---

## 微分の定義

**定義**：関数 $f(x)$ の $x = a$ における**微分係数**を次で定めます。

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

この極限が存在するとき $f$ は $x = a$ で**微分可能**といいます。$a$ を変数と見た関数 $f'(x)$ を**導関数**といいます。

---

## ネイピア数 $e$

指数関数 $a^x$（$a>0$、$a \neq 1$）を定義に従って微分してみます。

$$(a^x)' = \lim_{h \to 0}\frac{a^{x+h}-a^x}{h} = a^x\lim_{h \to 0}\frac{a^h-1}{h}$$

残った極限 $\lim_{h \to 0}\dfrac{a^h-1}{h}$ の値は底 $a$ によって変わります。この値がちょうど $1$ になる特別な底を**ネイピア数**といい、$e$ で表します。

この $e$ が具体的にどんな値かを求めてみます。目標は、$\lim_{h \to 0}\dfrac{a^h-1}{h}=1$ を満たす $a$ を特定することです。

$h=\dfrac1n$ とおくと（$h \to 0$ は $n \to \infty$ に対応します）、$h$ が $0$ に近いとき $\dfrac{a^h-1}{h}\approx 1$ という近似的な関係が成り立ち、これは $a^{1/n}-1 \approx \dfrac1n$ と書き換えられます。両辺に $1$ を足すと $a^{1/n} \approx 1+\dfrac1n$、さらに両辺を $n$ 乗すると $a \approx \left(1+\dfrac1n\right)^n$ となります。ただし、これはあくまで $h\to0$（$n\to\infty$）の極限で $\dfrac{a^h-1}{h}\to1$ となるという意味であり、有限の $n$ について厳密に等号 $a = \left(1+\dfrac1n\right)^n$ が成り立つわけではないことに注意してください。

そこで、有限の $n$ について数列 $a_n = \left(1+\dfrac1n\right)^n$ を考え、$n\to\infty$ の極限としてネイピア数 $e$ を定義します。

$$e = \lim_{n\to\infty}\left(1+\frac{1}{n}\right)^n \approx 2.71828\ldots$$

（実際にこの数列の極限が、もとの条件 $\lim_{h \to 0}\dfrac{a^h-1}{h}=1$ を満たす $a$ になっていることが確かめられます。）

底を $e$ に選ぶと $\lim_{h \to 0}\dfrac{e^h-1}{h}=1$ となるので、

$$(e^x)' = e^x$$

「微分しても変わらない」という特別な性質を持つのが $e^x$ です。量の変化率がその量自身に比例する（$y'=y$）現象は、$e^x$ がまさにその関係を満たす関数であるため、成長・減衰のモデルとして自然に登場します。

## 自然対数 $\ln$

底が $e$ の対数を**自然対数**といい、$\ln x = \log_e x$ と書きます。

$\ln x$ を定義に従って微分すると

$$(\ln x)' = \lim_{h \to 0}\frac{\ln(x+h)-\ln x}{h}$$

対数の商の法則 $\ln A - \ln B = \ln\dfrac{A}{B}$ により $\ln(x+h)-\ln x = \ln\dfrac{x+h}{x} = \ln\left(1+\dfrac hx\right)$ と変形できるので、

$$(\ln x)' = \lim_{h \to 0}\frac{1}{h}\ln\left(1+\frac{h}{x}\right)$$

$t = h/x$ とおくと $h \to 0$ のとき $t \to 0$ で、

$$(\ln x)' = \lim_{t \to 0}\frac{1}{xt}\ln(1+t) = \frac{1}{x}\lim_{t \to 0}\ln(1+t)^{1/t} = \frac{1}{x}\ln e = \frac{1}{x}$$

（対数法則 $k\ln a = \ln a^k$ により $\dfrac1t\ln(1+t) = \ln(1+t)^{1/t}$ と変形しています。また、前節では $n$ が自然数の場合（$t=1/n>0$、すなわち片側）として $e$ を定義しましたが、$n$ が自然数の場合と同様に、$t\to0^-$ の場合も含めて $\lim_{t \to 0}(1+t)^{1/t}=e$ が成り立つことが知られています（証明は本記事の範囲を超えるため省略します）。）したがって

$$(\ln x)' = \frac{1}{x}, \quad \int \frac{1}{x}\,dx = \ln|x| + C$$

積分は微分の逆操作であり、詳細は別記事[積分](integrals.md)で扱います。

## 三角関数の微分

$\sin x$ を定義に従って微分します。加法定理 $\sin(x+h) = \sin x\cos h + \cos x\sin h$ より

$$\sin(x+h)-\sin x = \sin x(\cos h - 1) + \cos x\sin h$$

と書けるので、

$$(\sin x)' = \lim_{h \to 0}\frac{\sin(x+h)-\sin x}{h} = \sin x\cdot\lim_{h \to 0}\frac{\cos h - 1}{h} + \cos x\cdot\lim_{h \to 0}\frac{\sin h}{h}$$

$\lim_{h \to 0}\dfrac{\sin h}{h} = 1$ に加えて、$\lim_{h \to 0}\dfrac{\cos h - 1}{h}=0$ も成り立ちます。これは次のように確かめられます。

半角の公式より $\cos h - 1 = -2\sin^2\dfrac h2$ と書けるので、

$$\frac{\cos h-1}{h} = -\sin\frac h2\cdot\frac{\sin(h/2)}{h/2}$$

$h\to0$ のとき $\sin\dfrac h2\to0$ かつ $\dfrac{\sin(h/2)}{h/2}\to1$ なので、右辺全体は $0$ に収束します。

したがって

$$(\sin x)' = \sin x\cdot 0 + \cos x\cdot 1 = \cos x$$

と導けます。同様の計算から $(\cos x)' = -\sin x$ が成り立ちます。

$\tan x = \dfrac{\sin x}{\cos x}$ の微分は、後述の「計算規則」で扱う商の微分法則を先取りして使うと

$$(\tan x)' = \frac{(\sin x)'\cos x - \sin x(\cos x)'}{\cos^2 x} = \frac{\cos^2 x + \sin^2 x}{\cos^2 x} = \frac{1}{\cos^2 x}$$

と導けます。

## べき関数の微分

$x^n$ の導関数も、定義に従って導けます。$n=2$ の場合、

$$(x^2)' = \lim_{h\to0}\frac{(x+h)^2-x^2}{h} = \lim_{h\to0}\frac{2xh+h^2}{h} = \lim_{h\to0}(2x+h) = 2x$$

$n=3$ の場合も同様に、$(x+h)^3=x^3+3x^2h+3xh^2+h^3$ を使うと、

$$(x^3)' = \lim_{h\to0}\frac{3x^2h+3xh^2+h^3}{h} = \lim_{h\to0}(3x^2+3xh+h^2) = 3x^2$$

一般に、$n$ が自然数のときも同じように $(x+h)^n$ を展開すると、$h$ の1次の項は $nx^{n-1}h$ で、それ以外は $h^2$ 以上を含むため $h\to0$ で消えます。よって $(x^n)'=nx^{n-1}$ が成り立ちます。

この二項展開による証明は $n$ が自然数の場合に限られますが、証明は省略するものの、この公式は $n$ が実数一般（負の数や分数の指数を含む）のときも成立することが知られています。例えば $n=-1$ のとき $\left(\dfrac1x\right)' = -\dfrac{1}{x^2}$ となり、公式 $nx^{n-1}$ に $n=-1$ を代入した結果と一致します。

## 基本的な導関数

| $f(x)$ | $f'(x)$ | 補足 |
|--------|---------|------|
| 定数 $c$ | $0$ | 変化しない |
| $x^n$ | $nx^{n-1}$ | $n$ は実数一般で成立 |
| $e^x$ | $e^x$ | 微分しても変わらない |
| $\ln x$ | $\dfrac{1}{x}$ | $x > 0$ で定義 |
| $\sin x$ | $\cos x$ | |
| $\cos x$ | $-\sin x$ | |

**例**：$f(x) = x^3$ のとき $f'(x) = 3x^2$。$f'(2) = 12$（$x=2$ での接線の傾き）。

## 接線の方程式

グラフ上の点 $(a, f(a))$ における接線は、傾きが $f'(a)$ で、その点を通る直線なので、次の式で表せます。

$$y - f(a) = f'(a)(x - a)$$

接点 $a$ の近くでは $f(a+h) \approx f(a) + f'(a)h$ という近似が成り立つため、接線は一般に、グラフに接点付近でよく近似する直線になります。

**例題**：$f(x) = x^2$ のグラフ上、$x=1$ の点における接線の方程式を求める。$f(1) = 1$、$f'(x) = 2x$ より $f'(1) = 2$。

$$y - 1 = 2(x - 1) \implies y = 2x - 1$$

**例題**：$f(x) = \sin x$ のグラフ上、$x=0$ の点における接線の方程式を求める。$f(0) = 0$、$f'(x) = \cos x$ より $f'(0) = 1$。

$$y - 0 = 1 \cdot (x - 0) \implies y = x$$

原点付近で $\sin x$ のグラフと直線 $y=x$ がほとんど重なって見えるのは、まさにこの近似的性質の具体例であり、接線がグラフに接点付近でよく近似することを表しています。

## 計算規則

**和の微分**：$(f + g)' = f' + g'$、$(\alpha f)' = \alpha f'$。これは極限の線形性（$\lim(f+g)=\lim f+\lim g$、$\lim(\alpha f)=\alpha\lim f$）から直ちに従います。

**積の微分法則**：$(fg)' = f'g + fg'$

定義に従って導いてみます。分子 $f(x+h)g(x+h)-f(x)g(x)$ を、次のように差を分解します。

$$f(x+h)g(x+h)-f(x)g(x) = \big[f(x+h)g(x+h)-f(x+h)g(x)\big] + \big[f(x+h)g(x)-f(x)g(x)\big]$$

$$= f(x+h)\big[g(x+h)-g(x)\big] + \big[f(x+h)-f(x)\big]g(x)$$

両辺を $h$ で割って $h\to0$ の極限をとると、$f(x+h)\to f(x)$（$f$ は微分可能なので連続）、$\dfrac{g(x+h)-g(x)}{h}\to g'(x)$、$\dfrac{f(x+h)-f(x)}{h}\to f'(x)$ より

$$(fg)' = fg' + f'g$$

が得られます。

**例**：$(x^2 \sin x)' = 2x\sin x + x^2\cos x$

**商の微分法則**：$\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$

この公式は、積の法則と連鎖律（または $g(x)^{-1}$ の微分）から導けます。

**例**：$\left(\dfrac{\sin x}{x}\right)' = \dfrac{x\cos x - \sin x}{x^2}$

**連鎖律**（合成関数）：$(f(g(x)))' = f'(g(x)) \cdot g'(x)$

（証明には $\epsilon$-$\delta$ 論法的な精密な扱いが必要なため、本記事では結果のみ示します。）

**例**：$(\sin(x^2))' = \cos(x^2) \cdot 2x$

## 増減と極値

$f'(a) > 0$ なら $x = a$ 付近で増加、$f'(a) < 0$ なら減少、$f'(a) = 0$ なら**極値の候補**です。

**定理**：$f'(a) = 0$ かつ前後で $f'$ の符号が変わるとき、$f(a)$ は極大値または極小値。

**例題**：$f(x) = x^3 - 3x$ の極値を求める。$f'(x) = 3x^2 - 3 = 3(x+1)(x-1) = 0 \Rightarrow x = \pm 1$。増減表は次のようになります。

| $x$ | $\cdots$ | $-1$ | $\cdots$ | $1$ | $\cdots$ |
|---|---|---|---|---|---|
| $f'(x)$ | $+$ | $0$ | $-$ | $0$ | $+$ |
| $f(x)$ | 増加 | 極大 $2$ | 減少 | 極小 $-2$ | 増加 |

よって $x=-1$ で極大値 $f(-1)=2$、$x=1$ で極小値 $f(1)=-2$。

## どんなところで使われるか

- 物理：速さ・加速度の計算
- 経済：「もう1個作ると収益がどれだけ増えるか」（限界費用）
- 機械学習：誤差が最小になるパラメータを探す方向

---

## まとめ

微分は「瞬間の変化率」を求める操作で、極限として定義されます。基本的な導関数と積・商・連鎖律などの計算規則を使うと、様々な関数の導関数を求められ、増減・極値の解析に応用できます。
