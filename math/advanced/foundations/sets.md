## 「ものの集まり」を扱う

「クラスの生徒全員」「今日の最高気温が30度以上だった日」——こうした「ものの集まり」を数学的に扱う道具が**集合**です。

集合で大切なのは、**何が含まれて何が含まれないかが明確なこと**です。「背の高い人の集合」は「どこから高いのか」が曖昧なので、数学的な集合としては扱いにくいですが、「身長170cm以上の人の集合」なら明確です。

## 集合の記法

**列挙記法**：要素を直接並べる。$A = \{1, 2, 3, 4, 5\}$

**内包記法**：条件で定義する。$B = \{x \mid x \text{ は10以下の偶数}\} = \{2, 4, 6, 8, 10\}$

$3 \in A$（3は $A$ の要素）、$6 \notin A$（6は $A$ の要素でない）。

| 記号 | 集合 | 例 |
|------|------|----|
| $\mathbb{N}$ | 自然数全体 | $\{1, 2, 3, \ldots\}$ |
| $\mathbb{Z}$ | 整数全体 | $\{\ldots, -2, -1, 0, 1, 2, \ldots\}$ |
| $\mathbb{Q}$ | 有理数全体 | $\frac{p}{q}$（$p, q$は整数、$q \neq 0$）の形 |
| $\mathbb{R}$ | 実数全体 | 数直線上のすべての点 |
| $\emptyset$ | 空集合 | 要素が1つもない集合 |

包含関係：$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$（$\subset$は一方の集合がもう一方にすべて含まれることを表す記号で、詳しくは後述の「部分集合」で扱います）

## 集合の3つの基本操作

クラスを例に考えます。$P$：「数学が好きな生徒の集合」、$Q$：「理科が好きな生徒の集合」

**和集合**（$P \cup Q$）——どちらかが好きな生徒全員。一般に $A \cup B = \{x \mid x \in A \text{ または } x \in B\}$ と定義されます。数の集合 $A = \{1, 2, 3, 4, 5\}$、$B = \{2, 4, 6, 8, 10\}$ で計算すると、$A \cup B = \{1, 2, 3, 4, 5, 6, 8, 10\}$ となります。

**共通部分**（$P \cap Q$）——両方が好きな生徒だけ。一般に $A \cap B = \{x \mid x \in A \text{ かつ } x \in B\}$ と定義されます。同じ $A, B$ で計算すると、$A \cap B = \{2, 4\}$ となります。

**補集合**（$P^c$）——数学が好きでない生徒（クラス全体から $P$ を除いた部分）。考えている対象全体の集合を**全体集合**（ここではクラス全体）と呼び、$U$ を全体集合とすると一般に $A^c = \{x \in U \mid x \notin A\}$ と定義されます。全体集合を $U = \{1, 2, \ldots, 10\}$、$A = \{1, 2, 3, 4, 5\}$ とすると、$A^c = \{6, 7, 8, 9, 10\}$ となります。

## 部分集合

「$A$ のすべての要素が $B$ にも属する」とき、$A$ は $B$ の**部分集合**といい、$A \subset B$ と書きます。「正三角形の集合」は「二等辺三角形の集合」の部分集合です（正三角形はすべて二等辺三角形でもあるため）。

## 演算の法則

**交換律**：$A \cup B = B \cup A$、$A \cap B = B \cap A$

**結合律**：$(A \cup B) \cup C = A \cup (B \cup C)$

**分配律**：$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$、$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$

例えば $P$：「数学が好き」、$Q$：「理科が好き」、$R$：「英語が好き」とします。\
1つ目の分配律 $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ は、左辺の「数学が好きで、かつ理科か英語が好き」な生徒の集まりが、右辺の「数学と理科の両方が好き」な生徒と「数学と英語の両方が好き」な生徒を合わせた集まりに一致することを表しています。\
2つ目の分配律 $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ は、左辺の「数学が好き、または理科と英語の両方が好き」な生徒の集まりが、右辺の「数学か理科のどちらかが好き」な生徒と「数学か英語のどちらかが好き」な生徒に共通する生徒の集まりに一致することを表しています。

**ド・モルガンの法則**：

$$(A \cup B)^c = A^c \cap B^c, \quad (A \cap B)^c = A^c \cup B^c$$

$(A \cup B)^c = A^c \cap B^c$ は「AまたはBでない」$=$「Aでない かつ Bでない」という直感に対応します。$(A \cap B)^c = A^c \cup B^c$ は「AかつBでない」$=$「Aでない またはBでない」という直感にも対応します。

---

## まとめ

集合は「はっきり決まるものの集まり」です。和集合・共通部分・補集合の3操作が基本で、ド・モルガンの法則で否定と演算が結びつきます。
