## 「ものの集まり」を扱う

「クラスの生徒全員」「今日の最高気温が30度以上だった日」——こうした「ものの集まり」を数学的に扱う道具が**集合**です。

集合で大切なのは、**何が含まれて何が含まれないかが明確なこと**です。「背の高い人の集合」は「どこから高いのか」が曖昧なので、数学的な集合としては扱いにくいですが、「身長170cm以上の人の集合」なら明確です。

## 集合の記法

**列挙記法**：要素を直接並べる。$A = \{1, 2, 3, 4, 5\}$

$3 \in A$（$3$ は $A$ の要素）、$6 \notin A$（$6$ は $A$ の要素でない）。

2つの集合の要素がまったく同じとき、2つの集合は**等しい**といい、等号 $=$ で結んで表します。\
等しいことを確かめるには、一方の要素がすべて他方の要素でもあり、他方の要素もすべて一方の要素でもあることを確かめます。

**内包記法**：条件で定義する（記号 $\mid$ は「〜を満たす」という意味です）。$B = \{x \mid x \text{ は } 10 \text{ 以下の正の偶数}\} = \{2, 4, 6, 8, 10\}$

| 記号 | 集合 | 例 |
|------|------|----|
| $\mathbb{N}$ | 自然数全体 | $\{1, 2, 3, \ldots\}$ |
| $\mathbb{Z}$ | 整数全体 | $\{\ldots, -2, -1, 0, 1, 2, \ldots\}$ |
| $\mathbb{Q}$ | 有理数全体 | $\frac{p}{q}$（$p, q$は整数、$q \neq 0$）の形 |
| $\mathbb{R}$ | 実数全体 | 数直線上のすべての点 |
| $\emptyset$ | 空集合 | 要素が1つもない集合 |

包含関係：$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$（$\subset$は等号を許さない包含関係を表す記号で、詳しくは後述の「部分集合」で、等号を許す $\subseteq$ との使い分けとあわせて扱います）

## 集合の3つの基本操作

クラスを例に考えます。$P$：「数学が好きな生徒の集合」、$Q$：「理科が好きな生徒の集合」

**和集合**（$P \cup Q$）——どちらかが好きな生徒全員。一般に $A \cup B = \{x \mid x \in A \text{ または } x \in B\}$ と定義されます。数の集合 $A = \{1, 2, 3, 4, 5\}$、$B = \{2, 4, 6, 8, 10\}$ で計算すると、$A \cup B = \{1, 2, 3, 4, 5, 6, 8, 10\}$ となります。

**共通部分**（$P \cap Q$）——両方が好きな生徒だけ。一般に $A \cap B = \{x \mid x \in A \text{ かつ } x \in B\}$ と定義されます。同じ $A, B$ で計算すると、$A \cap B = \{2, 4\}$ となります。

**補集合**（$P^c$）——数学が好きでない生徒（クラス全体から $P$ を除いた部分）。考えている対象全体の集合を**全体集合**（ここではクラス全体）と呼び、$U$ を全体集合とすると一般に $A^c = \{x \in U \mid x \notin A\}$ と定義されます。ここでは数の集合で具体的に確認します。全体集合を $U = \{1, 2, \ldots, 10\}$、$A = \{1, 2, 3, 4, 5\}$ とすると、$A^c = \{6, 7, 8, 9, 10\}$ となります。

## 部分集合

「$A$ のすべての要素が $B$ にも属する」とき、$A$ は $B$ の**部分集合**といい、$A \subseteq B$ と書きます。この定義は $A = B$ となる場合も含みます。特に $A \subseteq B$ かつ $A \neq B$ であるとき、$A$ は $B$ の**真部分集合**といい、$A \subset B$ と書きます。$A$＝正三角形の集合、$B$＝二等辺三角形の集合とすると、正三角形はすべて二等辺三角形でもあるため $A \subseteq B$ です。一方、二等辺三角形には正三角形でないものも存在するため、$A$ と $B$ は集合として一致しません（$A \neq B$）。したがって、これは真部分集合の例になっています。

## 演算の法則

**交換律**：$A \cup B = B \cup A$、$A \cap B = B \cap A$

**結合律**：$(A \cup B) \cup C = A \cup (B \cup C)$、$(A \cap B) \cap C = A \cap (B \cap C)$

**分配律**：$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$、$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$

例えば $P$：「数学が好き」、$Q$：「理科が好き」、$R$：「英語が好き」とします。

1つ目の分配律 $P \cap (Q \cup R) = (P \cap Q) \cup (P \cap R)$ は、次のように対応しています。

- 左辺：「数学が好きで、かつ理科か英語が好き」な生徒の集まり
- 右辺：「数学と理科の両方が好き」な生徒と「数学と英語の両方が好き」な生徒を合わせた集まり

2つ目の分配律 $P \cup (Q \cap R) = (P \cup Q) \cap (P \cup R)$ は、次のように対応しています。

- 左辺：「数学が好き、または理科と英語の両方が好き」な生徒の集まり
- 右辺：「数学か理科のどちらかが好き」な生徒と「数学か英語のどちらかが好き」な生徒に共通する生徒の集まり

数の集合でも確認してみましょう。$P = \{1, 2, 3\}$、$Q = \{2, 3, 4\}$、$R = \{3, 4, 5\}$ とすると、左辺は $Q \cap R = \{3, 4\}$ より $P \cup (Q \cap R) = \{1, 2, 3, 4\}$、右辺は $P \cup Q = \{1, 2, 3, 4\}$、$P \cup R = \{1, 2, 3, 4, 5\}$ より $(P \cup Q) \cap (P \cup R) = \{1, 2, 3, 4\}$ となり、両辺が一致することが確認できます。

## ド・モルガンの法則

補集合と和集合・共通部分の間には、次の**ド・モルガンの法則**が成り立ちます。

$$(A \cup B)^c = A^c \cap B^c, \quad (A \cap B)^c = A^c \cup B^c$$

$x \in A^c$ は、「$x$ は $A$ に属さない」ことを表します。\
この読み方を使うと、1つ目の法則は、「$x$ は $A$ と $B$ の少なくとも一方に属する」ことが成り立たないのは、$x$ が $A$ にも $B$ にも属さないときだ、という意味になります。\
2つ目の法則は、「$x$ は $A$ と $B$ の両方に属する」ことが成り立たないのは、$x$ が $A$ と $B$ の少なくとも一方に属さないときだ、という意味になります。

全体集合を $U = \{1, 2, \ldots, 10\}$、$A = \{1, 2, 3, 4, 5\}$、$B = \{2, 4, 6, 8, 10\}$ として確かめます。\
このとき $A^c = \{6, 7, 8, 9, 10\}$、$B^c = \{1, 3, 5, 7, 9\}$ です。

$$
\begin{aligned}
(A \cup B)^c &= \{1, 2, 3, 4, 5, 6, 8, 10\}^c = \{7, 9\} \\
A^c \cap B^c &= \{6, 7, 8, 9, 10\} \cap \{1, 3, 5, 7, 9\} = \{7, 9\} \\
(A \cap B)^c &= \{2, 4\}^c = \{1, 3, 5, 6, 7, 8, 9, 10\} \\
A^c \cup B^c &= \{6, 7, 8, 9, 10\} \cup \{1, 3, 5, 7, 9\} = \{1, 3, 5, 6, 7, 8, 9, 10\}
\end{aligned}
$$

どちらの法則も、両辺が同じ集合になりました。\
ただし、具体的な集合で両辺が一致しても、それはその例で成り立つことの確認にすぎません。\
どんな集合でも成り立つことの根拠にはならないので、要素を1つずつ追って確かめます。

1つ目の法則で確かめます。\
$U$ の要素 $x$ が $(A \cup B)^c$ に属するのは、$x$ が $A \cup B$ に属さないときです。\
$A \cup B$ には $A$ と $B$ の少なくとも一方に属するものがすべて入るので、$x$ が $A \cup B$ に属さないのは、$x$ が $A$ にも $B$ にも属さないときに限ります。\
これは $x \in A^c$ かつ $x \in B^c$、つまり $x$ が $A^c \cap B^c$ に属することと同じです。\
したがって $(A \cup B)^c$ と $A^c \cap B^c$ は要素がまったく同じなので、等しい集合です。$\square$

## まとめ

集合は「はっきり決まるものの集まり」です。和集合・共通部分・補集合の3操作が基本で、ド・モルガンの法則で否定と演算が結びつきます。
