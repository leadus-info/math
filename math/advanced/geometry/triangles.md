## 最もシンプルな多角形

3本の直線で囲まれた図形が**三角形**です。どんな複雑な多角形も三角形に分割できるため、三角形は幾何学の基本単位です。

3点 $A, B, C$ を頂点とする三角形 $\triangle ABC$ で、辺 $BC, CA, AB$ の長さをそれぞれ $a, b, c$、頂点の内角をそれぞれ $A, B, C$ と書きます。つまり、辺 $a$ は頂点 $A$ の対辺というように、小文字の辺の記号は同じアルファベットの大文字の頂点（対角）に対応します。

---

## 内角の和は必ず180度

**定理**：$A + B + C = 180°$

**証明**：頂点 $A$ を通り辺 $BC$ に平行な直線を引くと、錯角の関係から3角の和が直線（$180°$）に一致する。$\square$

「2つの角がわかれば、3つ目の角が自動的に決まる」——これが三角形の強力な性質です。

---

## 三平方の定理

直角三角形の直角をはさむ2辺の長さを $a$、$b$、斜辺の長さを $c$ とすると、次の関係が成り立ちます（[三平方の定理](../../intermediate/geometry/pythagorean-theorem.md)で証明済みです）。

$$a^2 + b^2 = c^2$$

例えば、直角をはさむ2辺が $3$、$4$ の直角三角形では、次のように斜辺が $5$ になります。

$$3^2 + 4^2 = 5^2 \quad (9 + 16 = 25)$$

（[三平方の定理の逆](../../intermediate/geometry/pythagorean-theorem.md)より）3・4・5の組み合わせは直角三角形になります。（これは後述の正弦定理・余弦定理からわかることですが）大きい角に向かい合う辺ほど長くなり、最も大きい角が直角なら、向かい合う辺（斜辺）が最も長くなります。

## 面積の公式

$$S = \frac{1}{2} \times \text{底辺} \times \text{高さ} = \frac{1}{2}ab\sin C$$

この式の導出は[三角比](trigonometry.md)の「三角形の面積」で示したとおりです。$\sin C$ を使う公式は「2辺 $a, b$ とその間の角 $C$ から面積を求める」場合に便利です。

**例**：$a = 6, b = 5, C = 30°$ のとき $S = \frac{1}{2} \times 6 \times 5 \times \frac{1}{2} = \frac{15}{2}$（最後の $\times\frac{1}{2}$ は $\sin30°=\frac{1}{2}$ を代入したものです）。

**ヘロンの公式**（3辺 $a, b, c$ から面積）：

$$s = \frac{a+b+c}{2}, \quad S = \sqrt{s(s-a)(s-b)(s-c)}$$

**例**：$a=3, b=4, c=5$ のとき $s=6$、$S = \sqrt{6 \cdot 3 \cdot 2 \cdot 1} = 6$。

## 正弦定理

外接円の半径を $R$ とするとき：

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

この式（$\frac{a}{\sin A} = 2R$）から、辺の長さは向かい合う角の $\sin$ の大きさに比例することがわかります。したがって、大きい角に向かい合う辺ほど長くなります。

> [!NOTE]
> 「大きい角に向かい合う辺ほど長くなる」ことは、次のように示せます（三角形の2角 $A, B$ について $A>B$ とする）。$A\leq90°$ の場合、$B<A\leq90°$ なので、$[0°,90°)$ における $\sin$ の単調増加性から直接 $\sin B<\sin A$ が成り立ちます。$A>90°$ の場合、$A+B+C=180°$、$C>0$ より $B<180°-A$。$A>90°$ なので $180°-A<90°$、したがって $B<180°-A<90°$ であり、$B$ と $180°-A$ はともに $[0°,90°)$ にあります。$\sin$ の単調増加性から $\sin B<\sin(180°-A)$。[鈍角への拡張](trigonometry.md#鈍角への拡張)で示した恒等式 $\sin(180°-A)=\sin A$ を用いると $\sin B<\sin A$ が得られます。いずれの場合も $\sin A>\sin B$ となるため、$a=2R\sin A>2R\sin B=b$ です。

> [!NOTE]
> 正弦定理の証明には円周角の定理を要するため割愛しますが、外接円の性質から導かれます。詳しくは[円周角の定理](../../intermediate/geometry/circle-angles.md)を参照してください。

**使いどころ**：2角と1辺がわかるとき、または2辺と対角（挟まない角）がわかるとき。

> [!NOTE]
> 2辺と対角がわかっている場合、条件を満たす三角形が2通り・1通り・0通りのいずれになるかは辺と角の大きさによって変わり、一意に定まらないことがあります。角 $A$ と辺 $a$（角 $A$ の対辺）、辺 $c$ がわかっているとします。頂点 $A$ から角 $A$ の方向に長さ $c$ の位置に頂点 $C$ を固定すると、残る頂点 $B$ は頂点 $C$ を中心とする半径 $a$ の円周上のどこかにあります。この円と、角 $A$ のもう一方の辺（頂点 $A$ から伸びる直線）との交点の個数が、条件を満たす三角形の個数に対応します。頂点 $C$ から直線までの垂線の長さは $c\sin A$ なので、$a<c\sin A$ なら交点0個（三角形なし）、$a=c\sin A$ なら接して1個（直角三角形）、$c\sin A<a<c$ なら2個、$a\geq c$ なら1個になります。

**例題**：$A = 30°, B = 45°, a = 3$ のとき $b$ を求める。$C = 180° - 30° - 45° = 105°$。$\frac{3}{\sin 30°} = \frac{b}{\sin 45°}$ より $b = 3 \times \frac{\sqrt{2}/2}{1/2} = 3\sqrt{2}$。

## 余弦定理

$$a^2 = b^2 + c^2 - 2bc\cos A$$

**証明**：頂点 $B$ から辺 $AC$ に垂線を下ろし、その足を $H$ とします。直角三角形 $ABH$ において $BH = c\sin A$、$AH = c\cos A$ です。したがって $HC = b - c\cos A$ となります。直角三角形 $BHC$ に三平方の定理を適用すると $a^2 = BH^2 + HC^2$ です。これに代入すると $a^2 = c^2\sin^2A + (b-c\cos A)^2 = c^2(\sin^2A+\cos^2A) + b^2 - 2bc\cos A = b^2+c^2-2bc\cos A$（$\sin^2A+\cos^2A=1$ を用いた）となります。$\square$

> [!NOTE]
> $A$ が鈍角の場合、垂線の足 $H$ は辺 $AC$ の延長線上（点 $A$ を越えた外側）に出ますが、$AH = c\cos A$ 自体は[鈍角への拡張](trigonometry.md#鈍角への拡張)で定義した $\cos A$（$90°<A<180°$ で負の値）を用いればそのまま成り立ち、$HC = b - c\cos A$ も符号を含めて統一的に扱えるため、公式は変わりません。

$A = 90°$ のとき $\cos 90° = 0$ となり三平方の定理の一般化になります。

**使いどころ**：3辺がわかるとき（角を求める）、または2辺とその間の角がわかるとき（辺を求める）。

**例題**：$b=5, c=7, A=60°$ のとき $a$ を求める。$a^2 = 25 + 49 - 2 \times 5 \times 7 \times \frac{1}{2} = 74 - 35 = 39$、$a = \sqrt{39}$。

## 五心

五心の定義には、いくつかの用語を使います。頂点と、その対辺の中点を結ぶ線分を**中線**といいます。辺のちょうど真ん中を通り、その辺に垂直な直線を**垂直二等分線**、角を半分に分ける直線を**角の二等分線**といいます。頂点から対辺（を含む直線）に垂直に下ろした線を**垂線**といいます。垂直二等分線・角の二等分線・垂線の作図方法について詳しくは[作図](../../intermediate/geometry/constructions.md)を参照してください。また、1つの角の二等分線に対し、隣り合う辺の一方を延長してできる外角を二等分する直線を**外角の二等分線**といいます。

| 点 | 定義 |
|----|------|
| 重心 $G$ | 3中線の交点 |
| 外心 $O$ | 各辺の垂直二等分線の交点（外接円の中心） |
| 内心 $I$ | 各角の二等分線の交点（内接円の中心） |
| 垂心 $H$ | 3つの頂点から対辺に下ろした垂線の交点 |
| 傍心 | 1つの角の二等分線と、他の2つの角の外角の二等分線の交点（傍接円の中心） |

傍心は頂点ごとに1つずつ、合計3つあります。内接円は三角形の内側にあって3辺に接するのに対し、傍接円は1つの頂点の外側にあり、1辺と他の2辺の延長に接します。

$G$, $O$, $H$ は同一直線（オイラー線）上にあり、$OG : GH = 1 : 2$ となることが知られています。

## まとめ

三角形の内角の和は常に180度で、三平方の定理は直角三角形の辺の関係を表します。正弦定理・余弦定理を使うと、辺と角の一部から残りを求められます。
