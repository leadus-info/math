## 円に内接する四角形

4つの頂点すべてが1つの円周上にある四角形を、その円に**内接する四角形**といいます。

**性質**：円に内接する四角形の対角の和は $180°$。

**証明**：四角形$ABCD$が円に内接し、4頂点がこの順に円周上に並んでいるとします。対角線$AC$、$BD$を引きます。

- $\angle ADB$と$\angle ACB$は、どちらも弧$AB$（$C$、$D$を含まない側の弧）に対する円周角なので、円周角の定理より$\angle ADB=\angle ACB$です。
- $\angle BDC$と$\angle BAC$は、どちらも弧$BC$（$A$、$D$を含まない側の弧）に対する円周角なので、$\angle BDC=\angle BAC$です。

4頂点がこの順に並ぶ四角形では、対角線$DB$は角$D$の内部を通るので、$\angle ADC=\angle ADB+\angle BDC$です。したがって

$$\angle ADC=\angle ACB+\angle BAC$$

です。三角形$ABC$の内角の和は$180°$なので、$\angle ACB+\angle BAC=180°-\angle ABC$です。よって$\angle ADC=180°-\angle ABC$、すなわち$\angle B+\angle D=180°$です。対角線$AC$が角$C$を分けることを使えば、同じ議論から$\angle A+\angle C=180°$も成り立ちます。$\square$

![円に内接する四角形ABCD(この順に円周上に並ぶ)に対角線AC・BDを引き、対角の∠Bと∠Dに印をつけた図](circle-theorems/images/cyclic-quadrilateral.svg)

**逆**：凸四角形の対角の和が $180°$ ならば、その四角形は円に内接します（円に内接する四角形は常に凸なので、逆の対象を凸四角形に限定します）。凸四角形とは、どの頂点もへこんでいない四角形のことです。

**証明**：凸四角形$ABCD$の頂点がこの順に並び、$\angle B+\angle D=180°$が成り立っているとします。3点$A,B,C$を通る円$\Gamma$を考えます（$A,B,C$は一直線上にないので、この円はただ1つに定まります）。この時点では、$D$が$\Gamma$上にあるかどうかはまだ分かっていません。それを示すのがこの証明の目的です。弦$AC$は$\Gamma$を2つの弧に分けます。$B$を含む側を弧₁、$B$を含まない側を弧₂と呼ぶことにします。

弧₂上に任意の点$E$をとると、$A,B,C,E$はこの順に円周上に並ぶので、四角形$ABCE$は$\Gamma$に内接する（この順に並ぶ）四角形です。前段で示した性質（円に内接する四角形の対角の和は$180°$）より$\angle ABC+\angle AEC=180°$。仮定の$\angle ABC+\angle ADC=180°$と合わせると、

$$\angle AEC=\angle ADC$$

が成り立ちます（弧₂上のどこに$E$をとってもこれが成り立ちます）。

弦は円を2つの弧に分け、各弧はその弦を通る直線に関して一方の側に留まるという基本的な事実があります。弧₁は$B$を含むので、$B$と同じ側にあります。弧₂はそれと反対側、すなわち直線$AC$に関して弧₁とは逆側にあります。一方、$D$が$B$とは反対側にあることは、凸四角形$ABCD$の対角線$AC$がその四角形の内部を通り、他の2頂点$B,D$を反対側に分けるという、凸四角形の対角線の基本的な性質から従います。したがって弧₂上の点$E$と点$D$は、直線$AC$に関して同じ側（ともに$B$の反対側）にあります（下図では、$D$を証明の結論として$D$が来る位置に描いています）。

![円Γと、Γを弧₁(Bを含む)と弧₂(Bを含まない)に分ける弦ACを示す図。弧₂上の点Eと点Dは、どちらも直線ACに関してBと反対側にある。Dは、証明の結論としてDが来る位置(弧₂上)に描いている](circle-theorems/images/converse-arc-sides.svg)

ここで前提記事「円周角の定理」の逆（2点が直線について同じ側にあり、その直線の両端を見込む角が等しければ、4点は同一円周上にある、という定理）を、直線$AC$（両端$A,C$）・弧₂上の点$E$・点$D$に適用します。$E$と$D$は直線$AC$について同じ側にあり、$\angle AEC=\angle ADC$なので、4点$A,C,E,D$は同一円周上にあります。$E$はもともと$\Gamma$上の点であり、$A,C,E$は一直線上にないので、この4点が乗る円は$A,C,E$を通る円、すなわち$\Gamma$そのものです。よって$D$も$\Gamma$上にあり、$A,B,C,D$は同一円周上にあります。つまり四角形$ABCD$は円に内接します。$\square$

> 円に内接する四角形$ABCD$において$\angle B=110°$のとき、$\angle D$を求める。性質より$\angle D=180°-110°=70°$。

## 接弦定理

円周上の2点を結ぶ線分を**弦**といいます。円の接点を$T$とし、$T$を通る弦$TA$と、接線上で$T$から一方の向きに伸びる半直線とのなす角を$\theta$とします。弦$TA$は円周を2つの弧に分けますが、そのうち角$\theta$の内側にない方の弧上に点$B$をとると、$\angle TBA=\theta$が成り立ちます。これを**接弦定理**といいます。

![円の接線と接点Tを通る弦TAのなす角θと、角θの内側にない弧上の点Bにおける円周角∠TBAが等しいことを示す図](circle-theorems/images/tangent-chord-angle.svg)

**証明**：円の中心を$O$とします。$\theta$が鋭角か直角か鈍角かで分けて示します。

**$\theta$が鋭角のとき**：接線は接点を通る半径$OT$に垂直なので、$\angle OTA = 90°-\theta$。三角形$OTA$は$OT=OA$（ともに半径）の二等辺三角形なので、底角が等しく$\angle OAT=\angle OTA=90°-\theta$。三角形の内角の和が$180°$であることから、$\angle TOA=180°-2(90°-\theta)=2\theta$。この$\angle TOA$は、角$\theta$の内側にある弧（$B$を含まない側の弧）に対する中心角なので、円周角の定理より、$B$からその弧を見込む円周角は中心角の半分、すなわち$\angle TBA=\theta$になります。

**$\theta$が直角のとき**：弦$TA$は接線に垂直なので、接点を通り接線に垂直な直線、つまり半径$OT$を延ばした直線の上にあります。したがって$TA$は直径です。直径に対する円周角は直角なので、$\angle TBA=90°=\theta$です。

**$\theta$が鈍角のとき**：接線上で反対向きの半直線と弦$TA$のなす角は$180°-\theta$で、これは鋭角です。この角の内側にない弧（つまり$B$を含む側とは反対の弧）上に点$B'$をとると、鋭角の場合の結果から$\angle TB'A=180°-\theta$です。四角形$TB'AB$は円に内接するので、対角の和は$180°$であり、$\angle TBA=180°-\angle TB'A=\theta$です。$\square$

![接弦定理の証明:中心Oと接点T・弦TAの他端Aを結ぶ半径OT・OAでできる二等辺三角形OTAにおいて、接線と半径OTが直角に交わること、底角∠OTA=∠OAT=90°−θであること、中心角∠TOA=2θであることを示す図](circle-theorems/images/tangent-chord-proof.svg)

> 円の接線と接点$T$を通る弦$TA$のなす角が$62°$であるとき、角の内側にない弧上の点$B$における円周角$\angle TBA$を求める。接弦定理より、$\angle TBA=62°$。

## 方べきの定理

円の内部または外部の1点 $P$ を通る2本の直線が、円とそれぞれ2点 $A,B$ と $C,D$ で交わるとき、

$$PA \cdot PB = PC \cdot PD$$

が成り立ちます。これを**方べきの定理**といいます。

![円の外部の点Pを通る2本の直線が円とP,A,B及びP,C,Dで交わり、PA・PB=PC・PDが成り立つことを示す図](circle-theorems/images/power-of-a-point.svg)

証明では、三角形 $PAC$ と三角形 $PDB$ が相似であることを示します。角が等しいことの根拠が、$P$ が円の外部にある場合と内部にある場合で異なるので、分けて確かめます。

### Pが円の外部にある場合

点の並び方を次のように決めます（上の図の場合です）。

- 直線 $AB$ 上で、$P,A,B$ がこの順に並ぶ（$A$ は $P$ と $B$ の間にある）
- 直線 $CD$ 上で、$P,C,D$ がこの順に並ぶ（$C$ は $P$ と $D$ の間にある）

まず、4点が円周上でどの順に並ぶかを確かめます。三角形$PBD$を考えると、$A$は辺$PB$上、$C$は辺$PD$上にあります。三角形の2つの頂点$D$、$B$から、それぞれ向かい合う辺上の点$A$、$C$へ引いた線分$DA$と$BC$は、三角形の内部で交わります。つまり、弦$AD$と弦$BC$は円の内部で交わります。円周上の4点で2本の弦が交わるのは、それぞれの弦の端点が互い違いに並ぶときなので、円周上で$A$と$D$の間に$B$と$C$が1つずつ入ります。したがって、4点は円周上で$A,B,D,C$の順に並びます。

この順に結んだ四角形 $ABDC$ は円に内接するので、円に内接する四角形の性質（対角の和が $180°$、前節参照）より、

$$\angle BAC+\angle CDB=180°$$

次に、この等式を三角形 $PAC$ と三角形 $PDB$ の角に言い換えます。

- $A$ は $P$ と $B$ の間にあるので、$\angle PAC$ と $\angle BAC$ を合わせると直線 $PB$ がなす $180°$ になり、$\angle PAC=180°-\angle BAC$ です。
- $C$ は $P$ と $D$ の間にあるので、半直線 $DP$ と半直線 $DC$ は一致し、$\angle PDB=\angle CDB$ です。

これらと上の等式から、$\angle PAC=180°-\angle BAC=\angle CDB=\angle PDB$ となります。

また、半直線 $PA$ と半直線 $PB$ は一致し、半直線 $PC$ と半直線 $PD$ も一致します。したがって、$\angle APC$ と $\angle DPB$ は同じ角です。

### Pが円の内部にある場合

このとき $P$ は弦 $AB$ と弦 $CD$ の交点で、$P$ は $A$ と $B$ の間、$C$ と $D$ の間にあります。この場合は内接四角形の性質を使わず、次の2つから直接角が等しいことがわかります。

- $\angle APC$ と $\angle DPB$ は対頂角なので等しくなります。
- $P$ は線分 $AB$、線分 $CD$ 上にあるので、$\angle PAC=\angle BAC$、$\angle PDB=\angle CDB$ です。弦 $AB$ と弦 $CD$ は $P$ で交わるので、円周上で $A,C,B,D$ の順に並び、$A$ と $D$ は直線 $BC$ について同じ側にあります。そのため、$\angle BAC$ と $\angle CDB$ はどちらも弧 $BC$ に対する円周角で等しく、$\angle PAC=\angle PDB$ となります。

### 相似から等式を導く

どちらの場合も、三角形 $PAC$ と三角形 $PDB$ は2組の角がそれぞれ等しい（$\angle PAC=\angle PDB$、$\angle APC=\angle DPB$）ので相似です。対応する頂点は $P\leftrightarrow P$、$A\leftrightarrow D$、$C\leftrightarrow B$ です。

相似な図形では対応する辺の比が等しいので、$PA:PD=PC:PB$ が成り立ちます。比例式では外項の積と内項の積が等しい（[一次方程式](../../intermediate/algebra/equations-linear.md)の比例式を参照）ので、$PA\cdot PB=PD\cdot PC$、すなわち $PA\cdot PB=PC\cdot PD$ です。$\square$

### 接線の場合

円と2点で交わる直線を**割線**といいます。$P$ が円の外部にあるとき、$P$ から円への接線の接点を $T$ とし、$P$ を通る割線と円の交点を $P$ に近い方から $A,B$ とすると（$P$、$A$、$B$ はこの順に一直線上に並びます）、$PT^2 = PA\cdot PB$ が成り立ちます。

**証明**：三角形 $PTA$ と三角形 $PBT$ が相似であることを示します。$\angle TPA$ と $\angle BPT$ は、半直線 $PA$ と半直線 $PB$ が一致するので同じ角です。また、接線上の半直線 $TP$ と弦 $TA$ のなす角 $\angle PTA$ を考えます。弦 $TA$ は円周を2つの弧に分けますが、$\angle PTA$ の内側にある弧は、直線 $TA$ について $P$ と同じ側にあります。一方、$A$ は $P$ と $B$ の間にあって直線 $TA$ 上の点なので、$P$ と $B$ は直線 $TA$ について反対側にあります。したがって $B$ は $\angle PTA$ の内側にない方の弧の上にあり、接弦定理より $\angle PTA=\angle TBA$ です。$A$ は $P$ と $B$ の間にあるので $\angle TBA=\angle TBP$ であり、$\angle PTA=\angle PBT$ です。2組の角がそれぞれ等しいので、三角形 $PTA$ と三角形 $PBT$ は相似です（$P\leftrightarrow P$、$T\leftrightarrow B$、$A\leftrightarrow T$）。対応する辺の比から $PT:PB=PA:PT$ となり、$PT^2=PA\cdot PB$ が得られます。$\square$

> [!NOTE]
> 直観的には、次のように考えることもできます。$P$ を通る割線を少しずつ回して接線に近づけると、2つの交点 $A,B$ はどちらも接点 $T$ に近づき、$PA$、$PB$ はどちらも $PT$ に近づきます。$PA\cdot PB$ は割線を回しても変わらないので、その値は $PT\cdot PT=PT^2$ に等しくなる、というわけです。これは証明ではなく、結果を思い出すための見方です。

> 円の外部の点$P$を通る2直線が円と$P,A,B$、$P,C,D$でそれぞれ交わり、$PA=2$、$PB=8$、$PC=2$のとき、$PD$を求める。方べきの定理より $PA\cdot PB=PC\cdot PD$ なので $2\times8=2\times PD$、$PD=8$。

## 2円の位置関係

2つの円の半径を $r_1, r_2$（$r_1 \geq r_2$）、中心間の距離を $d$ とします。ただし、2つの円が完全に重なる場合（$r_1=r_2$ かつ $d=0$）は除きます。このとき、位置関係は次のように分類されます。2つの円の両方に接する直線を**共通接線**といいます。

| 条件 | 位置関係 |
|------|---------|
| $d > r_1+r_2$ | 互いに外部にある（共通接線4本） |
| $d = r_1+r_2$ | 外接する（共通接線3本） |
| $r_1-r_2 < d < r_1+r_2$ | 2点で交わる（共通接線2本） |
| $d = r_1-r_2$ | 内接する（共通接線1本） |
| $d < r_1-r_2$ | 一方が他方の内部にある（共通接線0本） |

共通接線には2種類あります。2つの円が接線に関して同じ側にあるものを**外部共通接線**、反対側にあるものを**内部共通接線**といいます。

- 外部共通接線は、一方の円が他方の内部に（内接も含めて）含まれていなければ（$d>r_1-r_2$ のとき）2本引けます。内接するとき（$d=r_1-r_2$）は2本が接点で重なって1本になり、$d<r_1-r_2$ のときは引けません。
- 内部共通接線は、2つの円が互いに外部にあれば（$d>r_1+r_2$ のとき）2本引けます。外接するとき（$d=r_1+r_2$）は2本が接点で重なって1本になり、$d<r_1+r_2$ のときは引けません。

この2種類の本数を足したものが、表の共通接線の本数（4本・3本・2本・1本・0本）です。

## まとめ

円に内接する四角形は対角の和が $180°$、接弦定理は接線と弦のなす角を円周角と結びつけます。方べきの定理は円を通る2直線の線分の積が一定であることを示し、2円の位置関係は中心間の距離と半径の大小で分類できます。
