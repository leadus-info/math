## 「場所」だけを持つもの

鉛筆で紙に打った小さな点。数学ではこれをさらに理想化して、「大きさが全くなく、場所だけがある」ものを**点**と呼びます。

---

## 座標平面

[関数](../../intermediate/functions/functions.md)で学んだように、原点 $O(0, 0)$ で垂直に交わる横の数直線（$x$ 軸）と縦の数直線（$y$ 軸）を使い、点の位置を数の組 $(x, y)$ で表します。$x$ は原点から横方向にどれだけ進んだ位置か、$y$ は縦方向にどれだけ進んだ位置かを表し、$x$ 軸は右方向、$y$ 軸は上方向をそれぞれ正の向きとします（負の値は反対向きを表します）。この記事では、2本の軸の目盛りの間隔（単位の長さ）はそろっているものとします。2本の軸によって平面は4つの領域に分けられ、それぞれを**象限**といいます。右上の領域を第1象限とし、そこから反時計回りに第2象限、第3象限、第4象限と呼びます。

---

## 2点間の距離

点 $A(x_1, y_1)$ と $B(x_2, y_2)$ の距離は、[三平方の定理](../../intermediate/geometry/pythagorean-theorem.md)で学んだように、横 $|x_2 - x_1|$・縦 $|y_2 - y_1|$ を直角をはさむ2辺とする直角三角形の斜辺として、次の式で求められます。

$$|AB| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

**例**：$A(-2, 1)$, $B(2, 4)$ の距離 $= \sqrt{(2-(-2))^2+(4-1)^2} = \sqrt{16+9} = 5$

![2点A(-2,1)とB(2,4)を結ぶ線分を斜辺とし、横4・縦3の直角三角形から距離5が三平方の定理で求まることを示す図](point/images/distance-formula.svg)

## 中点・内分点

線分 $AB$ 上の点 $P$ が $AP:PB = m:n$ を満たすとき、$P$ は線分 $AB$ を $m:n$ に**内分**するといいます（$m$、$n$ は正の数）。$P$ の座標は次の式で求まります。

$$P = \left(\frac{nx_1+mx_2}{m+n}, \frac{ny_1+my_2}{m+n}\right)$$

$m$ が大きいほど $P$ は $B$ に近づき、$B$ の座標 $x_2$ にかかる重みも大きくなる、という対応になっています。

この式は、[相似](../../intermediate/geometry/similarity.md)を使って導けます。$A$ を通り $x$ 軸に平行な直線を引き、$P$、$B$ からこの直線に垂線を下ろして、その足をそれぞれ $P'$、$B'$ とします。三角形 $APP'$ と三角形 $ABB'$ は、$\angle A$ が共通で、$\angle AP'P = \angle AB'B = 90°$ なので、2組の角がそれぞれ等しく相似です。したがって

$$AP':AB' = AP:AB = m:(m+n)$$

が成り立ちます。$P'$ と $B'$ は $A$ から見て同じ側にあり、$AP'$ の長さは $|P_x - x_1|$、$AB'$ の長さは $|x_2 - x_1|$ なので、符号まで含めて

$$P_x - x_1 = \frac{m}{m+n}(x_2 - x_1)$$

となります。これを $P_x$ について整理すると $P_x = \dfrac{nx_1+mx_2}{m+n}$ が得られます。$y$ 座標も、$A$ を通り $y$ 軸に平行な直線を使えば同様に求まります。なお、$AB$ が $x$ 軸に平行なときは $P'=P$、$B'=B$ となり上の比が直接成り立ち、$AB$ が $y$ 軸に平行なとき（$x_1 = x_2$）は $P_x = x_1$ となって、どちらの場合も同じ式が成り立ちます。

**例**：$A(0,0)$, $B(6,9)$ を $2:1$ に内分する点：$\left(\frac{1\cdot0+2\cdot6}{3}, \frac{1\cdot0+2\cdot9}{3}\right) = (4, 6)$

線分 $AB$ の中点 $M$ は $1:1$ に内分する点なので、$m=n=1$ として次の式になります。

$$M = \left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$$

直線 $AB$ 上で線分 $AB$ の外側にあり、$AQ:QB = m:n$（$m \neq n$）を満たす点 $Q$ を、線分 $AB$ を $m:n$ に**外分**する点といいます。$m>n$ のときは $Q$ は $B$ を越えた位置に、$m<n$ のときは $A$ を越えた位置にあります。

- $m>n$ のとき：$B$ は線分 $AQ$ 上にあり、$AB = AQ - QB$ なので $AQ:AB = m:(m-n)$ です。$Q$ から同じ直線に下ろした垂線の足を $Q'$ とすると、上と同じ相似の議論により $AQ':AB' = AQ:AB$ が成り立ち、$Q'$ と $B'$ は $A$ から見て同じ側にあるので、$Q_x - x_1 = \dfrac{m}{m-n}(x_2 - x_1)$ となります。
- $m<n$ のとき：$A$ は線分 $QB$ 上にあり、$AB = QB - AQ$ なので $AQ:AB = m:(n-m)$ です。$Q$ から下ろした垂線の足を $Q'$ とすると、三角形 $AQQ'$ と三角形 $ABB'$ は、$A$ での角が対頂角で等しく、どちらも直角を持つので相似です。ただし $Q$ は $A$ から見て $B$ と反対側にあるので、$Q_x - x_1 = -\dfrac{m}{n-m}(x_2 - x_1) = \dfrac{m}{m-n}(x_2 - x_1)$ となります。

どちらの場合も同じ式 $Q_x - x_1 = \dfrac{m}{m-n}(x_2 - x_1)$ になり、これを整理すると次の公式が得られます（$y$ 座標も同様です）。内分点の公式の $n$ を $-n$ に置き換えた形になっています。

$$Q = \left(\frac{-nx_1+mx_2}{m-n}, \frac{-ny_1+my_2}{m-n}\right) \quad (m \neq n)$$

**例**：$A(0,0)$, $B(6,9)$ を $2:1$ に外分する点：$\left(\frac{-1\cdot0+2\cdot6}{1}, \frac{-1\cdot0+2\cdot9}{1}\right) = (12, 18)$

## 三角形の重心

三角形の頂点と、その対辺の中点を結ぶ線分を**中線**といいます。三角形には中線が3本あり、この3本は1点で交わります。この交点を三角形の**重心**といいます。また、重心は各中線を頂点側から $2:1$ に内分します。

3頂点を $A(x_1,y_1)$, $B(x_2,y_2)$, $C(x_3,y_3)$ とすると、重心 $G$ の座標は次の式で求まります。

$$G = \left(\frac{x_1+x_2+x_3}{3}, \frac{y_1+y_2+y_3}{3}\right)$$

**例題**：$A(1,2)$, $B(5,4)$, $C(3,9)$ の重心は $\left(\frac{9}{3}, \frac{15}{3}\right) = (3, 5)$。

上で述べた「3本の中線が1点で交わること」と「その点が各中線を $2:1$ に内分すること」は、内分点の公式を使って座標の計算で確かめられます。

辺 $BC$ の中点を $M=\left(\dfrac{x_2+x_3}{2},\dfrac{y_2+y_3}{2}\right)$ とし、中線 $AM$ を $A$ 側から $2:1$ に内分する点、つまり $AG:GM = 2:1$ を満たす点 $G$ を考えます。内分点の公式の1点目を $A$、2点目を $M$ として $m=2$、$n=1$ を当てはめると、

$$G_x = \frac{1\cdot x_1+2\cdot\dfrac{x_2+x_3}{2}}{2+1} = \frac{x_1+x_2+x_3}{3}$$

となり、$y$ 座標も同様に $G_y = \dfrac{y_1+y_2+y_3}{3}$ です。

この式は $x_1, x_2, x_3$（$y_1, y_2, y_3$）を入れ替えても変わりません。そのため、中線 $BN$（$N$ は辺 $CA$ の中点）を $B$ 側から $2:1$ に内分する点や、中線 $CL$（$L$ は辺 $AB$ の中点）を $C$ 側から $2:1$ に内分する点を同じように計算しても、まったく同じ座標になります。つまり、3本の中線はどれもこの点 $G$ を通り、$G$ は各中線を頂点側から $2:1$ に内分しています。これで、3本の中線が1点で交わることと、重心の座標の公式が同時に示されました。

## まとめ

座標を使うことで、幾何学の問題を数の計算で解くことができます。2点間の距離は三平方の定理、中点・内分点・重心は座標の加重平均で求められます。
