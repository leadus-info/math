## 整式の除法

[多項式](polynomials.md)で学んだ多項式は、**整式**とも呼ばれます。\
整数の割り算 $158 \div 12 = 13 \, \text{余り} \, 2$ と同じように、整式どうしも割り算ができます。

$$A = BQ + R \quad (B \neq 0,\ R = 0 \text{ または } R \text{ の次数} < B \text{ の次数})$$

$A$ を割られる式、$B$ を割る式、$Q$ を商、$R$ を余りといいます。余り $R$ が $0$ のとき、$A$ は $B$ で**割り切れる**といいます。

割られる式 $A$ と割る式 $B$ を決めると、上の式の条件を満たす商 $Q$ と余り $R$ はただ一組に定まります。

**例題**：$x^3 - 2x^2 + 3x - 1$ を $x - 1$ で割る。

1. 最高次項どうしを比べる：$x^3$ と $x$ から、商の最初の項は $x^2$。$x^2(x-1) = x^3 - x^2$ を引くと、$(x^3-2x^2+3x-1) - (x^3-x^2) = -x^2+3x-1$。
2. 次数が1つ下がった $-x^2$ と $x$ を比べる：商の次の項は $-x$。$-x(x-1) = -x^2+x$ を引くと、$(-x^2+3x-1) - (-x^2+x) = 2x-1$。
3. さらに次数が下がった $2x$ と $x$ を比べる：商の次の項は $2$。$2(x-1) = 2x-2$ を引くと、$(2x-1)-(2x-2) = 1$。次数が割る式 $x-1$ の次数（1次）より低くなったので終了。

商は $x^2 - x + 2$、余りは $1$。すなわち $x^3-2x^2+3x-1 = (x-1)(x^2-x+2) + 1$。

割られる式に欠けた次数の項があるときは、その項を係数 $0$ として補い、次数をそろえて計算します。割る式が2次以上の場合も手順は同じで、余りの次数が割る式の次数より低くなったところで終わります。

**例題**：$x^3 + 2x^2 - 1$ を $x^2 + 1$ で割る。$x$ の項が欠けているので、$x^3 + 2x^2 + 0x - 1$ として計算する。

1. $x^3 \div x^2 = x$ が商の最初の項。$x(x^2+1) = x^3 + x$ を引くと、$(x^3+2x^2+0x-1) - (x^3+0x^2+x) = 2x^2 - x - 1$。
2. $2x^2 \div x^2 = 2$ が商の次の項。$2(x^2+1) = 2x^2+2$ を引くと、$(2x^2-x-1) - (2x^2+2) = -x-3$。余り $-x-3$ の次数（1次）が割る式 $x^2+1$ の次数（2次）より低くなったので終了。

商は $x+2$、余りは $-x-3$。すなわち $x^3+2x^2-1 = (x^2+1)(x+2) + (-x-3)$。

## 分数式の計算

$A$、$B$ を整式とし、$B$ が文字を含むとき、$\dfrac{A}{B}$ の形で表される式を**分数式**といいます。分数式の約分・通分は、普通の分数と同じ考え方で行います。

約分では、分子と分母をそれぞれ因数分解し、共通な因数で分子と分母を割ります。

$$\frac{x^2-1}{x-1} = \frac{(x+1)(x-1)}{x-1} = x+1 \quad (x \neq 1)$$

通分では、それぞれの分母を因数分解し、どの分母の因数もすべて含む式を共通の分母にします。

$$\frac{1}{x^2-1} + \frac{1}{x+1} = \frac{1}{(x+1)(x-1)} + \frac{x-1}{(x+1)(x-1)} = \frac{1+(x-1)}{(x+1)(x-1)} = \frac{x}{(x+1)(x-1)}$$

## 剰余の定理

整式 $f(x)$ を1次式 $x - \alpha$ で割ったときの余りは、実際に割り算をしなくても求められます。

**剰余の定理**：整式 $f(x)$ を $x-\alpha$ で割った余りは $f(\alpha)$ に等しい。

**証明**：$f(x)$ を $x-\alpha$ で割った商を $Q$、余りを $R$ とすると、$f(x) = (x-\alpha)Q + R$ と書ける。$x-\alpha$ は1次式なので、余り $R$ の次数は $x-\alpha$ の次数（1次）より低く、$R$ は定数である。この等式は $x$ についての[恒等式](../../intermediate/algebra/equations.md)（＝どんな $x$ でも成り立つ等式）なので、特定の値 $x=\alpha$ でも当然成り立つ。したがって両辺に $x=\alpha$ を代入してもよい。代入すると $f(\alpha) = (\alpha-\alpha)Q + R = R$ となる。よって $R = f(\alpha)$ である。$\square$

**例**：$f(x)=x^3-2x^2+3x-1$ を $x-1$ で割った余りは $f(1) = 1-2+3-1=1$。これは「整式の除法」の例題で求めた商 $x^2-x+2$・余り $1$ のうち、余り $1$ と一致します。

整式 $f(x)$ が、ある整式 $g(x)$ を使って $f(x)=(x-\alpha)g(x)$ と表されるとき、$x-\alpha$ は $f(x)$ の因数です。[多項式](polynomials.md)で紹介した因数定理は、剰余の定理から次のように示せます。

**因数定理**：整式 $f(x)$ について、$f(\alpha)=0$ ならば $x-\alpha$ は $f(x)$ の因数である。逆に、$x-\alpha$ が $f(x)$ の因数ならば $f(\alpha)=0$ である。

**証明**：剰余の定理より、$f(x)$ を $x-\alpha$ で割った余りは $f(\alpha)$ である。$f(\alpha)=0$ ならば余りが $0$ なので、$f(x)$ は $x-\alpha$ で割り切れる。このときの商を $Q$ とすると $f(x)=(x-\alpha)Q$ となり、$x-\alpha$ は $f(x)$ の因数である。逆に、$f(x)=(x-\alpha)g(x)$ のとき、$x=\alpha$ を代入すると $f(\alpha)=(\alpha-\alpha)g(\alpha)=0$ である。$\square$

## 高次方程式を解く

この節では、方程式の解を[複素数](../numbers/complex-numbers.md)の範囲で求めます。

3次以上の方程式（**高次方程式**）は、因数定理を使って1次式・2次式の積に分解できれば解けます。$f(\alpha)=0$ となる $\alpha$ を見つけるには、最高次の係数が $1$ で他の係数もすべて整数の場合、定数項の約数を候補として順に試すのがよい方法です。候補には、$-1$ や $-2$ のような負の約数も含めます。

整数の解が定数項の約数に限られる理由は、次のとおりです。整式 $f(x) = x^n + \cdots + a_1 x + a_0$（係数はすべて整数）について、整数 $\alpha$ が $f(\alpha)=0$ を満たすとします。$a_0$ を移項し、左辺を $\alpha$ でくくると次のようになります。

$$
\begin{aligned}
\alpha^n + \cdots + a_1\alpha &= -a_0 \\
\alpha(\alpha^{n-1}+\cdots+a_1) &= -a_0
\end{aligned}
$$

$\alpha$ と係数はすべて整数なので、括弧の中の $\alpha^{n-1}+\cdots+a_1$ も整数です。したがって $-a_0$ は $\alpha$ の整数倍であり、$\alpha$ は $a_0$ の約数です。

**例題**：$x^3 - 6x^2 + 11x - 6 = 0$ を解く。定数項 $-6$ の約数 $\pm1, \pm2, \pm3, \pm6$ が解の候補である。$x=1$ を試すと $f(1) = 1-6+11-6=0$ なので $x-1$ が因数。整式の除法で $f(x) = (x-1)(x^2-5x+6) = (x-1)(x-2)(x-3)$。よって $x=1,2,3$。

> [!NOTE]
> ここまでの方法は、最高次の係数が $1$ の場合のものです。最高次の係数が $1$ でない整数係数の方程式では、有理数の解の候補は $\pm\dfrac{\text{定数項の約数}}{\text{最高次の係数の約数}}$ になります。例えば $2x^3-3x^2-3x+2=0$ の候補は $\pm1,\ \pm2,\ \pm\dfrac{1}{2}$ で、$x=\dfrac{1}{2}$ はその一つとして見つかる解です。候補をすべて試しても解が見つからない高次方程式もあります。その場合の解き方は、本記事の範囲外です。

**複二次方程式**（$x^4$ と $x^2$ と定数だけの式）は、$x^2=t$ とおき換えると2次方程式に帰着できます。

**例題**：$x^4 + x^2 - 2 = 0$。$t=x^2$ とおくと $t^2+t-2=0$、$(t+2)(t-1)=0$ より $t=-2, 1$。$x^2=1$ より $x=\pm1$、$x^2=-2$ より $x=\pm\sqrt{2}\,i$。よって $x=\pm1,\ \pm\sqrt{2}\,i$。

## まとめ

整式は整数と同じように除法ができ、$A=BQ+R$ の形に書けます。剰余の定理を使うと、実際に割り算をしなくても $x=\alpha$ を代入するだけで余りがわかります。因数定理と組み合わせれば、高次方程式を低次の方程式に分解して解くことができます。
