## 整式の除法

整数の割り算 $158 \div 12 = 13 \, \text{余り} \, 2$ と同じように、整式（多項式）どうしも割り算ができます。

$$A = BQ + R \quad (R \text{ の次数} < B \text{ の次数})$$

$A$ を割られる式、$B$ を割る式、$Q$ を商、$R$ を余りといいます。

**例題**：$x^3 - 2x^2 + 3x - 1$ を $x - 1$ で割る。

1. 最高次項どうしを比べる：$x^3$ と $x$ から、商の最初の項は $x^2$。$x^2(x-1) = x^3 - x^2$ を引くと、$(x^3-2x^2+3x-1) - (x^3-x^2) = -x^2+3x-1$。
2. 次数が1つ下がった $-x^2$ と $x$ を比べる：商の次の項は $-x$。$-x(x-1) = -x^2+x$ を引くと、$(-x^2+3x-1) - (-x^2+x) = 2x-1$。
3. さらに次数が下がった $2x$ と $x$ を比べる：商の次の項は $2$。$2(x-1) = 2x-2$ を引くと、$(2x-1)-(2x-2) = 1$。次数が割る式 $x-1$ の次数（1次）より低くなったので終了。

商は $x^2 - x + 2$、余りは $1$。すなわち $x^3-2x^2+3x-1 = (x-1)(x^2-x+2) + 1$。

## 分数式の計算

整式を分母とする分数を**分数式**といいます。約分・通分の考え方は普通の分数と同じです。

$$\frac{x^2-1}{x-1} = \frac{(x+1)(x-1)}{x-1} = x+1 \quad (x \neq 1)$$

$$\frac{1}{x} + \frac{1}{x+1} = \frac{x+1}{x(x+1)} + \frac{x}{x(x+1)} = \frac{(x+1)+x}{x(x+1)} = \frac{2x+1}{x(x+1)}$$

## 剰余の定理

整式 $f(x)$ を1次式 $x - \alpha$ で割ったときの余りは、実際に割り算をしなくても求められます。

**剰余の定理**：整式 $f(x)$ を $x-\alpha$ で割った余りは $f(\alpha)$ に等しい。

**証明**：$f(x)$ を $x-\alpha$ で割った商を $Q$、余りを $R$ とすると、$f(x) = (x-\alpha)Q + R$ と書ける。$x-\alpha$ は1次式なので、余り $R$ の次数は $x-\alpha$ の次数（1次）より低く、$R$ は定数である。この等式は $x$ についての[恒等式](../../intermediate/algebra/equations.md)（＝どんな $x$ でも成り立つ等式）なので、特定の値 $x=\alpha$ でも当然成り立つ。したがって両辺に $x=\alpha$ を代入してもよい。代入すると $f(\alpha) = (\alpha-\alpha)Q + R = R$ となる。よって $R = f(\alpha)$ である。$\square$

**例**：$f(x)=x^3-2x^2+3x-1$ を $x-1$ で割った余りは $f(1) = 1-2+3-1=1$。これは「整式の除法」の例題で求めた商 $x^2-x+2$・余り $1$ のうち、余り $1$ と一致します。

剰余の定理の式 $f(x) = (x-\alpha)Q + R$ において、$R=0$ のときは $f(x) = (x-\alpha)Q$ となります。これは $x-\alpha$ が $f(x)$ を割り切ること、すなわち $x-\alpha$ が $f(x)$ の因数であることを意味します。因数定理は、この余りがちょうど0になる特別な場合です。$R=f(\alpha)$ だったので、$R=0$ は $f(\alpha)=0$ と同値です。したがって $f(\alpha)=0$ となる $\alpha$ を見つければ、$x-\alpha$ が $f(x)$ の因数だとわかります。

## 高次方程式を解く

3次以上の方程式（**高次方程式**）は、因数定理を使って1次式・2次式の積に分解できれば解けます。$f(\alpha)=0$ となる $\alpha$ を見つけるには、最高次の係数が1で他の係数もすべて整数の場合、定数項の約数を候補として順に試すとよい方法です。これは次のようにわかります：整式 $f(x) = x^n + \cdots + a_1 x + a_0$（係数はすべて整数）について、整数 $\alpha$ が $f(\alpha)=0$、すなわち $\alpha^n + \cdots + a_1\alpha + a_0 = 0$ を満たすとすると、$a_0$ を移項して $\alpha^n + \cdots + a_1\alpha = -a_0$、左辺を $\alpha$ でくくって $\alpha(\alpha^{n-1}+\cdots+a_1) = -a_0$、すなわち $a_0 = -\alpha(\alpha^{n-1}+\cdots+a_1)$ となります。右辺が $\alpha$ の整数倍になっていることから、$\alpha$ は $a_0$ の約数でなければなりません。

**例題**：$x^3 - 6x^2 + 11x - 6 = 0$ を解く。定数項 $-6$ の約数のうち $x=1$ を試すと $f(1) = 1-6+11-6=0$ なので $x-1$ が因数。整式の除法で $f(x) = (x-1)(x^2-5x+6) = (x-1)(x-2)(x-3)$。よって $x=1,2,3$。

> [!NOTE]
> この方法は、都合のよい（因数定理で見つけられる）根が存在する場合にのみ有効です。定数項の約数を試しても根が見つからない高次方程式も存在し、その場合の解法は本記事の範囲外です。

**複二次方程式**（$x^4$ と $x^2$ と定数だけの式）は、$x^2=t$ とおき換えると2次方程式に帰着できます。

**例題**：$x^4 + x^2 - 2 = 0$。$t=x^2$ とおくと $t^2+t-2=0$、$(t+2)(t-1)=0$ より $t=-2, 1$。$t=x^2\geq0$ なので $t=1$、$x=\pm1$。

---

## まとめ

整式は整数と同じように除法ができ、$A=BQ+R$ の形に書けます。剰余の定理を使うと、実際に割り算をしなくても $x=\alpha$ を代入するだけで余りがわかります。因数定理と組み合わせれば、高次方程式を低次の方程式に分解して解くことができます。
