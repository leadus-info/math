## 2乗の壁

引き算ができないとき、負の数が生まれました。割り算がぴったりいかないとき、分数が生まれました。今度はこんな問題を考えてみましょう。

どんな実数を2乗しても、答えは0以上になります。$3 \times 3 = 9$、$(-3) \times (-3) = 9$。では、2乗して $-1$ になる数はあるでしょうか。実数の中には答えがありません。

---

## 虚数単位と複素数の定義

「2乗して $-1$ になる数」が存在すると決めて、$i$ という名前をつけます。

**定義**：$i^2 = -1$ を満たす数 $i$ を**虚数単位**といいます。実数 $a, b$ を用いて $z = a + bi$ と表せる数を**複素数**といいます。複素数全体の集合を $\mathbb{C}$ と書きます。

> [!NOTE]
> $-i$ も2乗すると $-1$ になります。平方根では実数の大小関係を使って正の方を$\sqrt{a}$と決めましたが、複素数には実数のような大小関係がないため、$i$と$-i$を「大きい方」のように区別する自然な方法はありません。どちらを$i$と呼ぶかは単なる約束です。

- $a = \text{Re}(z)$：**実部**
- $b = \text{Im}(z)$：**虚部**
- $b = 0$ のとき実数、$a = 0$ かつ $b \neq 0$ のとき純虚数

2つの複素数 $a+bi$ と $c+di$（$a,b,c,d$ は実数）は、$a=c$ かつ $b=d$ のときに限って等しいと定めます。\
つまり、実部どうしと虚部どうしがそれぞれ等しいときだけ、2つの複素数は等しくなります。\
このため、1つの複素数の実部と虚部はそれぞれ1つに定まります。

$\mathbb{R} \subset \mathbb{C}$ です（実数は $b = 0$ の複素数）。

## 四則演算

足し算・引き算は実部同士・虚部同士を計算します。

$$(3 + 2i) + (1 + 4i) = 4 + 6i$$

$$(3 + 2i) - (1 + 4i) = 2 - 2i$$

掛け算は分配法則で展開し、$i^2 = -1$ を使います。

$$(1 + 2i)(3 + i) = 3 + i + 6i + 2i^2 = 3 + 7i - 2 = 1 + 7i$$

$z=a+bi$ に対し、虚部の符号を反転した $\bar z=a-bi$ を $z$ の**複素共役**といいます。\
$z$ と $\bar z$ を掛けると、実数になります。

$$z\bar z=(a+bi)(a-bi)=a^2-b^2i^2=a^2+b^2$$

$z\neq0$ なら $a,b$ の少なくとも一方は $0$ でないので、$a^2+b^2>0$ です。\
割り算は、分母が $0$ でないときに限って考えます。\
分母・分子に分母の複素共役を掛けると、分母が $0$ でない実数になり、計算できます。

$$\frac{1 + 2i}{3 + i} = \frac{(1+2i)(3-i)}{(3+i)(3-i)} = \frac{5 + 5i}{10} = \frac{1}{2} + \frac{1}{2}i$$

分母の $10$ は $3^2+1^2$ です。

## 複素平面

複素数 $a + bi$ を平面上の点 $(a, b)$ として表します。横軸を**実軸**、縦軸を**虚軸**とした平面を**複素平面**（ガウス平面）と呼びます。

複素数 $z = a + bi$ の**絶対値**は、複素平面上の原点からの距離です。

$$|z| = \sqrt{a^2 + b^2}, \qquad |z|^2 = z \times \bar{z}$$

これは四則演算の節で見た $z\bar z = a^2+b^2$ と一致します。

---

## 極形式

原点以外の点 $z=a+bi$ を考えます。\
原点からの距離を $r=|z|$ とし、正の実軸から反時計回りに測った角を $\theta$ とします。\
この $\theta$ を $z$ の**偏角**といいます。\
$z=0$ では角が決まらないので、偏角は考えません。

「三角関数」で見たように、単位円上で角 $\theta$ の位置にある点の座標は $(\cos\theta,\sin\theta)$ です。\
点 $(a,b)$ は、原点から同じ向きに距離 $r$ だけ進んだ点なので、$a=r\cos\theta$、$b=r\sin\theta$ です。\
これを $z=a+bi$ に代入すると、次の形になります。

$$z = r\cos\theta + (r\sin\theta)i = r(\cos\theta + i\sin\theta)$$

この形を**極形式**といいます。

> [!NOTE]
> $\theta$ に $2\pi$ の整数倍を加えても同じ点を表すため、偏角は一意には定まりません。

**例**：$1+\sqrt3\,i$ を極形式で表す。\
絶対値は $r=\sqrt{1^2+(\sqrt3)^2}=2$。\
$a=r\cos\theta$、$b=r\sin\theta$ より $\cos\theta=\dfrac{1}{2}$、$\sin\theta=\dfrac{\sqrt3}{2}$ なので、$\theta=\dfrac{\pi}{3}$（$=60°$）。\
よって $1+\sqrt3\,i=2\left(\cos\dfrac{\pi}{3}+i\sin\dfrac{\pi}{3}\right)$。

極形式では、掛け算の意味が明確になります。

$$r_1(\cos\theta_1 + i\sin\theta_1) \times r_2(\cos\theta_2 + i\sin\theta_2) = r_1 r_2\bigl(\cos(\theta_1+\theta_2) + i\sin(\theta_1+\theta_2)\bigr)$$

左辺を展開すると、

$$r_1 r_2\bigl[(\cos\theta_1\cos\theta_2 - \sin\theta_1\sin\theta_2) + i(\sin\theta_1\cos\theta_2+\cos\theta_1\sin\theta_2)\bigr]$$

三角関数の加法定理より、これは $r_1 r_2\bigl(\cos(\theta_1+\theta_2)+i\sin(\theta_1+\theta_2)\bigr)$ に等しくなり、右辺と一致します。

つまり、複素数の掛け算は「絶対値を掛け合わせ、偏角を足し合わせる」操作です。\
幾何的には、$r_2(\cos\theta_2 + i\sin\theta_2)$ を掛けることは、原点のまわりに $\theta_2$ だけ回転し、原点からの距離を $r_2$ 倍することにあたります。\
$r_2>1$ なら拡大、$r_2<1$ なら縮小です。

**例**：$i = 0+1i$ は複素平面上の点 $(0,1)$ に対応し、$r=1$、$\cos\theta=0,\ \sin\theta=1$ より偏角は $90°$ です。したがって $i$ を掛けることは偏角を $90°$ 足すこと、つまり反時計回りに $90°$ 回転させることです。

## 複素数と二次方程式

二次方程式 $ax^2+bx+c=0$ を考えます。係数 $a,b,c$ は実数で、$a\neq0$ とします。

「二次方程式」で見たように、平方完成すると次の形になります。

$$\left(x+\frac{b}{2a}\right)^2=\frac{b^2-4ac}{4a^2}$$

この右辺は、平方完成の形 $(x+p)^2=q$ の $q$ にあたります。\
右辺の分子 $b^2-4ac$ を**判別式**といい、$D$ で表します。\
分母 $4a^2$ は正なので、$q$ の符号は $D$ の符号と同じです。\
実数の範囲では、$D<0$ のとき右辺が負になるので、解はありませんでした。

複素数を使うと、負の数にも平方根を考えられます。\
正の数 $s$ について $(\sqrt s\,i)^2=s\,i^2=-s$ なので、$\sqrt{-s}=\sqrt s\,i$ と定めます。\
特に $\sqrt{-1}=i$ です。

> [!NOTE]
> 根号の中身がともに負の数のときは、根号どうしの積を1つの根号にまとめることはできません。\
> 例えば $\sqrt{-1}\times\sqrt{-1}=i\times i=-1$ ですが、$\sqrt{(-1)\times(-1)}=\sqrt1=1$ です。\
> 負の数の平方根は、先に $i$ を使った形に直してから計算します。

これで、$D<0$ のときも $\sqrt D=\sqrt{-D}\,i$ が決まります。\
$D\geq0$ のときも $D<0$ のときも、$(\sqrt D)^2=D$ が成り立ちます。\
複素数も実数と同じ規則（分配法則など）で計算できるので、平方完成の式は次のように因数分解できます。

$$\left(x+\frac{b}{2a}\right)^2-\left(\frac{\sqrt D}{2a}\right)^2=\left(x-\frac{-b+\sqrt D}{2a}\right)\left(x-\frac{-b-\sqrt D}{2a}\right)=0$$

複素数でも、2つの数の積が $0$ なら、少なくとも一方は $0$ です。\
一方が $0$ でなければ、その数で両辺を割ると、もう一方が $0$ になるからです。\
したがって、解は次の2つに限られます。

$$x=\frac{-b\pm\sqrt D}{2a}$$

これは解の公式と同じ形です。\
$D=0$ のときは2つの解が一致します（重解）。\
複素数まで解を認めると、二次方程式は重解を2つと数えれば、いつもちょうど2つの解をもちます。

**例**：$x^2+x+1=0$ を解く。$D=1-4=-3$ なので、$x=\dfrac{-1\pm\sqrt{-3}}{2}=\dfrac{-1\pm\sqrt3 i}{2}$。

## 解と係数の関係

二次方程式 $ax^2+bx+c=0$ の2つの解を $\alpha=\dfrac{-b+\sqrt D}{2a}$、$\beta=\dfrac{-b-\sqrt D}{2a}$ とします。\
2つを足すと $\sqrt D$ が消えます。

$$\alpha+\beta=\frac{-2b}{2a}=-\frac{b}{a}$$

2つを掛けると、$(\sqrt D)^2=D=b^2-4ac$ より次のようになります。

$$\alpha\beta=\frac{(-b)^2-(\sqrt D)^2}{4a^2}=\frac{b^2-(b^2-4ac)}{4a^2}=\frac{4ac}{4a^2}=\frac{c}{a}$$

これを**解と係数の関係**といいます。\
解を実際に求めなくても、和や積はこの関係から分かります。

先ほどの例 $x^2+x+1=0$（$\alpha,\beta = \dfrac{-1\pm\sqrt3 i}{2}$）で実際に確かめてみましょう。

$$\alpha+\beta = \frac{-1+\sqrt3 i}{2} + \frac{-1-\sqrt3 i}{2} = -1$$

$$\alpha\beta = \frac{-1+\sqrt3 i}{2}\cdot\frac{-1-\sqrt3 i}{2} = \frac{(-1+\sqrt3 i)(-1-\sqrt3 i)}{4} = \frac{(-1)^2-(\sqrt3 i)^2}{4} = \frac{1-(-3)}{4} = 1$$

これは公式の $-\dfrac{b}{a} = -1$、$\dfrac{c}{a} = 1$（$a=b=c=1$）と一致します。

## ド・モアブルの定理

極形式で表した複素数の掛け算は「絶対値を掛け合わせ、偏角を足し合わせる」ことでした。これを同じ複素数どうしの掛け算（累乗）に使うと、次の関係が得られます。

**ド・モアブルの定理**：整数 $n$ について、

$$(\cos\theta+i\sin\theta)^n = \cos n\theta + i\sin n\theta$$

正の整数 $n$ については、掛け算を $n$ 回繰り返すことでこの式が得られます。

$n=0$ のときは、両辺とも $1$ となり成り立ちます。

$n$ が負の整数の場合に備えて、まず $\cos\theta+i\sin\theta$ の逆数を求めます。極形式の節で示した掛け算の公式（加法定理）を使うと、

$$(\cos\theta+i\sin\theta)(\cos(-\theta)+i\sin(-\theta)) = \cos(\theta-\theta)+i\sin(\theta-\theta) = \cos 0+i\sin 0 = 1$$

となります。\
したがって、$\cos\theta+i\sin\theta$ の逆数は、偏角の符号だけを反転した $\cos(-\theta)+i\sin(-\theta)$ です。\
この計算は、$\theta$ がどんな角でも成り立ちます。

負の整数 $n$ は、正の整数 $m$ を使って $n=-m$ と書けます。\
複素数 $z$ について、$z^{-m}$ は $\dfrac{1}{z^m}$、つまり $z^m$ の逆数を表します。\
正の整数 $m$ についての定理と、上で求めた逆数の形を角 $m\theta$ に当てはめると、次のようになります。

$$(\cos\theta+i\sin\theta)^{-m}=\frac{1}{(\cos\theta+i\sin\theta)^m}=\frac{1}{\cos m\theta+i\sin m\theta}=\cos(-m\theta)+i\sin(-m\theta)$$

$-m\theta=n\theta$ なので、$n$ が負の整数のときも定理が成り立ちます。

**例**：$\left(\cos\dfrac{\pi}{6}+i\sin\dfrac{\pi}{6}\right)^{12} = \cos2\pi+i\sin2\pi = 1$。

## 1のn乗根

$n$ を正の整数とします。$z^n=1$ を満たす複素数 $z$ を、**1の $n$ 乗根**といいます。

まず、両辺の絶対値を取ると $|z|^n=1$ です。

極形式の節で見たように、複素数の積の絶対値は各々の絶対値の積になります（$r_1(\cos\theta_1+i\sin\theta_1) \times r_2(\cos\theta_2+i\sin\theta_2) = r_1 r_2(\cdots)$ で $r=|z|$ に対応する部分、すなわち $|z_1z_2|=|z_1||z_2|$）。

これを $z$ を $n$ 個掛けた積に繰り返し使うと、$|z^n|=|z|^n$ となるので、先ほどの式が得られます。$|z|$ は0以上の実数なので $|z|=1$ です。よって $z=\cos\theta+i\sin\theta$ とおけます。

これにド・モアブルの定理を使うと、

$$\cos n\theta+i\sin n\theta=1$$

複素平面上で偏角 $n\theta$ の点が $1$（実軸上の点）を指すのは、$n\theta$ が $2\pi$ の整数倍のときに限られるので、

$$n\theta = 2k\pi \quad (k\text{は整数})$$

したがって $\theta=\dfrac{2k\pi}{n}$ です。

$k=0,1,\ldots,n-1$ のとき、$\theta=\dfrac{2k\pi}{n}$ は $0$ 以上 $2\pi$ 未満の範囲で相異なる値を取るため、対応する点もすべて異なります。

$k$ を $n$ だけずらすと $\theta$ は $2\pi$ の整数倍だけ変わり、同じ点を指します。以上の2点により、相異なる点を与える $k$ は $0,1,\ldots,n-1$ の $n$ 個に限られます。

$$z_k = \cos\frac{2k\pi}{n}+i\sin\frac{2k\pi}{n} \quad (k=0,1,\ldots,n-1)$$

これらは複素平面上で、単位円周上に等間隔に並ぶ $n$ 個の点です。\
$n\geq3$ のときは、点 $1$ を1つの頂点とする正 $n$ 角形の頂点になります。\
例えば $n=6$ のときを図に示すと、次のようになります。

![複素平面上で単位円周上に等間隔に並ぶ1の6乗根6個の点。点1を1つの頂点とする正六角形をなす](complex-numbers/images/nth-roots-of-unity.svg)

同じことを、今度は $n=3$ の場合で具体的に数値を確かめてみましょう。

**例**：$z^3=1$ の解は $z=1,\ \cos\dfrac{2\pi}{3}+i\sin\dfrac{2\pi}{3},\ \cos\dfrac{4\pi}{3}+i\sin\dfrac{4\pi}{3}$ の3つです（偏角 $\dfrac{2\pi}{3}$ は $120°$、$\dfrac{4\pi}{3}$ は $240°$ に相当）。複素平面上で正三角形をなします。

## まとめ

2乗して負になる数は実数の中にはありません。この壁を超えるために、$i^2=-1$ を満たす虚数単位 $i$ を導入し、複素数 $a+bi$ を作りました。複素数は複素平面上の点として幾何的に扱うことができ、掛け算は極形式で「回転と拡大・縮小」として理解できます。
