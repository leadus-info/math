## 連続的な値をとる確率変数

サイコロの出目のように、とびとびの値しかとらない確率変数（離散型）に対して、身長や測定誤差のように、ある範囲のどんな値もとりうる確率変数を**連続型確率変数**といいます。

連続型確率変数では、特定の1つの値をとる確率を考える代わりに、ある区間に入る確率をグラフの下側の面積として考えます。連続的な値は無数にあり、特定の1点をぴったりとる確率は事実上0になるため、区間の面積で確率を表すのです。この確率を与える関数を**確率密度関数**といいます（そのグラフを密度曲線と呼ぶこともあります）。

## 正規分布

自然界や社会に現れる多くのデータは、平均値の周りに左右対称の釣鐘型に分布する傾向があります。この代表的な分布を**正規分布**といい、平均 $\mu$、標準偏差 $\sigma$ の正規分布を $N(\mu,\sigma^2)$ と表します。

$N(\mu,\sigma^2)$ に従う確率変数を $X$ とすると、正規分布には次の性質があります（**68-95-99.7ルール**）。

$$P(\mu-\sigma \leq X \leq \mu+\sigma) \approx 0.683$$
$$P(\mu-2\sigma \leq X \leq \mu+2\sigma) \approx 0.954$$
$$P(\mu-3\sigma \leq X \leq \mu+3\sigma) \approx 0.997$$

平均から標準偏差の何倍離れているかによって、データがどれくらいの割合含まれるかがほぼ決まっている、ということです。

---

## 標準化と標準正規分布表

正規分布 $N(\mu,\sigma^2)$ に従う $X$ を、次のように変換します。

$$Z = \frac{X-\mu}{\sigma}$$

こうしてできる $Z$ は、平均0、標準偏差1の正規分布 $N(0,1)$（**標準正規分布**）に従います。この変換を**標準化**といいます。

標準正規分布の確率は**標準正規分布表**にまとめられており、$Z$ の値さえわかれば、どんな平均・標準偏差の正規分布の確率も、標準化してこの表を引くだけで求められます。標準正規分布表は、$0$ から $z$ までの範囲に入る確率 $P(0\leq Z\leq z)$ の値を与える表です。

| z | $P(0\leq Z\leq z)$ | z | $P(0\leq Z\leq z)$ |
|---|---|---|---|
| 0.0 | 0.0000 | 1.6 | 0.4452 |
| 0.1 | 0.0398 | 1.7 | 0.4554 |
| 0.2 | 0.0793 | 1.8 | 0.4641 |
| 0.3 | 0.1179 | 1.9 | 0.4713 |
| 0.4 | 0.1554 | 2.0 | 0.4772 |
| 0.5 | 0.1915 | 2.1 | 0.4821 |
| 0.6 | 0.2257 | 2.2 | 0.4861 |
| 0.7 | 0.2580 | 2.3 | 0.4893 |
| 0.8 | 0.2881 | 2.4 | 0.4918 |
| 0.9 | 0.3159 | 2.5 | 0.4938 |
| 1.0 | 0.3413 | 2.6 | 0.4953 |
| 1.1 | 0.3643 | 2.7 | 0.4965 |
| 1.2 | 0.3849 | 2.8 | 0.4974 |
| 1.3 | 0.4032 | 2.9 | 0.4981 |
| 1.4 | 0.4192 | 3.0 | 0.4987 |
| 1.5 | 0.4332 | | |

正規分布は平均を中心に左右対称で、全体の確率は1であるため、平均より大きい側の確率はちょうど0.5になります。

**例題**：ある試験の得点が平均60点、標準偏差10点の正規分布に従うとする。70点以上の受験者の割合を求める。$Z=\dfrac{70-60}{10}=1$。標準正規分布表より $P(0\leq Z\leq1)\approx0.3413$ なので、$P(Z\geq1)=0.5-P(0\leq Z\leq1)=0.5-0.3413=0.1587$。よって約16%。

## 二項分布の正規分布による近似

二項分布$B(n,p)$ は、$n$ が大きくなると、平均 $np$、標準偏差 $\sqrt{np(1-p)}$ の正規分布に近い形になっていきます。独立な試行を多数積み重ねた合計を考えます。この合計は、もとの分布の形によらず正規分布に近づくという性質があり、これを**中心極限定理**といいます。二項分布の確率を直接計算するのが大変な場合、正規分布で近似して計算できます。

> [!NOTE]
> ここでは直感的な理解にとどめています。厳密な証明は、より発展的な内容の[正規分布](../../bachelor/probability/distributions-normal.md)で扱います。

**例題**：さいころを720回投げて1の目が出る回数を $X$ とする。$n=720$、$p=\dfrac16$ として、$X$ はおよそ $N(120, 10^2)$ とみなせる（[二項分布](binomial-distribution.md)の例題より、$E(X)=np=120$、$\sigma(X)=\sqrt{np(1-p)}=10$）。$X\leq100$ となる確率を求める。

標準化すると、

$$Z=\frac{100-120}{10}=-2$$

$Z=-2$ は、$X$ がちょうど $\mu-2\sigma$（$=100$）に等しいことを意味する。68-95-99.7ルールより $P(\mu-2\sigma\leq X\leq\mu+2\sigma)\approx0.954$ なので、区間の外側に残る確率は $1-0.954=0.046$ である。正規分布は左右対称なので、この $0.046$ は上側・下側に均等に分配され、

$$
\begin{aligned}
P(X\leq100) &\approx \frac{1-0.954}{2} \\
&= \frac{0.046}{2} = 0.023
\end{aligned}
$$

となる。

---

## まとめ

正規分布は連続型確率変数の代表的な分布で、平均から標準偏差の何倍離れているかによってデータの含まれる割合がほぼ決まっています。標準化によってどんな正規分布も標準正規分布に変換でき、標準正規分布表を使って確率を求められます。二項分布も、試行回数が大きければ正規分布で近似できます。
